## 运行方式

- **Python**：`python xxx.py`，需要 Python 3。
- **C++**：`g++ xxx.cpp -o xxx` 后运行；部分文件使用 C++17/C++20。
- **OJ 题解片段**：`算法/题目/` 与 `力扣等编程（未整理）/leetcode 1-7/逐题代码/` 下多为 `class Solution` 或独立函数，省略了头文件和 `main()`，不能直接单独编译；需要时补全后贴回 LeetCode，或自行加测试入口。
- **算法题目自检**：`python 算法/tools/check.py`（语法 + 编码 + 命名 + 档案完整性），OJ 片段靠 `算法/tools/oj.h` 补头文件。

## 整理约定

- `算法/` 的规则写在 [`算法/整理原则.md`](算法/整理原则.md)：一题一档、`vN-做法.cpp` 命名、`状态`/`错因` 固定枚举、代码有错只标状态不改写。新增题解前先看模板。
- 中文资料直接使用中文文件名；文件名里不写空格、全角括号和主观评价。
- 已成体系的 `算法/` 与早期材料 `力扣等编程（未整理）/` 分开存放，避免把半成品混进成体系的笔记。
- `leetcode 1-7/` 内部按“文档保存 + 逐题代码”分层，文档标题与代码文件名尽量一一对应；增删题解时同步更新该目录的 `README.md` 与 `文件地图.md`。
- 移动/改名一律用 `git mv`，保留文件历史。
- 忽略规则见 `.gitignore`：Python 缓存、`node_modules`、构建产物和编辑器配置不入库。
