## 内容说明

### 算法与编程
- **力扣等编程（认真整理！）**：按 `月份/题号-方法` 的方式组织，例如 `26.10/1679-双指针解法`、`26.10/274 O(n)算法.cpp`。同一题的不同复杂度或不同思路会分别保留，方便对比。
- **力扣等编程（未整理）**：早期材料，包括题目 PDF、专题笔记（如 `map_unordered_map精讲.md`）和竞赛备赛资料，命名和分类还不统一。
- **一点离散**：以消解算法为主线，包含原始实现、优化版和配套讲解。
- **数据结构**：目前是零散的代码练习，后续会按专题补充。

### Python
入门阶段的小练习，重点在语法和基本思路，暂未形成系统笔记。

### 网页与游戏
- `小学期网页开发/`：小学期 vibe coding 出来的前端小游戏，功能已经完善，但美术和交互比较粗糙，计划后续重做。

## 运行方式

- **Python**：`python xxx.py`，需要 Python 3。
- **C++**：`g++ xxx.cpp -o xxx` 后运行；部分文件使用 C++17。
- **网页**：直接用浏览器打开 `小学期网页开发/index.html`；若涉及音频或模块加载，建议在目录下起一个本地静态服务器，例如 `python -m http.server`。

## 整理约定

- 中文资料直接使用中文文件名，题解尽量带上题号与解法关键词。
- “认真整理”和“未整理”分开存放，避免把半成品混进成体系的笔记。
- 忽略规则见 `.gitignore`：Python 缓存、`node_modules`、构建产物和编辑器配置不入库。
