# 示例课 02：邻接约束与条件翻译（模块 C 草案，层级 B，成文模式）

**题目背景**：删除任意元素、保留相对顺序，使剩余数组每对相邻元素的异或结果不为 0，求最少删除次数。

**为什么单列模块**：这题的认知动作不是"套算法"，是把位运算条件翻译成相等关系，再把局部约束收拢到连续段。与模块 A、B 都不同，属于"条件改写 + 局部化"这一类。

## 课文

nums = [1, 1, 2]。先按原样留下全部三个数：1 和 1 的异或结果是 0，第一对相邻元素就违规。把第一个 1 删掉，留下 [1, 2]；1 和 2 的异或结果是 3，非零，通过。一次删除。

nums = [1, 2, 1]。同样两个 1、一个 2，顺序换了一下。三个数全部留下：1 和 2 的异或结果是 3，2 和 1 的异或结果是 3。零次删除。

异或结果为零的相邻对，恰好就是相等的一对——翻译过来，条件里只剩相等和相邻两件事。挨着的相等元素连成一段，叫连续段。段内两两相等，留下一个，删掉 k−1 个（k 是段长）；两段的交界处，值必然不同，不用处理。最少删除次数，等于每个连续段长度减一之和。

nums = [1, 1, 1, 2, 2, 3]。三个连续段，长度分别是 3、2、1，删除次数 2 + 1 + 0 = 3。留下的 [1, 2, 3] 逐对验一遍：1 和 2 异或为 3，2 和 3 异或为 1，全部非零。

回到 [1, 1, 2]：一个长度 2 的连续段，删掉 1 个。异或为零的那对，就是连续段里挨着的两个 1；连续段把相等的元素聚成块，答案就是每块长度减一之和——也就是数一数有多少对相邻元素相等。

## 结论与实现

- 等价关系：`a ^ b == 0` 当且仅当 `a == b`。
- 答案 = 相邻相等对的数量 = n − 连续段数。
- 单次扫描，O(n) 时间、O(1) 空间。

```cpp
int minDeletions(vector<int>& nums) {
    int ans = 0;
    for (int i = 1; i < (int)nums.size(); ++i)
        if (nums[i] == nums[i - 1]) ++ans;
    return ans;
}
```
