# Python 学习目录规则

本规则用于本目录及子目录中的教学、出题、作业检查和路线图维护。

## 出题与阶段推进

- 工作前阅读 `教学路线图.md`，按已学内容、现有作业和阶段训练状态安排后续。
- 每部分必须包含基础训练、至少一道综合题和至少一道有难度的挑战题。
- 综合题至少组合三个已学知识点；后续继续安排跨部分综合题，复习旧知识。
- 挑战题通过问题拆解、边界分析、规律或调试提高难度，不依赖尚未讲解的语法。
- 使用仓库多本电子书的练习作为参考；核实相关章节后注明来源，区分原题、改编题和自编题。
- 具体题意、必要知识说明、样例和检查重点写入新的编号 `.py` 文件，保留作答区。
- 不覆盖学生已有答案，未被要求时不直接给完整解答。
- 新题创建后、回复前，必须同步在路线图对应部分加入有效的相对文件链接。
- 链接旁标明题号、题型（基础/综合/挑战）、检查状态；阶段题创建后替换对应的“待出题”。
- 路线图保留细化知识点和训练覆盖范围，不放具体题意、答案或长篇讲解。
- 知识点覆盖、综合题与挑战题检查完成后才将整个部分标为完成。
- 用户要求跳转时遵从安排，并记录未完成的阶段训练，后续适时补充。

## 作业检查

- 读取学生已保存的文件，检查实现方式，并在可运行时实际执行核对。
- 综合题、挑战题按题意检查有代表性的正常与边界情况；需要时在内存中变更测试数据，不改学生答案。
- 分开反馈核心知识、结果正确性、边界问题、输出格式与代码风格。
- 普通练习中的非关键格式差异不阻止核心知识过关；严格判题格式在出题时明确。
- 先给具体、分层提示；用户要求完整答案时再给解答。
- 检查后同步路线图状态：完全通过、核心已掌握（注明差异）、待修改或待检查。
- 不将“核心已掌握”写成严格输出和全部要求都已通过，不把基础题完成当成整个阶段完成。

## 当前约定

- 学生主要在编辑器中写题，保存后用“检查作业”等短指令触发读取与检查。
- 交流使用中文，以掌握知识和逐步独立解决问题为目标。
