## 二、核心知识点系统整合

### 1. 程序分析与基本布局
- **IPO 分析法（对应课件 `lec2`）**：写程序前先理清 **I（Input 输入什么）→ P（Process 如何处理）→ O（Output 按什么格式输出）**，避免边写边改、漏掉格式要求。
- **解释执行与顺序**：Python 自上而下逐行解释执行。后面语句对变量重新赋值，**不会自动回溯修改**此前已经拼接并存进另一个变量里的旧字符串（第 8 题核心原理）。
- **缩进规则**：同一代码块行首缩进必须一致（推荐 4 个空格），随意多空格或少空格会触发 `IndentationError`。
- **注释**：
  - 单行注释 `# ...`：用于解释代码意图或回答概念问题，不参与程序运行；
  - 多行文本/注释 `'''...'''` 或 `"""..."""`：可用于多行说明文档（在函数/类开头叫 docstring）。

### 2. 变量、命名规范与“保留字 vs 内置函数”
- **变量赋值与重赋值**：用单个等号 `=` 绑定值；同一变量再次赋值时，指向新值。修改原变量时，若还想保留原始资料或旧结果，必须先用新变量保存（或不要覆盖原变量）。
- **命名规则**：只能包含字母、数字和下划线 `_`，不能以数字开头，区分大小写（`name` 与 `Name` 不同）。
- **PEP 8 代码风格**：赋值号 `=` 左右各留 1 个空格（`name = "Eason"`），函数参数或解包逗号 `,` 后留 1 个空格（`center(30, "-")`）。
- **保留字 vs 内置函数（高频易考重点）**：
  - **保留字（关键字）**：如 `if`、`elif`、`else`、`for`、`while`、`in`、`is`、`def`、`return`、`import`、`True`、`False`、`None` 等（可通过 `help('keywords')` 或 `keyword.kwlist` 查看）。**不能用作变量名**，否则直接报 `SyntaxError`。
  - **内置函数 / 内置类型名**：如 `print`、`input`、`len`、`int`、`float`、`str`、`ord`、`chr`、`format`、`eval`。它们**不是保留字**，Python 语法上允许写 `str = "abc"` 或 `ord = 10`，但一旦这么写就会**覆盖原功能**，后面再写 `str(123)` 或 `ord('A')` 就会报错（如 `TypeError: 'int' object is not callable` 或 `'str' object is not callable`）。**工程上严禁用内置名当变量名**。

### 3. 字符串、引号、转义字符与 Unicode 编码
- **引号选择**：单引号 `'...'`、双引号 `"..."` 效果相同；当字符串内容里本身包含双引号时，要么外层用单引号 `'He said "Hi"'`，要么在双引号内部用反斜杠转义 `"He said \"Hi\""`。
- **常用转义字符**（注意是反斜杠 `\`，不是斜杠 `/`）：
  - `\n`：换行；
  - `\t`：水平制表符（**是 1 个 `\t` 字符，不是几个空格**）；
  - `\r`：回车（将光标移回当前行首，课件中用于文本进度条单行动态刷新）；
  - `\"` / `\'`：输出普通双引号 / 单引号；
  - `\\`：输出一个真正的反斜杠 `\`。
- **长度与编码**：
  - `len(s)`：返回字符串中的**字符个数**（1 个汉字、1 个空格、1 个 `\n` 或 `\t` 都算 1 个字符）。
  - `ord(ch)`：把**单个字符**转成对应的 Unicode 整数编码（如 `ord('A') == 65`、`ord('a') == 97`、`ord('0') == 48`、`ord('数') == 25968`）。
  - `chr(code)`：把整数编码还原为对应的**单个字符**（如 `chr(66) == 'B'`、`chr(ord('a') + 1) == 'b'`）。

### 4. 字符串格式化：`f-string` 与 `str.format()` 双轨对照
- **`f-string`**：`f"Char: \"{ch}\"\tCode: {code}"`，直观清晰，花括号里可直接放变量或简单表达式。
- **`str.format()` 完整规则（对齐课件 `lec3` 与第 14 题提问）**：
  基本结构为：
  ```text
  "{参数定位:格式说明}".format(参数0, 参数1, ...)
  ```
  1. **冒号前面（选哪个参数）**：
     - `{}`：省略编号，按花括号从左到右的顺序依次取 `.format()` 中的第 0、1、2… 个参数；
     - `{0}`、`{1}`：按位置序号取值，**编号必须从 `0` 开始**。如果 `.format(x)` 只传了 1 个参数，写了 `{1}` 就会报 **`IndexError: Replacement index 1 out of range`**；
     - `{name}`：按关键字参数取值，如 `"{name}: {score}".format(name="Ada", score=95)`。
  2. **冒号后面（怎么排版）**：
     常见顺序：`[填充字符][对齐方式][最小宽度][,][.精度][类型]`（按需选填）：
     - **对齐方式**：`<` 左对齐、`>` 右对齐、`^` 居中对齐（省略时，**字符串默认左对齐，数字默认右对齐**）；
     - **填充字符**：写在对齐符号**前面**的单个字符，省略默认填充空格（例：`"{:*^10}".format("PY")` → `"****PY****"`）；
     - **最小宽度**：整数，表示至少占多少字符。如果实际内容长度已经大于或等于该宽度，**不会截断**，按原长度完整输出；
     - **小数与数字格式**：如 `{:.2f}`（保留两位小数）、`{:02d}`（整数至少 2 位，不足左侧补 `0`）、`{:,}`（千分位）。

### 5. 字符串清理、大小写转换与居中方法
- **不可变性**：所有字符串方法（`.strip()`、`.upper()` 等）**都不会修改原字符串变量**，而是返回一个新字符串；必须用 `=` 赋值接住返回值，结果才会保存下来。
- **大小写转换**：
  - `.upper()`：全大写；
  - `.lower()`：全小写；
  - `.title()`：每个单词首字母大写、其余字母小写。
- **空白与字符集清理**：
  - 无参数 `.strip()` / `.lstrip()` / `.rstrip()`：分别清理**首尾两端 / 仅左侧 / 仅右侧**的全部空白字符（包含空格、`\t`、`\n` 等）。注意 `.rstrip(" ")` 只删半角空格，漏不掉 `\t`，一般直接用无参 `.rstrip()` 更稳妥。
  - **带参数 `.strip(chars)` / `.lstrip(chars)` / `.rstrip(chars)`**：参数 `chars` 表示**要剥离的字符集合**（不是按整个子串去匹配），从对应端点逐字符移除凡是在集合里的字符，直到遇到第一个不在集合里的字符就立刻停止；**字符串内部（中间）的字符绝不会被删掉**。
    - 示例：`"= python= ".strip(" =np")` → 两端去掉 `' '`、`'='`，右侧还会去掉 `'n'`，结果是 `"pytho"`；
    - 单侧清理意义：当末尾本身允许保留合法符号（如 `"  >>*build*  "` 的合法代号是 `"build*"`）时，必须用 `.rstrip().lstrip(" >*")`，而不能用双向 `.strip(" >*")`。
- **居中方法**：`s.center(width, fillchar)` 与 `"{:{fill}^{w}}"` 作用一致，当 `len(s) >= width` 时不截断。
- **链式调用**：`seg1.lstrip(" >*").rstrip()` 从左到右依次执行，前一个方法返回的仍是字符串，所以可以继续点出下一个方法。

### 6. 本阶段衔接的输入与拆分写法
- `raw = input()`：读取整行原始字符串（保留首尾空格，**不要在括号里写提示文字**）；
- `n = int(input())`：读取一行并转为整数；
- `a, b, c = raw.split("|")`：按指定分隔符 `|` 拆成三段并解包（默认无参 `.split()` 则按任意空白拆分）。

### 题型 A 答案与解析
- **A1**：
  - 代码 1：第 2 行输出 `1234`，但第 3 行会报 **`TypeError: 'str' object is not callable`**，因为第 1 行用变量 `str` 覆盖了内置类型 `str()`。
  - 代码 2：报 **`IndexError: Replacement index 1 out of range for positional args tuple`**，因为 `.format(x)` 只传了 1 个参数（索引为 `0`），不存在索引 `1`。
- **A2**：输出 **`ello*world`**。
  - 解析：`.strip("*=h")` 把 `"*=h"` 当作字符集合。左端依次剥掉 `*`、`=`、以及 `hello` 开头的 `'h'`，遇到 `'e'` 不在集合里就停下；右端依次剥掉 `*`、`=`，遇到 `'d'` 停下；**中间的 `*` 不会被删除**。
- **A3**：
  - 第 1 行：`[Python]`（内容长度 6 大于最小宽度 4，**不截断**，原样输出）；
  - 第 2 行：`[A   |   5]`（省略对齐符号时，字符串 `"A"` 默认左对齐，整数 `5` 默认右对齐）；
  - 第 3 行：`[**HI***]`（总宽 7、内容长 2，需补 5 个 `*`，Python 居中在奇数差额时左少 1 个、右多 1 个，即左 2 右 3）。
- **A4**：
  - `len(msg)` 等于 **`7`**（7 个字符依次是 `'A'`、`'\t'`、`'"'`、`'B'`、`'"'`、`'\n'`、`'C'`；转义序列 `\t`、`\"`、`\n` 各算 1 个字符）；
  - 输出两行：
    ```text
    A	"B"
    C
    ```

### 题型 B 答案与解析
- **B1**（共 4 处问题）：
  1. `input = input()` 覆盖了内置函数 `input`；
  2. `ord = ord(input)` 覆盖了内置函数 `ord`；
  3. 输出格式 `Code: \"{ord}\"` 多加了引号（目标要求 `Code: 97`）；
  4. **隐藏混用大坑**：前面写了 `f"..."`，后面又接 `.format(input, ord)`！`f-string` 会先求值，`{0:<4}` 在 `f-string` 里会被当成数字 `0` 格式化成 `0   `，`{1:>4}` 变成 `   1`，然后 `.format(...)` 因为字符串里已经没有 `{}` 槽位而什么都填不进去！
  - 改法示例：
    ```python
    ch = input()
    code = ord(ch)
    next_ch = chr(code + 1)
    card = "[{0:<4}|{1:>4}]".format(ch, code)
    print(f"Code: {code}\nNext: {next_ch}\n{card}")
    ```
- **B2**（共 2 处问题）：
  1. 用 `raw = ...` 覆盖了原变量 `raw`，导致最后输出两边的 `[...]` 变成同一个值，失去了原值；
  2. 用了双向 `.strip(" >*")`，把末尾合法的 `*` 也误删了，变成了 `"run"` 而不是 `"run*"`。
  - 改法：保留 `raw` 不变，新变量 `cleaned = raw.rstrip().lstrip(" >*")`，再输出 `f"[{raw}] -> [{cleaned}]"`。
- **B3**：
  1. `"{0}\t{1}".format(a)` 只传了 1 个参数 `a`，却写了 `{1}`，会报 `IndexError`，应传入 `(a, b)`；
  2. 即使传对了参数，先 `.format()` 再 `.center(10, "-")` 中间是 `\t`（占 1 个字符宽度），如果本意是不居中、或要分别处理，要先确认题意；按括号里注释的要求，应写成 `"{0}\t{1}".format(a, b).center(10, "-")`。

### 题型 C 答案与解析
1. - **绝对不能用（`SyntaxError`）**：`2nd_tag`（数字开头非法标识符）、`for`（保留字）、`in`（保留字）、`True`（保留字）。
   - **能过语法但严禁使用（会覆盖内置名）**：`str`、`format`、`ord`、`print`。
   - **合法且推荐**：`user_name`。
2. 因为 `.strip(" >*")` 会同时从**左右两端**剥离字符集里的字符，如果命令代号末尾本身合法带有 `*`（或 `>`），就会被一并删掉；改用 `.rstrip().lstrip(" >*")` 时，`.rstrip()` 只清右侧空白（保留末尾 `*`），`.lstrip(" >*")` 只清左侧多余的空格、`>`、`*`。
