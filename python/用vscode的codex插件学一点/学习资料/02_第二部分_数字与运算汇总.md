## 二、核心知识点系统整合

### 1. 数值类型、多进制、E 记法与复数
- **整数 `int`**：Python 整数精度不受位数限制（如 `pow(2, 500)` 不会溢出）。支持四种进制写法（多进制字面量可直接参与运算，如 `0xFB + 0b10 == 253`）：
  - 十进制：`425`
  - 二进制 `0b`：`0b110101001`；转字符串用 `bin(n)`（返回 `str`）
  - 八进制 `0o`：`0o651`；转字符串用 `oct(n)`（返回 `str`）
  - 十六进制 `0x`：`0x1a9`；转字符串用 `hex(n)`（返回 `str`）
- **浮点数 `float` 与科学计数法（E 记法）**：
  - `<a>e<b>` 或 `<a>E<b>` 表示 $a \times 10^b$，结果一定是 `float`（如 `4.3e-3 == 0.0043`，`9.6E5 == 960000.0`）。
  - `float("4.3e-3")` 可直接把科学计数法字符串转为浮点数。
- **复数 `complex`**：
  - 用 `a + bj` 或 `complex(a, b)` 构造（虚部单位是 `j`，不是数学里的 `i`）。
  - `z.real` 取实部，`z.imag` 取虚部，两者类型均为 `float`。
- **跨数值类型混合运算拓宽规则**：
  - 混合运算时按 **`int → float → complex`** 由窄到宽自动转换（如 `1 + 2.0` 为 `float`，`1 + 2.0 + (3 + 4j)` 为 `complex`）。
- **数字与数字字符串的区别**：`"12"` 是字符串不能直接做减法或乘方，参与数学运算前必须用 `int()` 或 `float()` 转换。

### 2. 算术运算、优先级与整数拆分技巧
- **三种除法对比**：
  - `/` 普通除法：结果**永远是 `float`**（即使 `10 / 2 == 5.0`）；
  - `//` 整除（向下取整商）：`17 // 5 == 3`；
  - `%` 取余（模运算）：`17 % 5 == 2`；恒等式：`n == (n // m) * m + (n % m)`（前提 $m \ne 0$）。
- **乘方 `**` 与右结合性（高频考题！）**：
  - 绝大多数算术运算符从左往右算，但 **`**` 是右结合（从右往左算）**：
    $$2 ** 3 ** 2 = 2 ** (3 ** 2) = 2 ** 9 = 512$$
  - 与 `pow(x, y)` 功能对应，注意 `^` 在 Python 里不是乘方（是按位异或）。
- **复合赋值**：`+=`、`-=`、`*=`、`//=`、`%=` 会**直接修改原变量**。当题意要求保留原始输入/总量（如第 9 题的 `total_seconds`）时，不要用 `%=` 覆盖它，应使用新变量接收余数。
- **纯整数向上取整公式（第 17 题挑战核心）**：
  - 当每箱装 `cap` 件、总计 `items` 件（`items >= 0`, `cap >= 1`）时，不用 `if` 或 `math.ceil()`，最少箱数为：
    ```python
    total_boxes = (items + cap - 1) // cap
    ```
  - 边界验证：`items = 0` → `(cap - 1) // cap == 0`；整除 `items = 20, cap = 10` → `29 // 10 == 2`；多 1 件 `items = 11, cap = 10` → `20 // 10 == 2`。
- **多层单位拆分（如跨天时刻）**：
  - 一天 `1440` 分钟：总天数 `days = total_min // 1440`，当天剩余分钟 `day_min = total_min % 1440`，小时 `day_min // 60`，分钟 `day_min % 60`。

### 3. 浮点误差、`Decimal`、`round()` 与 `math` 模块
- **浮点数二进制精度误差**：
  - 计算机用二进制存储浮点数，`0.1`、`0.2` 在二进制中是无限循环小数，因此 `(0.1 + 0.2) == 0.3` 结果为 **`False`**（实际约 `0.30000000000000004`）。
- **`decimal.Decimal` 高精度计算**：
  - `from decimal import Decimal` 后，务必传**字符串**：`Decimal("0.1") + Decimal("0.2")` 得到精确的 `Decimal('0.3')`。
  - **不能写成 `Decimal(float(x))` 或 `Decimal(0.1)`**：先转 `float` 会把二进制误差一并带进 `Decimal`，导致失真。
- **`round()` 的银行家舍入（四舍六入五成双 / Round half to even）**：
  - 在 Python 3 中，遇到正中间的 `.5` 时，向**离它最近的偶数**舍入：
    `round(0.5) == 0`、`round(1.5) == 2`、`round(2.5) == 2`、`round(3.5) == 4`。
  - 先完成所有中间计算，只在最后显示输出时再格式化舍入，不要提前截断中间结果。
- **`math` 模块常用能力**：
  - `math.sqrt(x)`（开平方）、`math.pow(x, y)`（浮点乘方，结果总是 `float`，而整数做 `**` 或内置 `pow()` 得 `int`）、`math.pi`（圆周率）；
  - **`math.nan` 与 `math.isnan()`**：`NaN`（Not a Number）不等于包括它自己在内的任何值，所以 `math.nan == math.nan` 和 `float('nan') == float('nan')` 都是 **`False`**，判断是否为 `NaN` 必须调用 `math.isnan(x)`。

### 4. 数值输入、拆分与数字格式化全解
- **输入转换与拆分原则**：
  - 课件中常见 `eval(input())`，虽然能直接算出表达式或逗号元组，但在工程和评测中存在安全隐患且容易掩盖类型错误。**做题统一按字段语义用 `int()` 和 `float()`**；
  - 评测时 `input()` 括号里**不要写提示文字**，否则提示文字会被当作输出的一部分；
  - 单行多参数先 `input().split()` 再解包并逐项转换；推荐无参 `.split()`（可处理连续空格、首尾空白与 `\t`），不要写成 `.split(" ")`（遇到连续空格会产生空字符串）。
- **百分比换算**：题意给出“减免 `20`（即 `20%`）”时，计算比例前务必先 `/ 100`。
- **通用数字格式说明符（`f-string` 与 `.format()` 冒号后完全通用）**：
  完整骨架：`{ 值 : [填充字符][对齐 < > ^][符号 + - 空格][0][最小宽度][千分位 ,][.精度][类型] }`
  - **拆解 `{n:02d}`**：`d` 表示十进制整数（同类还有 `f` 浮点数、`s` 字符串、`b`/`o`/`x` 二/八/十六进制、`%` 百分比）；`2` 表示最小宽度至少 2 格（位数大于等于 2 时**不截断**）；`0` 表示左侧补 `'0'`（遇负数补在负号后，如 `f"{-5:03d}"` → `"-05"`）。
  - **对齐与填充规则**：省略对齐时，数字默认右对齐、字符串默认左对齐（如 `f"{5:5d}"` → `"    5"`）；指定填充字符时**必须紧跟 `<`/`>`/`^` 对齐符号**（如 `f"{5:0>4d}"` → `"0005"`、`f"{'PY':*^8}"` → `"***PY***"`）。
  - **格式化 vs `round()` 的显示差异**：`round(7.0, 2)` 仍返回数值 `7.0`；只有 `f"{7:.2f}"` 或 `"{:.2f}".format(7)` 才会固定输出两位小数 `"7.00"`（补齐末尾 `0`，且不改变原变量值）。
  - **常用模板速查**：
    - `{x:.2f}` / `{x:8.2f}` / `{x:08.2f}`：保留 2 位小数 / 总宽 8 格（含小数点）右对齐 / 总宽 8 格左侧补 `0`；
    - `{x:.2e}`：科学计数法保留 2 位小数（如 `4.30e-02`）；
    - `{n:,}`：千分位逗号（如 `1,000,000`）；`{p:.1%}`：百分比形式（如 `12.5%`）。
