# Python 学习路线图

## 一、输出、变量与字符串基础

- `print()` 与程序执行顺序
- 变量、赋值、重新赋值与命名规范
- 字符串、引号与注释
- f 字符串
- 换行符 `\n`、制表符 `\t` 与转义
- 字符串方法：`strip()`、`lstrip()`、`rstrip()`
- 字符串大小写：`upper()`、`lower()`、`title()`

## 二、数字与运算

- 整数与浮点数
- 加、减、乘、除
- 整除、取余与乘方
- 运算优先级与括号
- 复合赋值运算符
- 浮点数精度与输出格式

## 三、输入、类型与条件判断

- `input()`
- `int()`、`float()`、`str()` 与 `type()`
- 布尔值与比较运算符
- 逻辑运算符 `and`、`or`、`not`
- 缩进与代码块
- `if`、`elif`、`else`
- 嵌套条件与边界条件

## 四、列表、字符串与循环

- 列表的创建、索引与切片
- 列表元素的增加、修改与删除
- `len()`、`sum()`、`min()`、`max()`
- `for`、`range()` 与 `while`
- 累加、计数与遍历
- `break`、`continue` 与循环嵌套
- `enumerate()` 与 `zip()`
- 字符串索引、切片、遍历与成员判断
- `split()`、`join()`、`replace()` 与查找
- 排序、反转、列表复制与列表推导式

## 五、元组、字典与集合

- 元组与序列解包
- 字典的键值对、增删改查与遍历
- `get()`、`keys()`、`values()`、`items()`
- 集合、去重与集合运算
- 嵌套数据结构
- 可变对象、不可变对象与引用

## 六、函数与代码组织

- 函数定义与调用
- 形参、实参、位置参数与关键字参数
- 默认参数与可变参数
- 返回值与多个返回值
- 变量作用域
- 文档字符串与类型标注
- 函数拆分与代码复用
- 模块、`import` 与主程序入口

## 七、异常与文件

- 常见异常与错误信息
- `try`、`except`、`else`、`finally` 与 `raise`
- 输入验证与异常处理
- 文件路径与 `pathlib`
- `with`、文本文件读写与字符编码
- JSON 与 CSV

## 八、面向对象基础

- 类、对象、属性与方法
- `__init__()` 与 `self`
- 实例属性与类属性
- 继承、方法重写与组合
- 常见特殊方法

## 九、常用标准库与开发环境

- `math`、`random`、`datetime` 与 `collections`
- 迭代器与生成器基础
- 正则表达式基础
- Python 解释器与命令行
- 虚拟环境、`pip` 与依赖管理
- Git 基础

## 十、调试、测试与综合运用

- 断点、单步执行与变量观察
- 语法错误、运行错误与逻辑错误
- `assert` 与单元测试
- 正常情况、边界情况与异常情况
- 日志
- 代码风格、重构与复杂度基础
- 需求拆解、数据建模与模块协作
