# Python 学习路线图

## 学习与出题约定

- 每部分按“基础练习 → 阶段综合题 → 阶段挑战题”推进，至少有一道综合题和一道有难度的挑战题。
- 综合题至少结合三个已学知识点；后续持续加入跨部分综合练习。
- 挑战题侧重独立拆解、边界情况、规律分析或调试。需要的新语法先讲解再使用。
- 参考仓库中的多本课本，实际查阅后注明书名和章节；明确区分原题、改编题与自编题。
- 每次新建题目，必须在本次回复前把有效的相对文件链接加入对应部分，并标明题型和检查状态。
- 检查后更新状态：完全通过、核心已掌握（注明差异）、待修改、待检查。
- 知识点已覆盖、综合题和挑战题均完成检查，才算完成一个部分。用户调整学习顺序时记录尚待补充的内容。
- 检查先关注思路、知识点和结果，再反馈边界、输出格式和风格；严格格式要求在出题时提前说明。
- 先给分层提示，用户要求完整答案时再提供解答。
- 本路线图只列知识点、训练覆盖范围、链接和进度；具体题目和说明放在对应文件。
- 第10题起采用标准输入与文件评测，操作见 [评测使用说明](评测使用说明.md)。
- 每题全部测试集中在 `评测/题库/题号.json`，设置和测试合并保存，保留充分的正常与边界数据。

## 题目分类与查找

- 统一采用“难度 / 知识点分类 / 题目文件”的三级结构。
- `基础题/输出与变量/`：第1、2题。
- `基础题/字符串处理/`：第3～5题。
- `基础题/数字与运算/`：第6、9、10、11题。

- `挑战题/字符串处理/`：第8题。
- 同一知识点分类在不同难度下使用相同目录名，后续按实际题目增加知识点目录。
- 跨知识点题目按主要训练主题归类；没有单一主要主题时放入相应难度的 `跨知识点综合/`，路线图保留其涉及部分的链接。
- 题号跨文件夹连续递增，文件名保持稳定；后续新题必须同时按难度和知识点归类。
- 路线图和教学规则保留在学习目录根部；以下题目链接均从此目录出发。
