## 一、核心知识点系统整合

### 1. 程序运行模型、IPO 分析与基本规范（课件 `lec2` /《从入门到实践》第 1～2 章）
- **IPO 分析法**：写代码前先拆清 **Input（输入什么）→ Process（怎么处理/算什么）→ Output（输出什么精确格式）**，防止漏掉单位、引号或空格。
- **解释型逐行执行**：Python 自上而下逐行执行。**重点机制**：如果先用变量 `old` 拼接并保存了旧文本，之后再重新给 `name` 赋值，`old` 里存好的旧字符串**不会自动跟着变化**（第 8 题核心原理）。
- **代码缩进与注释**：
  - 同一代码块行首缩进必须严格一致（PEP 8 推荐 **4 个空格**，勿混用 Tab 与空格），缩进错位直接触发 `IndentationError`；
  - 单行注释 `# ...` 用于解释“为什么这么写”；三引号字符串 `'''...'''` 或 `"""..."""` 可作多行说明（放在函数/类首行时为文档字符串 docstring）。
- **PEP 8 代码风格**：赋值号 `=` 与二元运算符左右各留 1 空格（`name = "Eason"`），函数参数逗号 `,` 后留 1 空格（`center(30, "-")`），冒号 `:` 前**不留空格**。

### 2. 变量、命名规范与“保留字 vs 内置函数”（课件 `lec2` /《基础教程》1.4）
- **变量本质与重赋值**：变量名是指向内存中对象的标签；用 `=` 赋值，重复赋值只是把标签改贴到新对象上。需要保留原值时（如原文本和清洗结果同时输出），不要覆盖原变量，另起新变量接收返回值。
- **命名语法规则**：只能含字母、数字、下划线 `_`，不能以数字开头，严格区分大小写（`name` 与 `Name` 不同）。习惯上普通变量全小写加下划线（`raw_text`），尽量避免 `Name` 这类首字母大写（通常留给类名）。
- **保留字（Keywords）vs 内置函数/类型名（Built-ins）**（高发考题）：

| 对比维度 | 保留字（关键字） | 内置函数 / 内置类型名 |
| --- | --- | --- |
| 常见成员 | `if`、`elif`、`else`、`for`、`while`、`in`、`is`、`def`、`return`、`import`、`True`、`False`、`None` 等 | `print`、`input`、`len`、`int`、`float`、`str`、`ord`、`chr`、`format`、`sum`、`eval` |
| 查询方式 | `import keyword; keyword.kwlist` 或 `help('keywords')` | 内置命名空间 `__builtins__` |
| 拿来当变量名后果 | **直接报 `SyntaxError` 语法错误** | 语法上能赋值，但**覆盖原功能**；后续调用报错（如 `TypeError: 'int' object is not callable`） |

### 3. `print()` 输出、引号、转义字符与 Unicode 编码（《笨办法》习题 6～10 / 课件 `lec3`）
- **`print()` 用法细节**：
  - `print(a, b)` 逗号隔开多个参数时默认用**单个空格**拼接并末尾换行（`sep=' ', end='\n'`）；
  - `print(x, end="")` 可取消自动换行（考场动态进度条与逐字符打印常用）；只写 `print()` 可单独输出一个空行。
- **引号搭配原则**：单引号 `'...'`、双引号 `"..."` 功能完全等价；三引号 `'''...'''` 支持直接换行写多行字符串。当字符串内容包含双引号时，可外单内双 `'He said "Hi"'`，或外双内转义 `"He said \"Hi\""`。
- **常用转义字符**（注意是反斜杠 `\`，不是 `/`）：
  - `\n`：换行；
  - `\t`：水平制表符（**占 1 个字符**，不是多个空格，评测严格区分 `\t` 与空格）；
  - `\r`：回车（将光标移回当前行首而不换行，课件中用于单行进度条刷新，如 `print("\r{:3}%".format(i), end="")`；注：某些简易 IDLE 会屏蔽 `\r` 退回效果，命令行终端/VS Code 终端可正常刷新）；
  - `\"` / `\'`：普通双引号 / 单引号；`\\`：输出单个反斜杠 `\`（例如 `'\\'` 长度只有 `1`）。
- **字符串运算符、长度与 Unicode 编码**：
  - 拼接 `s1 + s2`、重复 `s * 3`（课件例：`'-' * 20`）；
  - `len(s)`：统计字符总个数，1 个汉字、1 个空格、1 个 `\n` 或 `\t` 或 `\"` 都各计 **1 个字符**；
  - `ord(ch)`：返回**单个字符**的 Unicode 十进制编码（`ord('0') == 48`、`ord('A') == 65`、`ord('a') == 97`、`ord('数') == 25968`；传多字符报错）；
  - `chr(code)`：把整数编码还原为对应的**单个字符**（如凯撒偏移 `chr((ord(c) - ord('A') + 5) % 26 + ord('A'))`）。

### 4. 字符串索引、前后缀切片与常用不可变方法（课件 `lec2`/`lec3` +《快速上手》6.2 +《基础教程》1.10）
- **不可变性（核心特性）**：字符串一旦创建就不能原地修改内容。所有字符串方法（`.strip()`、`.upper()`、`.replace()` 等）**全都是返回处理后的新字符串副本**，不赋值接收就不会改变原变量。
- **正负索引与前后缀切片（考场高频！）**：
  - `s[0]` 取首字符，`s[-1]` 取末字符（注意用浮点数下标如 `'python'[1.5]` 报 **`TypeError`**）；
  - 1-based 第 `k` 个字符对应 `s[k - 1]`，索引前务必检查 `if not s or k < 1 or k > len(s):` 拦截空串、`k > len(s)`（`IndexError`）及 `k <= 0`（负索引回绕到末尾的静默错误）；
  - **紧贴单位的前后缀拆分**：`s[:-3]` / `s[-3:]` 拆 3 字符单位（`"RMB"`/`"CNY"`/`"EUR"`），`s[:-4]` / `s[-4:]` 拆 4 字符单位（`"Euro"`）。当单位长度不统一时，须先用 `s.endswith("Euro")` 或 `s.endswith(("RMB", "CNY", "EUR"))` 分支，不能写死同长度切片；
  - **切片越界与逆序规则**（课件 `basic-data-types.ipynb`）：切片下标超出长度**不会报错**；若起始位置在结束位置右侧（如 `"Programs"[6:3]`），返回空串 `""`；`s[::-1]` 可直接反转字符串；课件查表技巧如 `weekStr = "MONTUE..."`，`pos = (day - 1) * 3; weekStr[pos: pos + 3]`。
- **大小写、清理、统计与居中方法**：
  - 大小写：`.upper()` 全大写、`.lower()` 全小写、`.title()` 单词首字母大写；
  - 空白与字符集清理：
    - 无参 `.strip()` / `.lstrip()` / `.rstrip()`：清理两端 / 左端 / 右端全部空白字符（空格、`\t`、`\n` 等；一般优先用无参 `.rstrip()` 而非 `.rstrip(" ")`，防漏 `\t`）；
    - **带参 `.strip(chars)` / `.lstrip(chars)` / `.rstrip(chars)`**：把 `chars` 当**字符集合**而非完整子串，从端点逐字剥离直到遇到首个不在 `chars` 中的字符停下，**字符串内部不会被删**（如 `"= python= ".strip(" =np")` → `"pytho"`）。若合法末尾包含 `*` 等符号，须用单侧 `.rstrip().lstrip(" >*")`；
  - 统计与查找替换：`s.count(sub)` 统计互不重叠子串次数（如期中真题《棋子回位》）、`s.replace(old, new)` 替换、`s.center(width, fillchar)` 居中填充（奇数差额时左少 1、右多 1，超出宽度不截断）。

### 5. 字符串格式化全解：`f-string` 与 `str.format()`（课件 `lec3`《Format Specification Mini-Language》）
- **`f-string`**：`f"Name: {name}, Val: {val:.2f}"`；花括号内直接放变量或表达式；输出字面 `{` / `}` 需写 `{{` / `}}`。
- **`str.format()` 完整骨架**：`"{参数定位:格式说明}".format(...)`
  1. **冒号前（参数定位）**：
     - `{}`：省略编号，按出现顺序取 `.format()` 第 0、1、2… 个参数；
     - `{0}`、`{1}`：从 `0` 开始按位置取（只传 1 个参数却写 `{1}` 必报 **`IndexError`**）；
     - `{name}`：按关键字取；**混合传参时关键字参数必须放在位置参数之后**（否则 `SyntaxError`）。
  2. **冒号后（排版规格，`f-string` 与 `.format()` 完全通用）**：
     完整顺序：**`[填充字符][对齐 < > ^][符号 + - 空格][0][最小宽度][千分位 ,][.精度][类型]`**
     - **对齐与填充**：`<` 左对齐、`>` 右对齐、`^` 居中（**省略对齐时：字符串默认左对齐，数字默认右对齐**）。指定填充字符时必须紧跟在 `<`/`>`/`^` 前面；
     - **宽度不截断，但字符串 `.精度` 会截断（课件重点对比！）**：
       - `"{:>4}".format("Python")` → `"Python"`（宽度 4 小于长度 6，**不截断**）；
       - `"{:*^5.3}".format("caterpillar")` → `"*cat*"`（对字符串写 `.3` 精度会**先截断为前 3 个字符 `"cat"`**，再居中填充）；
     - **前导补零 `0` 与对齐陷阱**：`f"{5:02d}"` → `"05"`、`f"{-5:03d}"` → `"-05"`；注意不要写出 `"{:<05d}".format(12)`（左对齐配 `0` 会在右边补零变成 `"12000"`！）；
     - **类型符**：`d` 十进制、`b`/`o`/`x`/`X` 二/八/小十六/大十六进制、`c` Unicode 字符（`"{0:c}".format(65)` → `'A'`）、`f` 浮点、`e`/`E` 科学计数、`%` 百分比、`,` 千分位（`"{:,.2f}".format(12345.6789)` → `"12,345.68"`）；
     - **动态嵌套槽与复数精度（MOOC/第 25 题真题点）**：
       - `.format()` 与 `f-string` 都支持冒号后套 `{变量}` 动态指定填充符与宽度，如 `"{:{ch}^{w}}".format(val, ch=fill, w=width)` 与 `f"{pow(num, 0.5):{ch}>30.3f}"`（直接写 `:ch>` 漏掉 `{ch}` 会把 `'c'`/`'h'` 当格式符报 `ValueError`，且填充变量必须是单字符）；
       - 对复数 `complex` 用 `.3f` 会把**实部和虚部分别保留 3 位小数**，总宽按完整复数串对齐。

### 6. 本阶段衔接的输入拆分与真题写法识别
- 空白分隔推荐无参 `input().split()`（自动处理首尾空白、多空格和 `\t`），勿用 `.split(" ")`；考场逗号分隔用 `input().split(",")`。
- `eval(input())` 在 MOOC/题库常见，能解析数字/表达式但会把字符串当代码执行；作答仍以 `input()` + `int()`/`float()` + 切片为主。

## 二、个人高发易错点复盘与避坑对照

> 以下 6 类问题均来自 **第 1～15、25、27 题** 的实际作答复盘，重点以“错因 + 正误代码对照”帮你考前快速扫雷。

### 1. 拿内置类型/函数名当变量名（第 13、27 题）
- **实踩经过**：第 13 题写 `str = raw.strip(...)`、第 27 题在 `digit_sum` 里写 `sum = 0`；覆盖之后后面再调用 `str(456)` 或 `sum(ls)` 会直接报 `TypeError: 'str' object is not callable`。
- **避坑口诀**：命名避开所有 Python 颜色高亮词（`str`、`int`、`list`、`input`、`ord`、`format`、`sum`、`min`、`max`），改用 `cleaned`、`total`、`text` 等描述性名字。

### 2. `str.format()` 槽位索引、参数顺序与动态嵌套槽失误（第 14、25 题）
- **实踩经过**：第 14 题初版只传 1 个参数却写了 `{1:>6}` 触发 `IndexError`；第 25 题初版写 `:ch>30.3f` 漏写内层花括号，又写 `{c}^{w}}` 漏了开头的 `{:` 且少闭合右括号。
- **正误对照**：
  ```python
  # ❌ 报错写法
  "{1:>4}".format(x)              # IndexError: 只有位置 0
  "{name} {0}".format(name="Hi", "Ada")  # SyntaxError: 关键字不能在位置参数前
  f"{num:ch>30.3f}"               # ValueError: ch 未加花括号被当成格式码

  # ✅ 正确写法
  "{0:>4}".format(x)
  "{name} {0}".format("Ada", name="Hi")
  f"{num:{ch}>30.3f}"             # 嵌套变量必须套花括号 {ch}
  ```

### 3. 混用 `f-string` 与 `.format()` / 多余测试打印或引号（第 2、5、14 题）
- **实踩经过**：第 2 题保留了测试用 `str1`/`str2` 造成重复输出；第 5 题漏标签方括号；第 14 题初版多加了 `\"` 包住数字；同一串同时写 `f"..."` 与 `.format(...)` 会导致 `{0}` 先被 f-string 填成 `0`、后面的 `.format` 直接失效。

### 4. 单侧清理参数不通用 & 覆盖原值（第 5、15 题）
- **实踩经过**：第 15 题写了 `.rstrip(" ")` 只能删半角空格、遇到 `\t` 会漏删；且偶有 `raw = raw.strip(...)` 覆盖原文本风险。
- **正误对照**：
  ```python
  # ❌ 覆盖原串，且双向 strip 会误删末尾合法 "*"
  raw = raw.strip(" >*")
  # ✅ 保留原变量，无参 rstrip() 清理全部右空白再清左侧符号
  cleaned = raw.rstrip().lstrip(" >*")
  ```

### 5. 切片硬写固定长度 & 空串/负数下标边界（第 25、27 题）
- **实踩经过**：第 25 题初版只切 `[:-3]` 没区分 `"Euro"`（长 4）和 `"RMB"`（长 3），直接 `else:` 当作 `"CNY"`；第 27 题曾用 `s is None` 判空串，且当序号 `k <= 0` 时未拦截导致 `s[k - 1]` 变成负数下标静默绕到末尾比较 `s[-1] == s[-1]`。
- **避坑口诀**：空字符串判断写 `if not s:`；`1`-based 位置访问必须同时校验 `1 <= k <= len(s)`。

### 6. 格式微语言 4 个高频冷陷阱 & 编码规范
- **宽度不截断**：`"{:>4}".format("Python")` 仍输出完整 `"Python"`；只有加 `.精度`（如 `"{:.3}".format("caterpillar")` → `"cat"`）才会截断字符串。
- **数字补零用 `:05d` 或 `:0>5d`**：写 `"{:<05d}".format(12)` 会在右侧补零变成 `12000`。
- **转义长度计算**：`"A\t\"B\"\n\\C"` 长度为 `8`（每个转义字符 `\t`、`\"`、`\n`、`\\` 只占 1 个字符）。
- **代码风格**：变量名全小写加下划线、`=`/`==`/`,` 留规范空格、冒号前不留空格，并在提交前对照题目输出要求核对末尾 `#` 思考注释。
