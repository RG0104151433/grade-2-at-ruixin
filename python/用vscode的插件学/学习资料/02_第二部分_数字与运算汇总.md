## 一、核心知识点系统整合

### 1. 四类数值表示、多进制、E 记法与复数（课件 `lec3` /《从入门到实践》2.4）
- **整数 `int`（任意精度）**：Python 整数没有位数上限，算 `pow(2, 500)` 也不会像 C/Java 那样溢出。支持字面量下划线分隔（如 `1_000_000`）。
  - **四种进制字面量**（可直接混合做数学运算，例如 `0xFB + 0b10 == 253`）：
    - 十进制：`425`
    - 二进制 `0b`/`0B`：`0b110101001`；整数转二进制字符串用 `bin(n)`（返回如 `'0b1010'` 的 `str`）
    - 八进制 `0o`/`0O`：`0o651`；转字符串用 `oct(n)`（注：`0c` 不存在，写 `0c12` 直接报 `SyntaxError`）
    - 十六进制 `0x`/`0X`：`0x1a9`；转字符串用 `hex(n)`
- **浮点数 `float` 与科学计数法（E 记法）**：
  - 带小数点或用 `<a>e<b>` / `<a>E<b>`（表示 $a \times 10^b$）的字面量均为 `float`（例：`4.3e-3 == 0.0043`，`9.6E5 == 960000.0`）；`float("4.3e-3")` 可直接解析科学计数串。
- **复数 `complex`**：
  - 写作 `a + bj` 或 `complex(a, b)`（虚数单位是 **`j` 或 `J`**，不是 `i`；即使虚部系数为 1 也必须写 `1j`，不能单写 `j`）。
  - `z.real` 取实部，`z.imag` 取虚部，两者**永远是 `float`**。
- **混合运算类型拓宽规则**：按 **`int → float → complex`** 由窄到宽自动提升（如 `1 + 2.0` → `float`，`1 + 2.0 + (3 + 4j)` → `complex`）。
- **数字 vs 数字字符串**：`"12"` 不能直接减或乘方，先用 `int()` / `float()` 转换（注：`int(5.9)` 是**直接截断小数部分**得 `5`，不是四舍五入）。

### 2. 算术运算符、结合性、拆分公式与内置数值函数（《基础教程》1.3 /《往年题》`python.docx`）
- **三种除法对比（必考差异）**：
  - `/` 普通除法：结果**永远是 `float`**（即使整除，`10 / 2` 也得 `5.0`）；
  - `//` 整除（向负无穷方向取整商）：`17 // 5 == 3`、`-7 // 2 == -4`；
  - `%` 取余（模运算）：恒等式 `n == (n // m) * m + (n % m)`（$m \ne 0$）。
- **乘方 `**` 与右结合性（极高频易考！）**：
  - 同级加减乘除从左往右算，但 **`**` 是右结合（从右往左算）**：
    $$2 ** 3 ** 2 = 2 ** (3 ** 2) = 2 ** 9 = 512 \quad (\text{不是 } 64!)$$
    $$2 ** 3 ** 4 = 2 ** 81$$
  - 提示：`^` 在 Python 中不是乘方（是按位异或）。
- **复合赋值**：`+=`、`-=`、`*=`、`//=`、`%=` 会**原地修改原变量**；若需要保留初始输入（如总秒数 `total_seconds`），不要直接用 `%=` 覆盖它，用新变量接余数。
- **常用拆位与整数向上取整技巧**：
  - 三位数 `[0, 1000)` 十进制拆位：个位 `x % 10`、十位 `(x // 10) % 10`、百位 `x // 100`；
  - 多层时间换算：总天数 `total_min // 1440`，当天剩余分钟 `day_min = total_min % 1440`，小时 `day_min // 60`，分钟 `day_min % 60`；
  - **纯整数向上取整公式**（不靠 `if` 和 `math.ceil()`）：每箱装 `cap >= 1` 件、共 `items >= 0` 件时，最少箱数为 **`(items + cap - 1) // cap`**（`items == 0` 时结果为 `0`）。
- **考场高频内置数值函数**：
  - `abs(x)`：返回绝对值；做**同符号数学运算**（2026 春期中真题）时，先记 `a = abs(n)`，规定 `0` 的符号为正（`sign = 1 if n >= 0 else -1`），再把每项结果的绝对值乘回 `sign`（如 **`abs(a - 10) * sign`**，先取 `abs` 防 `a < 10` 时负负得正）；
  - `divmod(p, q)`：一次返回商和余数元组 `(p // q, p % q)`，用解包 `quo, rem = divmod(p, q)` 接收最简洁；
  - `pow(x, y)` vs **三参数 `pow(p, q, m)`**：两参返回 `x ** y`；三参数直接用“快速幂 + 边乘边取模”求 `(p ** q) % m`，在指数 `q` 很大时（如 $10^7$）不会构造极大整数，速度极快且不爆内存；
  - `max(x1, x2, ...)`、`min(x1, x2, ...)`、`sum(iterable)`。

### 3. 浮点误差、`Decimal`、`round()` 规则与 `math` 模块（课件 `lec3` +《往年题》）
- **浮点数二进制精度误差**：十进制 `0.1`、`0.2` 转二进制是无限循环小数，存在截断误差，因此 **`(0.1 + 0.2) == 0.3`** 与 **`(1.1 + 2.2) == 3.3`** 结果均为 **`False`**。
- **`decimal.Decimal` 高精度计算**：
  - 务必**传字符串**构造：`from decimal import Decimal; Decimal("0.1") + Decimal("0.2") == Decimal("0.3")`（`True`）。
  - **严禁写 `Decimal(0.1)` 或 `Decimal(float(x))`**：先变成 `float` 再传给 `Decimal`，会把二进制近似误差原封不动带进去。
- **`round(x[, d])` 银行家舍入（四舍六入五成双 / Round half to even）**：
  - 遇到恰好 `.5` 时向**最近的偶数**靠拢（正负数同理）：
    `round(0.5) == 0`、`round(-0.5) == 0`、`round(1.5) == 2`、`round(2.5) == 2`、`round(-3.5) == -4`、`round(-4.5) == -4`。
  - **计算原则**：中间步骤保留完整浮点精度，只在最终显示输出时再格式化舍入；注意 `round(7.0, 2)` 仍返回数值 `7.0`，想要补齐两位小数 `"7.00"` 必须用格式化 `:.2f`。
- **`math` 模块常用能力**：
  - 常数：`math.pi`（$\pi$）、`math.e`（$e$）、`math.inf`（正无穷）、`math.nan`；
  - 取整与幂根：`math.ceil(x)`（向上取整，如 `math.ceil(-2.3) == -2`）、`math.floor(x)`（向下取整，如 `math.floor(-2.3) == -3`）、`math.sqrt(x)`（开平方，**传入负数报 `ValueError`**，需负数开方改用 **`pow(x, 0.5)`** 自动转复数）、`math.pow(x, y)`（永远返回 `float`）、`math.fsum([...])`（精确浮点求和）、`math.hypot(x, y)`、`math.log(x[, base])`；
  - 三角函数与弧度转换：**`math.sin()`、`math.cos()` 接收弧度而非角度**！题目给角度 `deg` 时须先 `math.radians(deg)`（逆向用 `math.degrees(rad)`）；
  - **`NaN` 判断**：`NaN != NaN`，所以 `math.nan == math.nan` 与 `float('nan') == float('nan')` 都是 **`False`**，判空值 `NaN` 只能用 `math.isnan(x)`。

### 4. 数值输入、百分比与数字格式控制（课件 `lec3` /《从入门到实践》）
- **输入转换**：空白分隔用 `input().split()`（勿用 `.split(" ")`），考场逗号分隔用 `input().split(",")`。根据题意选 `int()` / `float()`；若需拦截 `"10**2"` 等非纯数字表达式而不用 `eval()`，按 `int()` → `float()` → `complex()` 级联 `try/except ValueError`。
- **百分比与 `-0.00` 边界**：减免 `20`（表示 `20%`）须先 `/ 100`；浮点运算得到 `-0.0` 时 `f"{-0.0:.2f}"` 会打印出 `"-0.00"`，可用 `if ans == 0: ans = 0.0` 清洗。
- **数字格式控制速查（`{值:[填充][对齐][符号][0][宽度][,][.精度][类型]}`）**：
  - `{n:02d}` / `{-5:03d}`：`05` / `-05`（负号占 1 格）；最小宽度不够时**不截断**；
  - `{x:.2f}` / `{x:8.3f}`：`{:.2f}` 补齐两位小数；`"{:8.3f}".format(12.2346)` → `"  12.235"`（总宽 8 格含小数点）；
  - `{x:.2e}`（科学计数如 `4.30e-02`）、`{n:,}`（千分位如 `1,000,000`）、`{p:.1%}`（百分比如 `12.5%`）、`{z:+>30.3f}`（复数同时格式化实部与虚部各 3 位小数）。

### 2.1 个人真实踩坑复盘（第 6、9～12、16～18、26 题）

1. **核心数学概念曾出现误判**（第 17 题误把 `2 ** 3 ** 2` 算成从左到右的 `128`，且不清楚 `round()` 银行家舍入；第 16 题对 `Decimal(float(x))` 只答到字符串类型转换，未点明 `float` 提前引入二进制误差；第 26 题初时不清楚三参数 `pow(p, q, 1000)` 快速幂取模优势）→ `[→ 练题 A1、A2、A5]`。
2. **公式/百分比换算与符号反转边界**（第 12 题初版忘了对折扣率 `/ 100`；第 16 题初版把 `r` 误写成 `n` 触发 `OverflowError` 且第二个项忘了改减号；同符号/角度问题易漏 `abs` 与 `math.radians`）→ `[→ 练题 B1、B3、B4]`。
3. **数值类型选用不严谨**（第 11 题沿用 `eval(input())`；第 12 题初版全转 `float()`；第 18 题把整数倍数 `k` 转成 `float(K)` 使 `complex + int` 拓宽演练失真）→ `[→ 练题 B1]`。
4. **原地修改覆盖原值 vs 漏存指定变量**（第 6 题没把找零存进 `change`；第 9 题用 `total_seconds %= 3600` 破坏了原始 `total_seconds`）→ `[→ 练题 B2]`。
5. **同一表达式或转换反复调用**（第 16 题 `int(n)` 算 3 遍；第 17 题向上取整公式算 2 遍；第 26 题把 `divmod(p, q)` 调两遍分别取 `[0]`/`[1]`、把 `abs(n)` 算 4 遍、把 `pow(delta, 0.5)` 算 2 遍）→ 先存变量再复用。
6. **变量命名风格**（`Items, Box_cap`、`Deg, P, Q` 等临时变量习惯首字母大写）→ 统一小写加下划线更规范。
