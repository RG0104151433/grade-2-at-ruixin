## 一、核心知识点系统整合

### 1. `for` 循环与 `range()` 完整解析（课件 `lec4` /《从入门到实践》第 4 章 /《基础教程》5.5.2）

- **`for` 遍历通用语法**：`for 变量 in 可迭代对象:` —— Python 中可迭代对象包括字符串 `str`、列表 `list`、元组 `tuple`、`range()`、字典 `dict`、集合 `set`、打开的文件对象等。
- **`range(start=0, stop, step=1)` 完整规则**：
  - 三种传参形式：
    1. `range(stop)`：从 `0` 到 `stop - 1`（共 `stop` 次，如 `range(5)` → `0, 1, 2, 3, 4`）；
    2. `range(start, stop)`：左闭右开 `[start, stop)`，步长 `1`；
    3. `range(start, stop, step)`：以 `step` 为公差生成整数序列（`step` 可负，但不能为 `0`，否则报 `ValueError`）。
  - **关键限制**：**参数必须全是整数 `int`**，传入浮点数会直接报 **`TypeError: 'float' object cannot be interpreted as an integer`**。
  - **倒序边界公式**：因不包含 `stop`，若要从 `b` 按步长 `-step` 倒序走到且**包含** `a`，写法是 `range(b, a - 1, -step)`；若要包含 `0`，需写 `range(b, -1, -1)`。
  - **空区间安全**：如 `range(5, 2)` 或 `range(1, 5, -1)` 不会报错，只是 0 次循环（一次都不执行）。
- **高频算例模式**：
  - **交错级数**：用 `(-1) ** k` 或标志 `sign = 1; sign = -sign` 交替变号累加（如莱布尼茨级数 $4 \times \sum_{k=0}^{n-1} \frac{(-1)^k}{2k+1}$）。
  - **连续区间定积分近似（第 28 题考点）**：`range` 不能用小数步长，必须先算每段宽 $dx = \frac{b - a}{n}$，再用 `for i in range(n):` 遍历整数段号，由 $x = a + i \cdot dx$ 计算采样点高度。
  - **行内打印序列**：`print(*ls)`（解包成多个参数，默认单空格隔开、末尾无多余空格）。

### 2. `while` 循环、不定行读入与迭代推进（课件 `lec4` /《从入门到实践》第 7 章 /《基础教程》5.5.1）

- **标准语法与防死循环（`TLE`）**：
  - `while 条件:` 当条件为真时反复执行；循环体内**必须有变量向结束方向推进**（或有明确 `break`），否则无限运行在评测中触发 **`TLE`**（超时）。
- **三种考场读入场景区分（务必对号入座，勿混用！）**：

| 输入场景 | 典型特征 | 标准读入骨架 | 易错对比 |
| --- | --- | --- | --- |
| **场景 1：未知行数、空回车结束**（第 29 题、第 32 题第 1 段） | 不给行数 `n`，末尾给 1 个空行 | `while True:`<br>`    line = input().strip()`<br>`    if not line: break` | 不能先 `int(input())`（空行 `ValueError`），也不能只写 `if not val:`（会误杀合法整数 `0`） |
| **场景 2：已给明确行数 `r`**（第 32 题第 2 段矩阵） | 先读 `r`，再读 `r` 行，**末尾无空行** | `for i in range(r):`<br>`    row = [int(x) for x in input().split()]` | 此时千万不能用 `while True:` 等空行，否则读到输入尽头报 **`EOFError`** |
| **场景 3：单行空格列表（可能为空行 `[]`）**（第 33 题） | 严格固定 3 行，某行可能是 `""` | `nums = [int(x) for x in input().split()]` | 对空串 `"".split()` 安全返回 `[]`；切忌 `sys.stdin.read().split()` 吞掉空行导致错行 |

### 3. `break`、`continue` 与 `for / else`、`while / else`（课件 `lec4` 重点）

- **`break` vs `continue`**：
  - `continue`：**跳过本轮剩余代码**，直接进入下一次循环判断；
  - `break`：**立刻彻底终止当前所在的最内层循环**。
  - ⚠️ **嵌套循环规则**：内层循环触发 `break`，**只会跳出内层，不会跳出外层**；若需“找到后连外层一起跳出”，应设布尔标志 `found = True` 并在外层 `if found: break`。
- **`for / else` 与 `while / else`（高频必考，第 28、33 题）**：
  - **唯一触发条件**：当循环**自然跑完**（`for` 遍历完所有元素 / `while` 条件变为 `False`），且**途中一次也没有因为该循环本身的 `break` 而退出**时，执行 `else:` 块。
  - **关键辨析**：只要当前循环触发了 `break`，就跳过对应的 `else:`；如果嵌套中只有**内层**循环触发 `break`、而**外层**自己没触发 `break`，外层对应的 `else:` **仍会执行**！
  - **典型用途**：素数判定（试除全不整除进 `else: return True`）、`TwoSum` / 搜索无解兜底（全搜完没 `break` 进 `else: print(-1)`）。

### 4. 列表基础：创建、索引、切片、切片赋值与 `del`（课件 `lec6` /《从入门到实践》第 3 章 /《基础教程》2.3）

- **创建**：
  - `[]` 创建空列表；
  - `list(iterable=())`：无参得 `[]`；传一个可迭代对象会**逐个拆元素**放入新列表，如 `list("BIT") -> ['B', 'I', 'T']`、`list(range(3)) -> [0, 1, 2]`（传整数 `list(123)` 报 `TypeError`）。
- **索引与修改**：正索引 `0 ~ len-1`、负索引 `-len ~ -1`（`-1` 为末位），越界报 `IndexError`；列表**可变**，可直接 `ls[i] = val` 修改。
- **切片 `ls[start:stop:step]`**：
  - 默认 `start` 为开头、`stop` 为末尾、`step=1`；切片越界不报错，返回**新列表对象**。
  - `ls[:]` 生成全量**浅拷贝**副本；`ls[::-1]` 生成反转后的**新列表**（不改原 `ls`）。
- **切片赋值与 `del`（原地修改，无返回值）**：
  - **连续区间替换 `ls[i:j] = iterable`**：将 `[i, j)` 原地替换，**左右长度可不等**！
    - 扩张替换：`s = [0, 1, 2, 3]; s[1:3] = [99, 88, 77]` → `[0, 99, 88, 77, 3]`；
    - 区间插入：`s[1:1] = [8, 9]`；区间删除：`s[1:3] = []`。
  - **带步长赋值 `ls[i:j:k] = iterable`（`k != 1`）**：右侧元素个数**必须严格等于**被选中位置数，否则报 `ValueError`。
  - **`del` 语句**：`del ls[i]` 删单位置；`del ls[i:j]` 删连续段；`del ls[::2]` 删偶数下标离散位（`0, 2, 4...`）。

### 5. 列表常用方法与聚合函数全速查（课件 `lec6` / `往年题/python.docx` 6.3～6.4）

> [!IMPORTANT]
> **核心铁律**：除 `pop()`、`count()`、`index()`、`copy()` 外，下表中所有修改类方法均**原地修改原列表**、**返回值为 `None`**！绝不能写成 `ls = ls.append(x)`、`ls = ls.reverse()` 或 `ls = ls.sort()`，否则变量立刻变成 `None`，后续调用方法直接报 `AttributeError`。

| 方法 / 函数 | 完整参数与默认值 | 作用与返回值 | 关键细节与常见报错 |
| --- | --- | --- | --- |
| `ls.append(x)` | 任意单个对象 `x` | 把 `x` **整体当作 1 个元素**追加到末尾；返回 `None` | 若 `x` 是 `[3, 4]` 会嵌套进去，列表长度仅加 `1` |
| `ls.extend(iterable)` | 可迭代对象 `iterable` | 把 `iterable` 中元素**逐个拆开**追加到末尾；返回 `None` | `[1, 2].extend([3, 4])` 得 `[1, 2, 3, 4]`；传整数报 `TypeError` |
| `ls.insert(index, x)` | 整数下标 `index`、元素 `x` | 在下标 `index` 前插入 `x`（后续右移）；返回 `None` | 超出右端插到末尾，小于 `-len` 插到开头 `0` |
| `ls.pop(index=-1)` | 可选下标 `index`（默认 `-1`） | 删除并返回下标 `index` 处元素（**有返回值**） | 空表或下标越界报 **`IndexError`** |
| `ls.remove(value)` | 目标值 `value` | 从左往右删**第一个**等于 `value` 的元素；返回 `None` | 值不存在报 **`ValueError`**，建议先 `if value in ls:` |
| `ls.reverse()` | 无参数 | **原地**前后颠倒列表；返回 `None` | 想保原表时改用 `ls[::-1]` |
| `ls.clear()` | 无参数 | 清空列表变为 `[]`；返回 `None` | 与 `del ls`（删除变量名）不同 |
| `ls.copy()` | 无参数 | 返回浅拷贝**新列表** | 等价于 `ls[:]`、`list(ls)` |
| `ls.count(value)` | 目标值 `value` | 返回 `value` 出现次数（整数） | 不存在返回 `0` |
| `ls.index(value, start=0, stop=...)` | 值与可选 `[start, stop)` | 返回首次出现下标 | 找不到报 **`ValueError`** |
| `sum(iterable, start=0)` | 数值序列与可选初值 `start` | 返回累加总和 | 空列表返回 `0`（即 `start`）；元素须可相加 |
| `min / max(iterable, *, key=None, default=...)` | 序列或直传多参 | 返回最小/最大值（`key` 同排序用法） | **空序列不传 `default=` 会报 `ValueError`**，须先 `if ls:` |

### 6. 列表推导式、`enumerate()`、`zip()` 与函数签名 `/`、`*`（《从入门到实践》第 4 章 /《基础教程》5.5.4）

- **列表推导式（比“空表 + `for` + `append`”更紧凑，返回新列表）**：
  - 映射转换：`nums = [int(x) for x in input().split()]`
  - 带筛选：`evens = [x for x in nums if x >= 0 and x % 2 == 0]`
  - 安全建二维：`mat = [[0] * cols for _ in range(rows)]`
- **`enumerate(iterable, start=0)`**：
  - 每次产出 `(序号, 元素)` 二元组；排名编号常用 `start=1`，配合拆包：`for idx, val in enumerate(ls, start=1):`（若元素本身也是二元组则可两层拆包 `for idx, (name, score) in enumerate(ranked, start=1):`）。
- **`zip(*iterables, strict=False)`**：
  - 按位置把多个序列第 `k` 项打包成元组；默认按**最短**序列截断（Python 3.10+ 设 `strict=True` 则不等长报 `ValueError`）。
  - ⚠️ `enumerate` 与 `zip` 返回的是**惰性迭代器**：只能消耗一轮，且**没有 `.sort()` 方法**，排序须传给 `sorted(zip(...))` 或先 `list(zip(...))`。
- **看懂函数签名中的 `/` 和 `*`（重要通用阅读技能）**：
  - **独立的 `/`**：左边参数**只能按位置传**（不能写 `iterable=ls`），调用时不输入 `/`；
  - **独立的 `*`**：右边参数**必须写关键字 `参数名=值`**（如 `key=...`、`reverse=...`、`strict=...`），不能省略参数名按位置塞；调用时不输入 `*`；
  - **贴在参数名前 `*iterables`**：接收任意多个位置参数（调用时按逗号传即可）；它后面的具名参数同样强制用关键字。

### 7. 排序双剑客 `list.sort()` vs `sorted()` 与多关键字排序（课件 `lec6` / 期中第 9 题）

- **`ls.sort(*, key=None, reverse=False)`**：列表专属方法，**原地修改** `ls`，返回 `None`。
- **`sorted(iterable, /, *, key=None, reverse=False)`**：通用内置函数，不改原对象，返回**排好序的新列表**。
- **`key` 参数与多关键字用法**：
  - `key=` 传入一个**单参数函数本身（不要加括号）**，排序时按 `key(元素)` 的返回值比较（**原元素值本身不会被改写**）：
    - 内置函数直传：`sorted(nums, key=abs)`、`max(words, key=len)`；
    - 匿名函数 `lambda` 单条件：`sorted(pairs, key=lambda item: item[1])`；
    - **多关键字元组法**：`lambda` 返回 `(第一关键字, 第二关键字)`。当不同关键字升降序方向相反时，数值字段可**取负号**：
      - 绝对值升序、同绝对值按原值降序：`sorted(nums, key=lambda x: (abs(x), -x))`
      - 分数降序、同分按姓名升序：`sorted(zip(names, scores), key=lambda s: (-s[1], s[0]))`
  - **稳定性**：`key` 完全相等的元素，排序后维持原有相对先后次序。

### 8. 二维列表与四大高发内存/遍历陷阱（课件 `lec6` /《从入门到实践》第 3～4 章）

1. **二维列表初始化与副本隔离（重点）**：
   - 正确方式 ①（逐行 `append` 读入）：`grid = []; for _ in range(r): grid.append([int(x) for x in input().split()])`
   - 正确方式 ②（推导式建全 `0` 规则矩阵）：`mat = [[0] * c for _ in range(r)]`（每轮创建独立子列表；注意内层 `* c` 仅限不可变初值）。
   - 正确方式 ③（独立深复制二维数字矩阵）：`dup = [row[:] for row in grid]`。
   - ❌ **致命大坑 `[[0] * c] * r`**：外层 `* r` 只复制了**同一个内层列表的引用**（`mat[0] is mat[1]` 为 `True`），修改 `mat[0][0]` 会让所有行第 0 列一起变！
   - 按列求极值：固定列号 `j`、内层遍历行号 `i`，且**初值务必取 `grid[0][j]`**（切勿取 `0`，否则全负数列会错输出 `0`）。
2. **`lt = ls` 引用别名陷阱**：`lt = ls` 只是给同一块内存起别名，修改或 `.sort()` 会连原表一起改坏；一维保护原表需用 `ls.copy()`、`ls[:]` 或 `list(ls)`。
3. **遍历时原地 `remove()` 漏删**：`for x in a: if x == 2: a.remove(x)` 删掉前项后右侧元素左移，循环指针却继续右移一格，导致紧邻的下一个 `2` 被跳过！应改用推导式 `[x for x in a if x != 2]` 重建或遍历 `a[:]`。
4. **统计中位数与函数无副作用**：在函数内求中位数务必用 `sorted(nums)`（且**接住返回值**）而非 `nums.sort()`，避免改坏调用方列表；索引下标须用整除 `// 2`，偶长度两数求平均的最外层仍用真除 `/ 2`。

### 9. `random` 模块与 `turtle` 迭代绘图（课件 `lec2` / `lec4`）

| `random` 函数 | 区间 / 行为 | 说明与典型场景 |
| --- | --- | --- |
| `random.seed(a=None)` | 初始化随机数生成器 | 传入固定整数后，后续生成的随机序列完全可复现（评测必考） |
| `random.random()` | `[0.0, 1.0)` 随机小数 | 基础概率与蒙特卡洛模拟（如 `lec4` 撒点算 $\pi$） |
| `random.randint(a, b)` | **`[a, b]` 闭区间**整数（含 `b`） | 投骰子、概率分档（`randint(1, 5)`）、字符编码抽样 `chr(randint(ord('A'), ord('Z')))` |
| `random.randrange(start, stop, step=1)` | **`[start, stop)` 半开**（不含 `stop`） | 按步长抽整数，如 `randrange(10, 100, 5)` 抽两位数中的 5 的倍数 |
| `random.uniform(a, b)` | `[a, b]` 随机小数 | 指定区间连续小数抽样 |
| `random.choice(seq)` | 从非空序列随机选 1 项 | 随机抽单词/奖品（空序列报 `IndexError`） |
| `random.shuffle(x)` | **原地打乱列表 `x`，返回 `None`** | 不可对字符串/元组使用，也不可写 `ls = random.shuffle(ls)` |

- ⚠️ **固定种子排错**：`random.seed(s)` 只能调一次（放在循环外）；多调、少调一次或调换 `randint`/`randrange` 顺序都会改变后续整个随机序列。
- **选做拓展（`turtle` 迭代绘图，课件 `lec2`/`lec4`）**：`for _ in range(n): turtle.fd(L); turtle.left(360 / n)` 绘制正多边形或递增边长螺旋，不纳入标准输入自动评测。

## 二、个人高发易错点复盘与避坑对照

> 以下 6 类问题全部来自你在 **第 28～33 题** 实际编写和调试时真实踩过的坑，复习或考前速查时直接按“错在哪 → 怎么改”对照即可。

### 1. 真除法 `/` 与整除 `//` 混用（第 32 题）
- **实踩经过**：算中位数下标时写了 `tmp[(len(nums) - 1) / 2]`，触发 `TypeError: list indices must be integers or slices, not float`；改成 `//` 后，又顺手把偶长度求两数均值最外层的 `/ 2` 也改成了 `// 2`，导致 `4.50` 被截断成 `4.00`。
- **正误对照**：
  ```python
  # ❌ 下标用了 /，或者求均值用了 //
  med = (tmp[n / 2 - 1] + tmp[n / 2]) // 2

  # ✅ 口诀：方括号里面用 // 算整数下标，外面求平均值仍用 /
  med = (tmp[n // 2 - 1] + tmp[n // 2]) / 2
  ```

### 2. 函数调用符号、内置名冲突与接口返回值（第 31、32 题）
- **实踩经过**：第 31 题出现 `int[i]` 方括号调函数、`abs` 漏传参数 `(abs, -x)`、未初始化局部变量 `sum` 就写 `sum += i`；第 32 题 `calc_stats` 返回列表 `[avg, std, med]` 而非约定的三元组 `(avg, std, med)`。
- **正误对照**：
  ```python
  # ❌ 常见笔误与冲突
  score = [int[i] for i in input().split()]
  nums = sorted(ori, key=lambda x: (abs, -x))
  sum += i  # sum 未初始化且与内置 sum() 重名

  # ✅ 规范写法
  score = [int(i) for i in input().split()]
  nums = sorted(ori, key=lambda x: (abs(x), -x))
  return avg, std, med  # 返回三元组而非列表
  ```

### 3. “空行结束读入” vs “已知行数读入”与类型转换（第 29、32 题）
- **实踩经过**：第 29 题初稿直接 `int(input())` 遇空行报 `ValueError` 且 `if not cur:` 误伤合法 `0`；第 32 题第 1 段多行输入初稿用了单行 `.split()`，而第 2 段已给矩阵行数 `r` 且末尾无空行却继续套用 `while True:` 导致 `EOFError`（且 `r, c` 曾漏转 `int`）。
- **正误对照**：

### 6. 题目约束、嵌套 `else` 理解与版本兼容（第 28、29、31 题）
- **实踩经过**：第 28、29 题禁用列表约束下仍使用了列表、`is_prime` 未采用 `for / else`；第 29 题写了仅 Python 3.12+ 才合法的同引号嵌套 `f"{"".join(...)}"`；第 31 题 `print(a, ' | ', *b)` 在 `' | '` 两端多打空格引起格式多空格。
- **避坑口诀**：
  - 嵌套循环中 `break` **只跳最内层**，外层只要自己没触发 `break`，外层的 `else:` 依然执行；
  - `print(a, '|', *b)` 用逗号传参已自带单空格，分隔符前后**勿再额外加空格**；
  - f-string 内层与外层尽量使用**不同引号**（如 `f"{''.join(...)}"`），保证 Python 3.8～3.14 全版本通用。
