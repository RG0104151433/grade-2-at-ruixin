# Python 学习路线图

## 学习与出题约定

- 每部分按“基础练习 → 阶段综合题 → 阶段挑战题”推进，至少有一道综合题和一道有难度的挑战题。
- 综合题至少结合三个已学知识点；后续持续加入跨部分综合练习。
- 挑战题侧重独立拆解、边界情况、规律分析或调试。需要的新语法先讲解再使用。
- 参考仓库中的 `资料/往年题/`、`资料/老师的课件/` 与 `资料/电子书/`；实际查阅后注明出处，区分原题、改编题与自编题。
- **期末考场导向风格**：题干精炼短小，减少冗长业务文案，强化数学/字符串/逻辑/数据结构紧凑拆解；混合采用“从零编写”与考场高频“给定函数模板补全”题型；输入兼容逗号分隔、紧贴单位前后缀、空回车终止与严格末尾分隔输出。
- 每次新建题目，必须在本次回复前把有效的相对文件链接加入对应部分，并标明题型和检查状态。
- 检查后更新状态：完全通过、核心已掌握（注明差异）、待修改、待检查。
- 知识点已覆盖、综合题和挑战题均完成检查，才算完成一个部分。用户调整学习顺序时记录尚待补充的内容。
- 检查先关注思路、知识点和结果，再反馈边界、输出格式和风格；严格格式要求在出题时提前说明。
- 先给分层提示，用户要求完整答案时再提供解答。
- 本路线图聚焦知识点、训练覆盖范围与题目规划索引；动态学习进度、每题检查详情与待办事项已独立维护在 [当前进度](当前进度.md)，具体题目和说明放在对应文件。
- 出题与补充讲解兼顾“课程课件（`资料/老师的课件/`）”、“往年真题库（`资料/往年题/`）”与“参考课本”：标明哪些属于课堂与期末必考核心，哪些属于工程拓展进阶。
- 除编程实现题外，每个阶段适当穿插“概念辨析 / 输出预测 / 代码改错”训练，覆盖课件中的典型易错点。
- 第10题起采用标准输入与文件评测，操作见 [评测使用说明](评测使用说明.md)；后续涉及文件读写、函数/类接口或图形库（如 `turtle`）的题目，可采用脚本断言检查或人工运行核验。
- 每题全部测试集中在 `评测/题库/题号.json`，设置和测试合并保存，保留充分的正常与边界数据。

## 一、输出、变量与字符串基础

### 已学小结

- 输出与换行、变量赋值与重新赋值、执行顺序。
- 字符串拼接、f 字符串与变量插值。
- 首尾空白清理、大小写转换与连续方法调用。
- 原始资料、中间结果、多行字符串与旧结果保留。
- 通用处理与替换数据验证；代码注释的初步使用。
- 阶段汇总与易错自测：[第一部分学习资料](学习资料/01_第一部分_输出变量与字符串基础汇总.md) ｜ [第一部分易错专练](易错专练/01_第一部分_易错专练.md)。

### 知识点

- 程序分析基本思路：**IPO（Input-Process-Output）** 与编程基本步骤（定义问题、分析、设计、编码、调试、维护）。
- `print()`、执行顺序、默认换行；解释型语言逐行执行特点。
- 变量创建、赋值、重新赋值与 PEP 8 命名规范；**保留字（`keyword.kwlist`）与内置函数（如 `print`、`input`、`eval`）的区别**及大小写敏感。
- 字符串、单引号、双引号、多行字符串/多行注释（`'''...'''`）、单行注释 `#` 与基本代码风格、缩进规则（`IndentationError`）。
- f 字符串、`str.format()` 基本规则与变量插值：`{参数定位:格式说明}` 结构（省略编号 `{}` 按顺序取值、从 `0` 开始的位置索引 `{0}`/`{1}` 不可越界、`{name}` 关键字参数），冒号后 `[填充字符][对齐 < > ^][最小宽度]`（省略时字符串默认左对齐、数字默认右对齐；超出最小宽度不截断）及基础小数格式 `{:.2f}`。
- `\n`、`\t`、`\r`（回车与单行刷新）、引号与反斜杠转义。
- `strip()`、`lstrip()`、`rstrip()` 与首尾空白，以及 `strip(chars)` 指定字符集合清理。
- `upper()`、`lower()`、`title()`、`center()` 与大小写转换/居中填充。
- 方法调用、返回值保存、处理前后的变量值；Unicode 编码基础（`ord()`、`chr()`）与字符长度 `len()`。

## 二、数字与运算

### 知识点

- 整数（任意精度）、浮点数、复数（`complex`、`.real`/`.imag`）、数字与数字字符串的区别。
- 整数多进制字面量（`0b`、`0o`、`0x`）与转换函数（`hex()`、`oct()`）；浮点数科学计数法（E 记法如 `4.3e-3`）。
- `+`、`-`、`*`、`/` 与除法结果；跨数值类型混合运算的类型拓宽规则（`int → float → complex`）。
- 整除 `//`、取余 `%`、乘方 `**` 与 `pow()`；恒等式 `n == (n // m) * m + (n % m)`。
- 运算优先级、右结合乘方（如 `2 ** 3 ** 4`）、括号与中间结果。
- `+=`、`-=` 等复合赋值。
- 浮点数二进制表示误差（如 `1.1 + 2.2 != 3.3`）、`round()` 的偶数舍入（银行家舍入）、`decimal.Decimal` 高精度思路与 f 字符串/`format()` 的小数格式。
- `math` 模块常用能力（`math.sqrt`、`math.pi`、`math.pow`、`math.isnan()` 与 `NaN != NaN` 特性）。
