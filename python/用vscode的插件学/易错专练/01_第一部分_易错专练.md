## 题型 A：概念辨析与输出预测

**A1.** 下面三段代码分别输出什么，或者报什么错？
```python
# 代码 1
str = "123"
print(str + "4")
print(str(456))

# 代码 2
x = "AB"
print("{1:>4}".format(x))

# 代码 3
print("{name} {0}".format(name="Hi", "Ada"))
```

**A2.** 下面代码输出什么？（辨析 `strip(chars)` 字符集合语义）
```python
s = "**==hello*world==**"
print(s.strip("*=h"))
```

**A3.** 写出下面每行 `format` 的精确输出（注意默认对齐、宽度不截断、字符串 `.精度` 截断与 `<0` 陷阱）：
```python
print("[{:>4}]".format("Python"))
print("[{:4}|{:4}]".format("A", 5))
print("[{:*^7}]".format("HI"))
print("[{:*^5.3}]".format("caterpillar"))
print("[{:<05d}]".format(12))
```

**A4.** 下面两行分别输出什么？`len(msg)` 等于多少？
```python
msg = "A\t\"B\"\n\\C"
print(len(msg))
print(msg)
```

**A5.**（考场切片与动态槽格式化）下面代码每行分别输出什么？
```python
m = "12.5Euro"
print(m[:-4], "|", m[-4:], "|", m[6:3])
print("{:{ch}^{w}}".format(-64, ch="*", w=8))
print(f"{pow(-9, 0.5):+>18.2f}")
```

## 题型 B：代码找茬与改错

**B1.（目标：输入字符 `a`，输出 `Code: 97`、下一字符 `b` 以及 `[a   |  97]`）**
```python
input = input()
ord = ord(input)
next = chr(ord + 1)
print(f"Code: \"{ord}\"\nNext: {next}\n[{0:<4}|{1:>4}]".format(input, ord))
```

**B2.（目标：对 `"  >>*run*  "` 清理左侧空格/`>`/`*` 和右侧所有空白得 `"run*"`，同时保留原值输出 `"[  >>*run*  ] -> [run*]"`）**
```python
raw = "  >>*run*  "
raw = raw.strip(" >*")
print(f"[{raw}] -> [{raw}]")
```

**B3.（目标：输入整数 `a = -4` 与填充符 `ch = "*"`、宽度 `w = 10`，第 1 行输出用 `ch` 左补至 30 宽的复数开方，第 2 行用 `.format()` 输出居中占 `w` 格的 `a ** 3`）**
```python
a = -4
ch = "*"
w = 10
print(f"{pow(a, 0.5):ch>30.3f}")
print("{c}^{w}}".format(a ** 3, c=ch, w=w)
```

**B4.（目标：若金额末尾是 `"Euro"` 或 `"RMB"` 提取数值；第 2 段比较 `s2` 第 `k` 位（1 起算）与末字符，位置非法输出 `ERROR`）**
```python
s1 = input().strip()
num = float(s1[:-3])   # 输入可能为 "10Euro" 或 "10RMB"

s2, k = input().split(",")
k = int(k)
if s2[k - 1] == s2[-1]:
    print("True")
else:
    print("ERROR")
```

## 题型 C：快速概念问答

### 题型 A 答案与解析
- **A1**：
  - 代码 1：第 2 行输出 `1234`，第 3 行报 **`TypeError: 'str' object is not callable`**（覆盖了内置类型 `str()`）。
  - 代码 2：报 **`IndexError: Replacement index 1 out of range`**（只传 1 个参数，索引只有 `0`）。
  - 代码 3：报 **`SyntaxError: positional argument follows keyword argument`**（混合传参时关键字参数必须在位置参数后面，应改为 `.format("Ada", name="Hi")` 并将串改 `{name} {0}`）。
- **A2**：输出 **`ello*world`**（`strip` 按字符集从两端剥离，内部 `*` 不删）。
- **A3**：
  - `[Python]`（最小宽度 `4` 小于长度 `6`，不截断）
  - `[A   |   5]`（字符串默认左对齐、数字默认右对齐）
  - `[**HI***]`（居中补 5 个 `*`，左少 1 右多 1）
  - `[*cat*]`（字符串指定 `.3` 精度会**截断**成 `"cat"` 再占 5 格居中填充）
  - `[12000]`（`<` 左对齐配合 `0` 会在右侧补零，数字补零请直接用 `:05d` 或 `:0>5d`！）
- **A4**：`len(msg)` 为 **`8`**（`'A'`、`'\t'`、`'"'`、`'B'`、`'"'`、`'\n'`、`'\\'`、`'C'` 各占 1 字符）；输出两行：`A	"B"` 与 `\C`。
- **A5**：
  - `12.5 | Euro | `（`m[6:3]` 起点在终点右边，返回空串 `""`）
  - `**-64***`
  - `++++++++0.00+3.00j`（实部虚部共 10 字符，左补 8 个 `+` 达 18 宽）

### 题型 B 答案与解析
- **B1**（共 4 处错）：`input`/`ord` 覆盖内置函数名；输出多加了 `\"`；`f"..."` 里混用 `.format(...)` 导致 `{0:<4}` 先被 f-string 算出 `0   `，`.format` 失效！改用新变量名 `ch`/`code` 且只用一种格式化方式即可。
- **B2**（共 2 处错）：覆盖了原变量 `raw` 丢失原值；双向 `.strip(" >*")` 把合法末尾 `*` 误删。应保留 `raw` 并用 `cleaned = raw.rstrip().lstrip(" >*")`。
- **B3**（共 3 处错）：第 1 句 `:ch>30.3f` 漏了内层花括号，应写 `:{ch}>30.3f`；第 2 句 `"{c}^{w}}"` 少了开头 `{:`（应为 `"{:{c}^{w}}"`），且末尾缺闭合右括号 `)`。
- **B4**（共 2 处错）：`"Euro"` 长 4，写死 `s1[:-3]` 会切成 `"10E"` 报 `ValueError`，应区分 `.endswith("Euro")` 切 `[:-4]`；索引前未检查 `if not s2 or k < 1 or k > len(s2):`，导致 `k = 0` 悄悄变成 `s2[-1] == s2[-1]` 输出 `True`，且不等时漏了 `False` 分支。

### 题型 C 答案与解析
1. **绝对不能用（`SyntaxError`）**：`2nd_tag`（数字开头）、`for`、`in`、`True`（保留字）。
   **能过语法但严禁使用（覆盖内置名）**：`str`、`format`、`ord`、`print`、`sum`。
   **推荐**：`user_name`。
2. 双向 `.strip(" >*")` 会把合法末尾 `*` 删掉；`.rstrip(" ")` 只删半角空格，遇到 `\t` 会残留；无参 `.rstrip()` 能清理右侧所有空白再配合 `.lstrip(" >*")` 只清左侧符号。
