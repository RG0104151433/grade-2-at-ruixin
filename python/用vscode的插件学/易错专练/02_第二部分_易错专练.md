## 题型 A：概念辨析与输出预测

**A1.** 口算下面每个表达式的结果：
1. `2 ** 3 ** 2` 与 `(2 ** 3) ** 2`
2. `round(0.5)`, `round(-0.5)`, `round(1.5)`, `round(2.5)`, `round(-3.5)`, `round(-4.5)`
3. `1 + 2.0 + (3 + 4j)` 的结果与 `type(...)`

**A2.** 下面 4 行分别输出 `True` 还是 `False`？
```python
import math
from decimal import Decimal

print((1.1 + 2.2) == 3.3)
print(Decimal("1.1") + Decimal("2.2") == Decimal("3.3"))
print(Decimal(0.1) == Decimal("0.1"))
print(math.nan == math.nan, math.isnan(math.nan))
```

**A3.** 写出下面每行 `print` 的精确输出结果（数清空格与 `0`）：
```python
print(f"{5:02d} {-5:03d} {105:02d}")
print(f"{3.1:07.2f} | {round(7.0, 2)} | {7:.2f}")
print("{:8.3f}".format(12.2346))
print(f"{12000:,} {0.125:.1%} {0.043:.2e}")
```

**A4.** 下面两段代码输出什么？最后一行输入 `"10   20"`（中间 3 个空格）会怎样？
```python
m = 40; n = 19
print(m - (m // n) * n - (m % n))
print(10 / 2, type(10 / 2), 10 // 2, type(10 // 2))

x, y = input().split(" ")
```

**A5.**（考场高频函数）写出下面代码的精确输出：
```python
import math
print(divmod(17, 5), pow(2, 10, 100), math.ceil(-2.3), math.floor(-2.3))
print(round(math.sin(math.radians(30)), 2))
print(f"{pow(-9, 0.5):+>16.2f}")
```

## 题型 B：Bug 找茬与改错

**B1.（目标：单价 `12.5`、整数数量 `3`、折扣 `20`（减免 `20%`）、运费 `5`，输出保留 2 位小数的应付金额 `35.00`）**
```python
price, qty, disc, ship = input().split()
total = float(price) * float(qty)
pay = total * (1 - float(disc)) + float(ship)
print(f"{pay:.2f}")
```

**B2.（目标：用 `Decimal` 精确相加两个小数字符串，并保留原始 `total_seconds` 不变同时拆出小时与分钟）**
```python
from decimal import Decimal
a, b = input().split()
ans = Decimal(float(a)) + Decimal(float(b))

total_seconds = int(input())
hours = total_seconds // 3600
total_seconds %= 3600
mins = total_seconds // 60
secs = total_seconds % 60
print(ans, total_seconds)
```

**B3.（目标：已知直角边 `a`、`b` 与变化率 `r`，两行输出斜边 `2` 位小数以及 365 天日进/日退 `r` 的值 `2` 位小数）**
```python
import math
a, b, r = input().split()
print(f"{math.sqrt(int(a)**2 + int(b)**2):.2f}")
print(f"{math.pow(1 + float(r), 365)} {math.pow(1 + float(r), 365)}")
```

**B4.（目标：1. 计算 `sin(60°) + cos(60°)`；2. 支持负数开方成复数；3. 对 `n = -5` 输出同符号 `|n|-10` 得 `-5`、`n = 0` 按正号算）**
```python
import math
print(math.sin(60) + math.cos(60))
a = int(input())
print(math.sqrt(a))

n = int(input())
sign = 1 if n > 0 else -1
print((abs(n) - 10) * sign)
```

## 题型 C：独立边界推导小测

1. 某箱子最多装 `cap = 12` 瓶，请代入 `items = 0, 1, 12, 13` 检验公式 `(items + cap - 1) // cap`（不用 `if` 与 `math.ceil()`）。
2. 某班车 `23:50`（`1430` 分）出发，耗时 `1455` 分钟，手算 `+<days>d <HH>:<MM>` 格式的到达时间。

### 题型 B 答案与解析
- **B1**：`qty`、`disc` 应转 `int()`；`1 - float(disc)` 忘了先 `/ 100`（应 `1 - int(disc) / 100`）。
- **B2**：`Decimal(float(a))` 应直接 `Decimal(a)` 传字符串；`total_seconds %= 3600` 破坏了原变量，应用新变量 `rem = total_seconds % 3600`。
- **B3**：`a`、`b` 宜转 `float()` 并先存变量；第二个 `math.pow` 应为 `1 - float(r)`；两行都缺 `:.2f`。
- **B4**：`math.sin(math.radians(60))` 才对；负数开方用 `pow(a, 0.5)`；`0` 按正号须写 `if n >= 0`；同符号差值须外包 **`abs(abs(n) - 10) * sign`**（否则 `-5` 负负得正）。

### 题型 C 答案与解析
1. `items=0` → `11//12=0`；`1` → `12//12=1`；`12` → `23//12=1`；`13` → `24//12=2`，全部成立。
2. `1430 + 1455 = 2885` 分；`days = 2885 // 1440 = 2`，`day_min = 2885 % 1440 = 5`，小时 `0`、分钟 `5`，输出 **`+2d 00:05`**。
