## 题型 A：输出预测与机制辨析

**A1.** 下面 3 段代码分别输出什么？
```python
# (1) 嵌套 break 与外层 else
for i in range(2):
    for j in range(3):
        if j == 1:
            break
    else:
        print("inner else")
else:
    print("outer else")

# (2) 列表原地方法返回值
a = [3, 1, 2]
b = a.append(4)
c = a.sort()
print(a, b, c)

# (3) zip 截断与 enumerate
names = ["A", "B", "C"]
scores = [90, 80]
for k, (n, s) in enumerate(zip(names, scores), start=1):
    print(f"{k}:{n}={s}", end=" ")
```

**A2.** 下面代码想建一个 `2 × 3` 全零表格后只改左上角，结果会打印什么？为什么？
```python
mat = [[0] * 3] * 2
mat[0][0] = 9
print(mat)
```

**A3.** 判断下面 5 条调用哪些**合法**、哪些会**直接报错**（并说明报错类型）：
```python
ls = [-3, 1, -2]
sorted(ls, key=abs)              # ①
sorted(iterable=ls)              # ②
ls.sort(abs, True)               # ③
max([], default=0)               # ④
zip([1, 2], [3, 4], True)        # ⑤
```

**A4.** 对 `a = [2, 2, 3, 2, 4]` 执行 `for x in a: if x == 2: a.remove(x)` 后，`a` 最终剩下什么？为什么？

## 题型 B：真实坑位 Bug 找茬与改错

**B1.（目标：补全函数计算样本均值和偶长度中位数、并返回二元组 `(mean, med)`，不得改坏传入的 `nums`）**
```python
def f(nums):
    nums.sort()
    n = len(nums)
    avg = sum(nums) / n
    med = (nums[n / 2 - 1] + nums[n / 2]) // 2
    return [avg, med]
```

**B2.（目标：先读入到空行为止的整数列表（含 `0`），再读入 `r c` 与接下来的 `r` 行矩阵数据）**
```python
nums = []
while True:
    x = int(input().strip())
    if not x:
        break
    nums.append(x)

r, c = input().split()
grid = []
while True:
    row = [int[t] for t in input().split()]
    if not row:
        break
    grid.append(row)
```

**B3.（目标：对文本 `valid` 做保序去重后存入 `dedup`，按成绩降序、同分按姓名升序排 `zip(names, scores)`，最后求原矩阵 `grid` 第 0 列最大值，全负数矩阵如 `-5, -2` 也应正确）**
```python
valid = [10, 20, 10, 30]
seen = []
dedup = []
for v in valid:
    seen.append(v)
    if v not in seen:
        dedup.append(v)

pairs = zip(names, scores)
pairs.sort(key=lambda s: (-s[0], s[1]))

mx = 0
for i in range(len(grid)):
    mx = max(mx, grid[i][0])
```

**B4.（目标：求 `nums = [2, 2, 5, 7, 7, 8]` 的最长严格连续递增片段长度与起点，并按“非破坏原列表”打印反转后前 3 项）**
```python
nums = [2, 2, 5, 7, 7, 8]
mx_len, start = 1, 0
for i in range(len(nums)):
    cur = []
    for j in range(i + 1, len(nums)):
        if nums[j] >= cur[-1]:
            cur.append(nums[j])
    if len(cur) > mx_len:
        mx_len, start = len(cur), i

nums.reverse()
print(*nums[:3])
```

### 题型 A 答案与解析
- **A1**：
  1. 输出 **1 行 `outer else`**：内层因 `j == 1` 触发 `break`，跳过了 `inner else`；但外层自己从未触发 `break`，完整跑完了 `i = 0, 1` 两轮，因此外层的 `outer else` 照常执行！
  2. 输出 **`[1, 2, 3, 4] None None`**：`append` 和 `sort` 均原地修改 `a` 并返回 `None`。
  3. 输出 **`1:A=90 2:B=80`**（`"C"` 因 `scores` 较短被 `zip` 截断）。
- **A2**：打印 **`[[9, 0, 0], [9, 0, 0]]`**：外层 `* 2` 把同一个子列表引用重复放了 2 次（`mat[0] is mat[1]`），改 `mat[0][0]` 两行同步改变。正确初始化为 `[[0] * 3 for _ in range(2)]`。
- **A3**：
  - ① 合法，返回 `[1, -2, -3]`（按 `abs(x)` 升序）；
  - ② 报错 `TypeError`（`/` 左边 `iterable` 只准按位置传，不能写 `iterable=`）；
  - ③ 报错 `TypeError`（`*` 右边 `key`、`reverse` 必须写关键字名 `ls.sort(key=abs, reverse=True)`）；
  - ④ 合法，返回 `0`（传了 `default=0` 兜底）；
  - ⑤ 报错 `TypeError`（`strict` 在 `*iterables` 之后只能写关键字 `strict=True`，否则 `True` 被当成第 3 个不可迭代的对象传入）。
- **A4**：最终剩下 **`[2, 3, 4]`**！第 0 轮删掉下标 `0` 的第一个 `2` 后，列表变成 `[2, 3, 2, 4]`，第二个 `2` 左移到下标 `0`，但迭代器下一轮前进到下标 `1`（即 `3`）把第二个 `2` 跳过了；接着再往后遇到第 3 个 `2` 才把它删掉，留下第二个 `2`。

### 题型 B 答案与解析
- **B1**（共 4 处错）：
  1. `nums.sort()` 原地改坏了调用方传入的列表，应改用 `tmp = sorted(nums)`；
  2. 列表下标 `n / 2` 是 `float` 会报 `TypeError`，须改 `n // 2`；
  3. 外层均值反而不该用 `// 2`（会把 `4.5` 截断成 `4`），须用 `/ 2`；
  4. 要求返回二元组 `(avg, med)` 而不是列表 `[avg, med]`。
- **B2**（共 4 处错）：
  1. 空行读到 `""` 时 `int("")` 直接报 `ValueError`，且 `if not x:` 遇到合法整数 `0` 会误退，应先 `line = input().strip(); if not line: break` 再转 `int(line)`；
  2. `r, c = input().split()` 拆出的是字符串，后面必须转为 `int`；
  3. 第 2 段已明确有 `r` 行且结尾无空行，不能再用 `while True:` 等空行（会 `EOFError`），要改 `for _ in range(r):`；
  4. `int[t]` 误用方括号，函数调用必须写 `int(t)`。
- **B3**（共 4 处错）：
  1. 先 `seen.append(v)` 再 `if v not in seen:`，条件永远为假，导致 `dedup` 永远是空表（应直接 `if v not in dedup: dedup.append(v)`）；
  2. `zip(names, scores)` 返回惰性迭代器没有 `.sort()` 方法，应改用 `sorted(zip(names, scores), key=...)`；
  3. `(name, score)` 中 `s[0]` 是字符串姓名不能加负号，应写 `lambda s: (-s[1], s[0])`；
  4. `mx = 0` 在全负数列（如 `-5, -2`）时会错输出 `0`，初值必须设为 `mx = grid[0][0]`。
- **B4**（共 4 处错）：
  1. `cur = []` 空列表直接取 `cur[-1]` 会立刻报 `IndexError`；
  2. `>=` 允许相邻相等（与“严格递增 `>`”冲突），且即使加上首项后一旦断开也没写 `else: break`（会变成非连续子序列）；
  3. 用 `nums.reverse()` 原地修改破坏了原列表，应改成非破坏切片 `print(*nums[::-1][:3])`。
  - （参考改法：线性或双层起点赋 `cur_len = 1`、比较 `nums[j] > nums[j - 1]` 否则 `break`，本例 `[2, 5, 7]` 最长 `3` 起自下标 `1`。）

### 题型 C 答案与解析
1. `range()` 参数仅接受整数，传浮点步长会报 `TypeError`。标准解法：用整数段数 `n` 与 `range(n)` 遍历段号 `i`，再通过 `x = start + i * 0.5` 换算实际浮点坐标。
2. `ori[:]` 只是在创建那一瞬间拍一张列表快照。如果先原地修改了 `ori`，再写 `ls = ori[:]`，拿到手的就已经是“被移动过 `0` 之后的新顺序”，不再是原始输入了。
3. `random.seed(s)` 只是把伪随机数生成器拨回起点；之后每调用一次随机函数都会按确定顺序消耗队列里的下一个随机数，位置前置或次数增减都会让后续每次抽取偏移，从而使激活码彻底改变。
