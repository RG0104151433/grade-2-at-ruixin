### 开源配套站怎么打开
它不是纯静态文件（用了 ES module），直接双击 index.html 打不开。在 `repo/stanford-thinking-with-ai-main` 目录下执行：

```
python -m http.server 8193
```

然后浏览器开 http://localhost:8193 。里面最好用的部分：next-token 预测器、上下文挤压、注意力聚光灯、RAG "投毒"实验、prompt injection 找茬、agent 解剖、token/水电计算器、API key 泄露谜题。
它把课程内容做成了能动手的东西，适合看完视频之后练。
