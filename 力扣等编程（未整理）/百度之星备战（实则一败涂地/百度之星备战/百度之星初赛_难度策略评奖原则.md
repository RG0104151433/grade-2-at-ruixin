## 一、评奖原则

### 1.1 奖项与比例（比例制，按当届实际参赛人数计算）

| 奖项 | 比例 | 备注 |
|---|---|---|
| 省金奖 | 前 5% | |
| 省银奖 | 前 10% | |
| 省铜奖 | 前 15% | |
| 合计 | 约 30% | AC 为 0 不计入得奖 |

来源：[(赛氪2026页面)](https://m.saikr.com/vse/59405)、[(2024章程PDF)](https://new.dlnu.edu.cn/__local/9/5D/9A/38A4B6B93B1F32CAE2D89A7D2B6_9BD04E5E_49687.pdf)。

### 1.2 晋级国赛

- 每场约 400 个晋级名额，两场合计约 800 + 内训约 200 + 外卡 50-100。
- 晋级线 ≈ **全场前 8%-13%**（由 2025 第一场 400/3084≈13%、2023 第三场 300/3740≈8% 推算）。
- "可参加任意场次、取最佳成绩"——9/19 这场是独立赛道，不背第一场包袱。

### 1.3 AC 数与奖级对应（真实样本）

| AC 数 | 名次 / 奖级 | 依据 |
|---|---|---|
| 2 题 | 铜奖档 | 2K22 自述"2 题铜"（单人经验） |
| 3 题 | 铜奖档（晋级线附近） | 比例外推 |
| 4 题 | **前 5%-10%，晋级 + 银奖** | 浙江工商大学战报：152/3084≈4.9%、328/3321≈9.9% |
| 5 题 | 稳过晋级线，银奖~金奖 | 比例外推 |
| 6 题 | 金奖档 | 比例外推 |

**一句话结论：获奖与晋级都是比例制，绝对分数无意义；4 题是"晋级 + 银奖"的现实门槛，5 题是安全垫。**

## 二、难度画像

### 2.1 结构：签到 3 + 中档 3 + 难题 2

四届初赛恒定"3 小时 8 题、ACM 罚时制"，题量结构高度稳定。

### 2.2 三档考点分工

| 难度档 | 题量 | 高频形态 |
|---|---|---|
| **签到** | 2-3 | 直接模拟、简单贪心、打表找规律、简单公式——无算法门槛，只考实现与特判 |
| **中档** | 3-4 | 二分答案+check、排序枚举+贪心、双指针+set/multiset、基础计数 DP、线段树/BIT 模板应用 |
| **难题** | 1-2 | 树上换根 DP+线段树、树上组合计数、数论构造、观察性质+区间 DP |

### 2.3 知识点频次（36 题，主考点单一归属）

**第一梯队（合计约 64%）**：DP 6、数学·数论 6、模拟·实现 6、贪心 5
**第二梯队**：线段树/BIT 3、二分 3、图论 3、构造/找规律 2
**几乎绝迹**：单调栈 0、计算几何、高级字符串结构（后缀数组仅 2023 出现一次且存归属争议）

### 2.4 与你（C++ / DP·二分·单调栈强项）的匹配

- **抢分主线**：DP + 二分直接覆盖约 1/4 题量，是明确强项。
- **最需补短板（按性价比）**：① 数论三件套（组合数 / Lucas / 逆元 / 998244353）；② 线段树模板级应用（区间赋值/置换、动态开点）；③ 树上基础（换根 DP、度数-配对计数）。
- 数论与线段树在近三届 T2-T5 区间出现率约"每届 1-2 题"，是从 4 题档迈向 5-6 题档的最短路径。

## 三、比赛策略

### 3.1 开题顺序与时间分配（3 小时）

| 时段 | 动作 | 止损 |
|---|---|---|
| 0-10 min | 通读 8 题，按"题面长度 + 数据范围"预判难度排序 | — |
| 10-50 min | 清空 2-3 道签到题（模拟/贪心/找规律优先） | 每题 15 min |
| 50-110 min | 主攻中档（二分答案 → DP → 双指针优先） | 每题 30 min |
| 110-170 min | 第三道中档或难题，写结构化暴力保底 | — |
| 最后 10 min | 只做编译检查 + 规避重复提交 | 不开新题 |

依据：2024 有选手"1h 过 4 题"即达晋级线附近；反面教训是"没趁早拿下简单题、漫无目的盯难题"。

### 3.2 罚时控制（三个真实血泪点）

1. **long long**：默认 `#define int long long`（注意内存）或提交前逐一检查乘法处类型。2024 数星星数据达 1e18，多人 WA 在没开 long long。
2. **多测清空 + 数组大小**：多测用例务必清空，数组按 n 上限开并留一倍余量。
3. **评测异常留证**：怀疑评测异常时保留提交记录并截图，赛后按官方渠道申诉，勿反复无效提交。

**对拍习惯**：中档题（尤其贪心/构造/二分）提交前用"随机小数据 + 暴力对拍"验证。省下的 20 分钟罚时，往往是 100-200 名的差距（4 题区间，152 名与 328 名差距即在此）。

### 3.3 应急预案（源自真实事故）

- 2023/8/6 码蹄集开赛即遭攻击瘫痪、延期换题。
- **9/18 晚**：比赛客户端 + 浏览器双端登录，并试提交任意历史题一次。
- 开赛 10 分钟内若页面/评测异常：立即截图（含时间）→ 查看官方公告群 → 不反复提交制造罚时。
- 本地备好可离线编译的模板与对拍脚本，账号密码提前存档。

## 四、附：与码蹄杯的定位差异（供"占比"对标参考）

| 维度 | 码蹄杯国赛 | 百度之星初赛 |
|---|---|---|
| 级别 | 决赛 | 初赛 |
| 时长/题量 | 5h / 12 题 | 3h / 8 题 |
| 获奖比例 | 60%（金:银:铜 = 1:2:3） | 30%（金 5% / 银 10% / 铜 15%） |
| 参赛池 | 各省晋级的强手 | 全民开放（含大量新手，水平更参差） |
| 获奖题数参考 | 铜 3-5 / 银 6-8 / 金 8-10 | 铜 2-3 / 银 4 / 金 5-6 |

> 核心差异：码蹄杯国赛是"强手池里排前 60%"，百度之星初赛是"全民池里排前 30%"。**同一绝对能力，在初赛这个更弱的池子里，相对排名会显著更靠前。**
