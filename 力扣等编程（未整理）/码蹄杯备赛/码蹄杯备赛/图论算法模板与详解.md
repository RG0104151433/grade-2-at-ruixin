## 1. 建图（邻接表）

### 无向无权图

```cpp
int n, m;
cin >> n >> m;
vector<vector<int>> g(n);
while (m--) {
    int u, v;
    cin >> u >> v;
    // 通常转化为 0-based
    u--; v--;
    g[u].push_back(v);
    g[v].push_back(u);  // 无向图加反向边
}
```

### 有向带权图

```cpp
int n, m;
cin >> n >> m;
vector<vector<pair<int,int>>> g(n);  // (邻居, 权值)
while (m--) {
    int u, v, w;
    cin >> u >> v >> w;
    u--; v--;
    g[u].push_back({v, w});  // 有向图只加单向
}
```

### 说明

- `vector<vector<int>> g(n)` 创建了 n 个空 vector，不是 n×n 矩阵
- 空间复杂度 O(n + m)，不是 O(n²)
- 竞赛中 90% 的情况用邻接表，只有 n ≤ 1000 且图很稠密时才考虑邻接矩阵

## 2. Dijkstra 堆优化

### 用途

给定起点 s，求 s 到所有其他点的最短距离（边权必须非负）。

### 模板

```cpp
const int INF = 0x3f3f3f3f;

vector<int> dijkstra(int s, const vector<vector<pair<int,int>>>& g) {
    int n = g.size();
    vector<int> dist(n, INF);
    // 小根堆: (距离, 节点编号)，greater 让堆顶是最小值
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;

    dist[s] = 0;
    pq.push({0, s});

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();

        // 关键：跳过旧数据
        // 同一个节点可能被 push 多次，只有最小的那次有效
        if (d > dist[u]) continue;

        // 松弛操作：尝试用 u 缩短邻居的距离
        for (auto [v, w] : g[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}
```

### 逻辑详解

| 部分 | 作用 |
|------|------|
| `dist[u]` | 当前已知的 s→u 的最短距离，初始 INF |
| `pq.push({0, s})` | 起点距离自己是 0 |
| `d > dist[u]` 跳过 | 同一个节点可能被多次松弛、多次入堆，只处理最新的最短距离 |
| `dist[u] + w < dist[v]` | 松弛条件：经过 u 到 v 比原来更短，就更新 |
| `pq.push({dist[v], v})` | 更新后把新距离入堆，等待后续扩展 |

### 为什么 priority_queue 不用 `pair<int,int>` 排序有问题？

默认是大根堆（最大元素在堆顶），我们需要最小元素，所以要传 `greater<>`。
或者可以写成 `priority_queue<pair<int,int>> pq` 然后 push 时存 `{-dist[v], v}`，用负数模拟小根堆。

### 时间复杂度

O(m log n)，其中 m 是边数，n 是点数。

### 刷题

- **743·网络延迟时间**：模板题，算 s 到所有点的最短路，取最大值
- **1514·概率最大路径**：把"最小化"改成"最大化"，dist 初始 0 起点 1，松弛条件用乘法

## 3. Kruskal

### 用途

求最小生成树（MST）的总权值，即用 n-1 条边连通所有点，且边权和最小。

### 模板

```cpp
struct Edge {
    int u, v, w;
    bool operator<(const Edge& other) const {
        return w < other.w;  // 按权值排序
    }
};

// 并查集
vector<int> p;
int find(int x) {
    return p[x] == x ? x : p[x] = find(p[x]);
}

int kruskal(int n, vector<Edge>& edges) {
    // 1. 按边权从小到大排序
    sort(edges.begin(), edges.end());

    // 2. 初始化并查集
    p.resize(n);
    iota(p.begin(), p.end(), 0);

    int ans = 0, cnt = 0;  // cnt: 已选边数
    for (auto& e : edges) {
        int ru = find(e.u), rv = find(e.v);
        if (ru != rv) {        // 不在同一集合 → 不会成环
            p[ru] = rv;
            ans += e.w;
            if (++cnt == n - 1) break;  // 选了 n-1 条边就够了
        }
    }

    // 如果 cnt < n-1，说明图不连通，没有最小生成树
    return cnt == n - 1 ? ans : -1;
}
```

### 逻辑详解

| 部分 | 作用 |
|------|------|
| 按权值排序 | 贪心核心：每次选当前最小的边 |
| 并查集判断环 | 如果 u 和 v 已经连通，再加这条边就会成环 |
| `cnt == n-1` 提前结束 | 树有 n-1 条边，够了就停 |
| 返回 -1 | 图不连通，无法构成生成树 |

### 为什么 Kruskal 是对的？

**贪心选择性**：在任何时刻，权值最小的边如果不会成环，它一定属于某棵最小生成树。
**反证法**：如果最小边 e 不在 MST 中，把 e 加入 MST 会形成环，环上一定有比 e 大的边，替换后总权值更小，矛盾。

### 对比 Prim

| | Kruskal | Prim |
|--|---------|------|
| 思路 | 选边 | 选点 |
| 数据结构 | 并查集 | 堆（类似 Dijkstra） |
| 适用场景 | 稀疏图（边少） | 稠密图（边多） |
| 复杂度 | O(m log m) | O(m log n) |
| 推荐 | **竞赛更常用** | 了解即可 |

### 刷题

- **1584·连接所有点的最小费用**：Kruskal 模板题，先建所有边再排序

## 4. 拓扑排序

### 用途

对有向无环图（DAG）排序，使得每条边的起点都在终点之前。常用于任务调度、依赖关系。

### 模板（Kahn 算法·BFS）

```cpp
vector<int> topoSort(int n, const vector<vector<int>>& g) {
    vector<int> inDeg(n, 0);  // 入度
    for (int u = 0; u < n; u++)
        for (int v : g[u])
            inDeg[v]++;

    queue<int> q;
    for (int i = 0; i < n; i++)
        if (inDeg[i] == 0) q.push(i);  // 入度为 0 的入队

    vector<int> ans;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        ans.push_back(u);
        for (int v : g[u])
            if (--inDeg[v] == 0)       // 去掉 u 的影响
                q.push(v);
    }

    // 如果 ans.size() < n，说明有环，无法拓扑排序
    return ans.size() == n ? ans : vector<int>();
}
```

### 逻辑详解

| 部分 | 作用 |
|------|------|
| `inDeg` | 记录每个节点的入度（有多少条边指向它） |
| 入度为 0 入队 | 没有前置依赖的节点可以直接输出 |
| `--inDeg[v] == 0` | 去掉 u 后，v 的依赖少了一个，如果减到 0 说明前置全部完成 |
| `ans.size() < n` 判环 | 有环时环内节点入度永远不为 0，无法入队 |

### 拓扑排序的两种写法

- **BFS（Kahn）**：上面这个，更常用，还能顺便判环
- **DFS**：后序遍历，再反转，不常用但理解递归有帮助

### 刷题

- **207·课程表**：判环即可，看拓扑排序能否排完所有课
- **210·课程表 II**：输出具体顺序，直接套模板

## 5. DFS 图遍历

### 用途

遍历连通分量、回溯搜索、检测环。

### 函数声明

```cpp
void dfs(int u, const vector<vector<int>>& g, vector<bool>& vis);
```

**参数含义：**
- `u`：当前正在访问的节点编号
- `g`：邻接表，整个图的结构（加 const 表示不修改它）
- `vis`：访问标记数组，`vis[i] == true` 表示 i 已经去过了

### 模板

```cpp
void dfs(int u, const vector<vector<int>>& g, vector<bool>& vis) {
    vis[u] = true;                     // ① 标记已访问
    for (int v : g[u]) {               // ② 遍历 u 的所有邻居
        if (!vis[v]) {                 // ③ 如果邻居没去过
            dfs(v, g, vis);            // ④ 递归进去
        }
    }
}
```

**逐行执行过程：**
从 0 出发 → 找 0 的第一个邻居 1 → 去 1 → 找 1 的第一个邻居 2 → 去 2 → 2 没邻居了 → 退回 1 → 找 1 的下一个邻居 → ...

### 连通分量计数

```cpp
int main() {
    // 建图 g ...

    int n = g.size();
    vector<bool> vis(n, false);
    int cnt = 0;                     // 连通分量计数

    for (int i = 0; i < n; i++) {    // 遍历所有节点
        if (!vis[i]) {               // 如果 i 还没被访问过
            cnt++;                   // 发现一个新的连通块
            dfs(i, g, vis);          // 把整个连通块全标记上
        }
    }

    cout << cnt << endl;             // 输出连通分量个数
}
```

**为什么这样就能数出连通块？** 第一次调用 dfs(0) 会把节点 0 所在的整个"团伙"全部标记掉。等它回来，再找下一个没标记的，一定是另一个独立的团伙。

### 判环（有向图）

```cpp
// 0=未访问, 1=在栈中, 2=已结束
vector<int> state(n, 0);

function<bool(int)> hasCycle = [&](int u) -> bool {
    state[u] = 1;  // 入栈
    for (int v : g[u]) {
        if (state[v] == 1) return true;  // 遇到还在栈中的节点 → 有环
        if (state[v] == 0 && hasCycle(v)) return true;
    }
    state[u] = 2;  // 出栈，标记结束
    return false;
};
```

## 6. BFS 图遍历

### 用途

无权图最短路、层次遍历、多源搜索。

### 函数声明

```cpp
void bfs(int s, const vector<vector<int>>& g, vector<int>& dist);
```

**参数含义：**
- `s`：起点编号
- `g`：邻接表
- `dist`：距离数组，`dist[i]` 表示从 s 到 i 的最短距离，初始填 -1 表示不可达

### 模板

```cpp
void bfs(int s, const vector<vector<int>>& g, vector<int>& dist) {
    queue<int> q;                        // ① 队列：先进先出
    dist[s] = 0;                         // ② 起点到自己的距离是 0
    q.push(s);                           // ③ 起点入队

    while (!q.empty()) {                 // ④ 队列不空就一直做
        int u = q.front();               // ⑤ 拿出队首
        q.pop();

        for (int v : g[u]) {             // ⑥ 遍历 u 的所有邻居
            if (dist[v] == -1) {         // ⑦ 第一次遇到 v
                dist[v] = dist[u] + 1;   // ⑧ v 的距离 = u 的距离 + 1
                q.push(v);               // ⑨ v 入队，以后从 v 继续扩展
            }
        }
    }
}
```

**每行含义：**

| 行 | 在干什么 |
|----|---------|
| `queue<int> q` | 创建一个队列，BFS 的"待办清单" |
| `dist[s] = 0` | 起点到自己是 0 步 |
| `q.push(s)` | 把起点放进待办清单 |
| `while (!q.empty())` | 只要还有没办完的事 |
| `u = q.front(); q.pop()` | 从待办清单里拿一个出来处理 |
| `for (int v : g[u])` | 看 u 认识哪些人 |
| `if (dist[v] == -1)` | 如果 v 还没被访问过（第一次到） |
| `dist[v] = dist[u] + 1` | 记录距离：从 s 到 u 再走一步到 v |
| `q.push(v)` | 把 v 放进待办清单，以后从 v 继续扩展 |

### 为什么 BFS 第一次访问就是最短距离？

BFS 按层扩展：从 s 出发，先走 1 步能到的所有点，再走 2 步能到的所有点……

```
         s  (层0)
        / \
       a   b (层1)
      / \   \
     c   d   e (层2)
```

第一次访问到 c 时，一定是从 s 走最短路径到的，因为如果还有更短的路径，c 应该更早被访问到。

### 多源 BFS

多个起点同时入队，常用于"腐烂的橘子"类问题。

```cpp
queue<int> q;
// 所有起点先入队
for (int i = 0; i < n; i++)
    if (/* 起点条件 */) {
        dist[i] = 0;
        q.push(i);
    }
// 然后正常 BFS
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) {
        if (dist[v] == -1) {
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }
}
```

### 主函数里怎么调用

```cpp
int main() {
    // ... 建图 g ...

    int n = g.size();
    vector<int> dist(n, -1);       // 初始全部 -1，表示还没去过

    bfs(0, g, dist);               // 从 0 开始 BFS

    // 输出结果：看 0 到每个点的距离
    for (int i = 0; i < n; i++) {
        cout << "0 → " << i << " : " << dist[i] << endl;
    }
}
```

## DFS vs BFS 一句话对比

| | DFS | BFS |
|--|-----|-----|
| 数据结构 | 栈（递归就是系统栈） | 队列 |
| 性格 | 一头扎到底，走不通再回头 | 一圈一圈往外扩 |
| 用途 | 连通块计数、回溯、判环 | **无权图最短路**、层次遍历 |
| 距离 | 不保证最短 | 第一次到就是最短 |

**码蹄杯里怎么用：**
- 问"有多少个连通块" → DFS 或并查集
- 问"最短路径长度" → BFS（无权图）或 Dijkstra（带权图）
- 问"有没有环" → DFS 三色标记
- 问"按层输出" → BFS

## 7. Floyd（选学）

### 用途

求所有点对之间的最短路径。n ≤ 500 时可用。

### 模板

```cpp
const int INF = 0x3f3f3f3f;
vector<vector<int>> dist(n, vector<int>(n, INF));
for (int i = 0; i < n; i++) dist[i][i] = 0;

// 初始化已知边
for (auto& e : edges) dist[e.u][e.v] = e.w;

// 核心：三重循环
for (int k = 0; k < n; k++)          // 中间点
    for (int i = 0; i < n; i++)      // 起点
        for (int j = 0; j < n; j++)  // 终点
            if (dist[i][k] < INF && dist[k][j] < INF)
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
```

### 说明

- 最外层 k 是"允许使用的中间点"，从 0 到 n-1 逐步放开
- 三层循环结束后，dist[i][j] 就是 i→j 的最短距离
- O(n³)，竞赛中 n > 500 就别用了

## 总结：快速决策指南

拿到一道图论题，按以下流程判断用哪个算法：

```
题目给了什么？
│
├─ 问"最短路径" ──→ 边权有负数吗？
│                      ├─ 没有 → Dijkstra（第2节）
│                      └─ 有 → Bellman-Ford（不常用，码蹄杯极少考）
│
├─ 问"所有点对之间的最短路径" ──→ n ≤ 500 → Floyd（第8节）
│
├─ 问"连通所有点的最小代价" ──→ 最小生成树 → Kruskal（第3节）
│
├─ 问"能否按依赖顺序完成/有无环" ──→ 拓扑排序（第5节）
│
├─ 问"最短步数/层数"（无权图）──→ BFS（第7节）
│
├─ 问"有几个连通块/能否走通" ──→ DFS（第6节）或并查集
│
└─ 问"能否分成两组，组内无边" ──→ 二分图判定 → DFS染色（第6节）
```

## 各算法详细拆解

### ① Dijkstra 堆优化（第2节）

| 项目 | 说明 |
|------|------|
| **解决什么问题** | 从一个起点到所有其他点的最短路径（如"从节点1到节点5的最短时间"） |
| **怎么判断该用** | ① 题目问"最短路径""最小时延""最少花费" ② 边权都是正数 ③ 只给了一个起点 |
| **模板位置** | **[第2节·Dijkstra 堆优化](#2-dijkstra-堆优化)** |
| **典型例题** | 743·网络延迟时间（模板题），1514·概率最大路径（变形） |
| **码蹄杯考频** | ★★★★★ 最常考，**模板必须背熟** |
| **常见坑** | ① 节点编号是1-based还是0-based？注意转换 ② dist要初始化为一个大数（INF），不要用0或-1 ③ 堆优化版一定要写 `greater<>`，否则默认大根堆全错 |

**一句话记模板：** priority_queue小根堆，dist初始INF，起点0入队，弹出时d>dist跳过，对每个邻居尝试松弛。

### ② Kruskal（第3节）

| 项目 | 说明 |
|------|------|
| **解决什么问题** | 用最少的边连通所有点（如"修建道路使所有城市连通，总造价最小"） |
| **怎么判断该用** | ① 题目问"最小生成树""最小代价连通""所有点连通的最小花费" ② 给了点和边，要求选边 ③ 可以用并查集的地方 |
| **模板位置** | **[第3节·Kruskal](#3-kruskal)** |
| **典型例题** | 1584·连接所有点的最小费用 |
| **码蹄杯考频** | ★★★★☆ 常有，既然并查集练过，这个不难拿分 |
| **常见坑** | ① 边数可能很大，排序后记得 `cnt == n-1` 提前break ② 图可能不连通，要返回-1 ③ 边权可能为0或负数，Kruskal同样适用 |

**一句话记模板：** 边按权值排序，并查集判断是否成环，选n-1条就停。

### ③ Prim（第4节·选学）

| 项目 | 说明 |
|------|------|
| **解决什么问题** | 和Kruskal一样求最小生成树 |
| **怎么判断该用** | ① 图特别稠密（边数接近n²） ② 题目给了邻接矩阵而不是边列表 |
| **模板位置** | **[第4节·Prim](#4-prim最小生成树选学)** |
| **码蹄杯考频** | ★★☆☆☆ 极少单独考，了解原理即可，竞赛中Kruskal更常用 |

### ④ 拓扑排序（第5节）

| 项目 | 说明 |
|------|------|
| **解决什么问题** | 有依赖关系的任务排序（如"先修课安排""工序先后顺序"），或判断有没有环 |
| **怎么判断该用** | ① 题目出现"依赖关系""前置条件""先后顺序""课程表" ② 有向图且问"能否完成""按顺序输出" ③ 要判断有向图是否有环 |
| **模板位置** | **[第5节·拓扑排序](#5-拓扑排序)** |
| **典型例题** | 207·课程表（判环），210·课程表II（输出顺序） |
| **码蹄杯考频** | ★★★☆☆ 偶有，代码短容易拿分 |
| **常见坑** | ① 只适用于有向无环图（DAG），有环时返回空 ② 不要求图连通，多个连通分量也能排 ③ 入度数组要算对，每条边 `u→v` 让 `inDeg[v]++` |

**一句话记模板：** 算入度，入度为0入队，弹出时减邻居入度，减到0再入队，最后看排了n个没有。

- Prim和Floyd保持了解，比赛时真有需要再看模板## 3.5 Prim（最小生成树·选学）

### 用途

和 Kruskal 一样求最小生成树，但思路不同：Kruskal 选边，Prim 选点。

### 模板（堆优化版，类似 Dijkstra）

```cpp
const int INF = 0x3f3f3f3f;

int prim(int s, const vector<vector<pair<int,int>>>& g) {
    int n = g.size();
    vector<int> dist(n, INF);  // 到当前树的最小距离
    vector<bool> vis(n, false);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;

    dist[s] = 0;
    pq.push({0, s});
    int ans = 0, cnt = 0;

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (vis[u]) continue;          // 已加入树，跳过
        vis[u] = true;
        ans += d;                      // 把这条边加入 MST
        if (++cnt == n) break;         // 所有点都在树里了

        for (auto [v, w] : g[u]) {
            if (!vis[v] && w < dist[v]) {
                dist[v] = w;           // 注意：这里不是 dist[u]+w，而是 w
                pq.push({dist[v], v});
            }
        }
    }
    return cnt == n ? ans : -1;        // 不连通返回 -1
}
```

### 逻辑详解

| 部分 | 作用 |
|------|------|
| `dist[v]` | 节点 v 到**当前已选中的树**的最小距离，不是到起点的距离 |
| `ans += d` | 每选中一个点，把它连入树的边权加入总权值 |
| `w < dist[v]` | 如果通过新加入的点 u 到 v 距离更近，就更新 |

### 和 Dijkstra 的区别

| | Dijkstra | Prim |
|--|---------|------|
| `dist[v]` 含义 | 起点 s 到 v 的最短距离 | 已选中的树到 v 的最短距离 |
| 松弛条件 | `dist[u] + w < dist[v]` | `w < dist[v]` |
| 累加 | 不累加，只记录距离 | `ans += d` 累加边权 |

**一句话：** Prim 和 Dijkstra 代码几乎一样，区别只有两行——松弛条件不同，以及 Prim 要累加边权。

### 什么时候用 Prim

- 稠密图（边数接近 n²）时 Prim 比 Kruskal 快
- 但竞赛中**绝大多数情况用 Kruskal**，因为并查集刚练过，而且码蹄杯的图通常是稀疏图
- Prim 了解原理即可，不要求闭眼写
