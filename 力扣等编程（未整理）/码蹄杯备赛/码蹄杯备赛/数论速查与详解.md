## 1. GCD 最大公约数 🔴

### 1.1 辗转相除法（欧几里得算法）

**核心逻辑：** `gcd(a, b) = gcd(b, a % b)`，直到 b = 0 时 a 就是答案。

```cpp
int gcd(int a, int b) {
    return b ? gcd(b, a % b) : a;
}
// 或 C++17 直接用 std::gcd
```

**为什么能这样？** 如果 d 能整除 a 和 b，那么 d 也一定能整除 a % b = a - ⌊a/b⌋ × b。反过来同理，所以公约数集合不变。

**时间复杂度：** O(log min(a, b))

### 1.2 LCM 最小公倍数

```cpp
int lcm(int a, int b) {
    return a / gcd(a, b) * b;  // 先除后乘，防溢出
}
```

### 1.3 贝祖定理（Bézout's identity）

**定理：** 存在整数 x, y 使得 ax + by = gcd(a, b)

**码蹄杯应用：水壶问题（LeetCode 365）**
- 两个容量为 x、y 的水壶，能否量出 z 升水？
- 每次操作等价于对水量做 ±x 或 ±y
- 能测出的水量恒为 gcd(x, y) 的倍数
- **判断条件：** z % gcd(x, y) == 0 且 z ≤ x + y

### 1.4 题目识别

| 特征 | 思路 |
|------|------|
| 求最大公约数 / 化简分数 | 直接 gcd |
| 两个数能否凑出某个数 | 判 z % gcd(x, y) == 0 |
| 循环节 / 周期相遇问题 | 本质是 lcm |

## 2. 快速幂 🔴

### 2.1 迭代版（推荐）

**核心逻辑：** 把指数 n 拆成二进制，例如 3¹³ = 3⁸ × 3⁴ × 3¹ = 3^(1101₂)

```cpp
using ll = long long;
ll qpow(ll a, ll n, ll mod) {
    ll res = 1;
    while (n) {
        if (n & 1) res = res * a % mod;
        a = a * a % mod;
        n >>= 1;
    }
    return res;
}
```

**时间复杂度：** O(log n)

### 2.2 递归版（理解用）

```cpp
ll qpow(ll a, ll n, ll mod) {
    if (n == 0) return 1;
    ll t = qpow(a, n / 2, mod);
    t = t * t % mod;
    if (n & 1) t = t * a % mod;  // n 为奇数多乘一个 a
    return t;
}
```

### 2.3 快速乘（防溢出）

当 mod 很大（接近 1e18），两数相乘会爆 long long 时：

```cpp
ll qmul(ll a, ll b, ll mod) {
    ll res = 0;
    while (b) {
        if (b & 1) res = (res + a) % mod;
        a = (a + a) % mod;
        b >>= 1;
    }
    return res;
}
```

### 2.4 题目识别

| 特征 | 思路 |
|------|------|
| 求 a^n % MOD，n 很大（1e9+） | 快速幂 |
| 求逆元（MOD 为质数） | a^(MOD-2) % MOD |
| 矩阵快速幂（递推优化） | 把递推式写成矩阵，快速幂算矩阵 |

## 3. 质数筛 🔴

### 3.1 埃氏筛（Eratosthenes）

**核心逻辑：** 从 2 开始，把每个质数的倍数全标记为合数。

```cpp
const int N = 1e6 + 5;
bool is_prime[N];  // true 表示是质数
void sieve(int n) {
    fill(is_prime, is_prime + n + 1, true);
    is_prime[0] = is_prime[1] = false;
    for (int i = 2; i * i <= n; i++) {
        if (is_prime[i]) {
            for (int j = i * i; j <= n; j += i)  // 从 i*i 开始，避免重复标记
                is_prime[j] = false;
        }
    }
}
```

**时间复杂度：** O(n log log n)，n=1e6 够用

### 3.2 欧拉筛（线性筛）

**核心逻辑：** 每个合数只被它的最小质因子标记一次，保证 O(n)。

```cpp
const int N = 1e7 + 5;
bool is_prime[N];
int primes[N], cnt;  // primes 存质数列表

void linear_sieve(int n) {
    fill(is_prime, is_prime + n + 1, true);
    is_prime[0] = is_prime[1] = false;
    for (int i = 2; i <= n; i++) {
        if (is_prime[i]) primes[cnt++] = i;
        for (int j = 0; j < cnt && i * primes[j] <= n; j++) {
            is_prime[i * primes[j]] = false;
            if (i % primes[j] == 0) break;  // 关键：primes[j] 是 i 的最小质因子
        }
    }
}
```

**什么时候用欧拉筛？** n 达到 1e7 级别，或者需要同时维护其他数论函数（如最小质因子、欧拉函数 φ）。

### 3.3 判断单个数是否为质数

```cpp
bool is_prime_single(int x) {
    if (x < 2) return false;
    for (int i = 2; i * i <= x; i++)
        if (x % i == 0) return false;
    return true;
}
```

### 3.4 题目识别

| 特征 | 思路 |
|------|------|
| 统计 n 以内质数个数 | 埃氏筛 / 欧拉筛 |
| 判断一个大数（1e12）是否为质数 | 试除法到 sqrt(n) 即可 |
| 质数相关数学题 | 先筛，再枚举质数 |

## 4. 质因数分解 🟡

### 4.1 试除法

```cpp
vector<pair<int, int>> factorize(int x) {
    vector<pair<int, int>> res;  // {质因子, 次数}
    for (int i = 2; i * i <= x; i++) {
        if (x % i == 0) {
            int cnt = 0;
            while (x % i == 0) {
                x /= i;
                cnt++;
            }
            res.push_back({i, cnt});
        }
    }
    if (x > 1) res.push_back({x, 1});  // 剩余的一个质因子
    return res;
}
```

### 4.2 最小质因子筛法（O(log n) 分解）

预处理出每个数的最小质因子（min_prime），然后反复除以它：

```cpp
const int N = 1e6 + 5;
int mpf[N];  // 最小质因子 (min prime factor)

void init_mpf(int n) {
    for (int i = 2; i <= n; i++) {
        if (mpf[i] == 0) {
            mpf[i] = i;
            for (int j = i; j <= n; j += i)
                if (mpf[j] == 0) mpf[j] = i;
        }
    }
}

vector<int> factorize_fast(int x) {
    vector<int> res;
    while (x > 1) {
        int p = mpf[x];
        res.push_back(p);
        x /= p;
    }
    return res;
}
```

### 4.3 题目识别

| 特征 | 思路 |
|------|------|
| 求一个数的所有质因子 | 试除法 |
| 多次分解（1e5 次） | 预处理最小质因子 |
| 因数个数、因数之和 | 分解后用公式：d(n) = Π(cnt_i + 1) |

## 5. 逆元与组合数 🟡

### 5.1 费马小定理求逆元

**前提：** MOD 是质数，且 a 不是 MOD 的倍数。

```
a^(MOD-1) ≡ 1  (mod MOD)
→ a × a^(MOD-2) ≡ 1  (mod MOD)
→ a 的逆元 = a^(MOD-2) % MOD
```

```cpp
ll inv(ll a, ll mod) {
    return qpow(a, mod - 2, mod);
}
```

### 5.2 预处理阶乘与逆元求 C(n, k)

**用途：** 多次查询组合数，n 和 k 在 1e6 以内。

```cpp
const int MOD = 1e9 + 7;
const int MAXN = 1e6 + 5;
ll fac[MAXN], inv_fac[MAXN];

void init() {
    fac[0] = 1;
    for (int i = 1; i < MAXN; i++)
        fac[i] = fac[i - 1] * i % MOD;
    inv_fac[MAXN - 1] = qpow(fac[MAXN - 1], MOD - 2, MOD);
    for (int i = MAXN - 2; i >= 0; i--)
        inv_fac[i] = inv_fac[i + 1] * (i + 1) % MOD;
}

ll C(int n, int k) {
    if (k < 0 || k > n) return 0;
    return fac[n] * inv_fac[k] % MOD * inv_fac[n - k] % MOD;
}
```

### 5.3 卢卡斯定理（简要了解）

**适用：** n 和 k 很大（1e9+），但 MOD 较小（1e5 左右）。

```cpp
ll lucas(ll n, ll k, ll p) {
    if (k == 0) return 1;
    return C(n % p, k % p, p) * lucas(n / p, k / p, p) % p;
}
```

### 5.4 题目识别

| 特征 | 思路 |
|------|------|
| 求组合数 C(n, k) % MOD，MOD 为质数 | 预处理阶乘 + 逆元 |
| 求 a / b % MOD | 先算 b 的逆元，再乘 a |
| n 很大（1e9），MOD 较小 | 卢卡斯定理 |

## 6. 数根与负数取模 🟢

### 6.1 数根（数字根）

一个数的数根 = 各位数字之和反复求和，直到剩一位。

```cpp
int digital_root(int x) {
    return (x - 1) % 9 + 1;  // 公式解，x > 0
}
```

**本质：** 数根 = x % 9，但 9 的倍数数根是 9 而不是 0。

### 6.2 负数取模

C++ 中 `-5 % 3 = -2`，但数学上我们通常要正余数：

```cpp
int mod(int a, int m) {
    return (a % m + m) % m;
}
```
