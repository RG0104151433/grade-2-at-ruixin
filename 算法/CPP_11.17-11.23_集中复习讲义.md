## 01｜11/17：完整程序、输入输出与数值运算

### 1. 一份完整程序有哪些部分

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << 1LL * a + b << '\n';
    cout << 1LL * a * b << '\n';
    return 0;
}
```

`#include <iostream>` 提供标准输入输出工具；`using namespace std;` 让本讲义可以直接使用 `cin`、`cout`；`main` 是程序入口；`return 0;` 表示正常结束。每条普通语句通常用分号结尾，花括号把一组语句放在一起。

程序读入两个整数，第一行输出和，第二行输出积。这里假设两个输入均在 −10⁹ 到 10⁹ 之间，和与积都能用 `long long` 保存。

输入：

```text
100000 100000
```

输出：

```text
200000
10000000000
```

`cin >> a >> b` 对整数读取会跳过空白，所以两个数写在同一行或分两行通常都可以。`cout << x << '\n'` 表示输出 `x` 后换行。

### 2. 常用类型怎么选

| 类型 | 用途 | 需要记住的点 |
| --- | --- | --- |
| `int` | 个数、下标、范围较小的整数 | 常见竞赛环境为 32 位，约 −2.1×10⁹ 到 2.1×10⁹ |
| `long long` | 大整数、累计和、较大的乘积 | 至少 64 位；常见有符号 64 位最大值约 9.22×10¹⁸ |
| `double` | 小数、平均值 | 存在浮点误差，不能替代精确的大整数计算 |
| `char` | 单个字符 | 如 `'A'`、`'7'`，使用单引号 |
| `bool` | 判断结果 | 值为 `true` 或 `false` |

先看数据范围，再看中间结果。例如 10⁵ 个、每个最大为 10⁹ 的整数，总和可能达到 10¹⁴，单个元素可以用 `int`，总和应使用 `long long`。

### 3. 三个必须分清的运算问题

**整数除法：**两个整数相除，结果仍是整数，向零截断。因此 `5 / 2` 为 `2`，`-5 / 2` 为 `-2`；`5.0 / 2` 为 `2.5`。需要小数时，先转换参与运算的一个数，例如 `double avg = 1.0 * sum / n;`，前提是 `n != 0`。

**取余：**`a % b` 得到整数除法的余数，`b` 不能为 0。判断偶数可以写 `x % 2 == 0`，判断奇数建议写 `x % 2 != 0`，它也适用于负奇数。

**计算类型：**接收结果的变量类型，不会提前改变右侧的计算类型。

```cpp
int a = 100000, b = 100000;
// long long wrong = a * b;  // 先进行 int 乘法，发生有符号溢出，行为未定义
long long right = 1LL * a * b;
```

`1LL` 是 `long long` 类型的整数常量，使上述连乘从一开始就在 `long long` 中进行。它也不是无限大，仍要保证结果在可表示范围内。

### 4. 易错点

- `=` 是赋值，`==` 是判断相等；`if (x = 1)` 不能代替 `if (x == 1)`。
- 普通局部变量使用前要赋值，例如 `long long sum = 0;`。
- `double x = 5 / 2;` 得到的是 `2.0`，整数除法已经先完成。
- 有符号整数溢出是未定义行为，不能依赖其“绕回”结果。

### 5. 练习 1

读入一个整数 `n`，满足 `0 <= n <= 10^9`，输出 `1 + 2 + ... + n`。要求使用公式完成，不逐项循环。

输入 `100000`，应输出 `5000050000`。先想一想：公式中的乘法应该用什么类型？

## 02｜11/18：条件、循环、数组与 vector

### 1. 控制程序执行的三种结构

```cpp
if (x > 0) {
    // x 为正时执行
} else {
    // x 不为正时执行
}

for (int i = 0; i < n; ++i) {
    // i 依次为 0、1、...、n-1
}

while (x > 0) {
    x /= 10;
}
```

上面是语法片段，需放入合适的程序并先定义变量。`for` 适合按次数或下标遍历；`while` 适合“条件成立就继续”。注意循环中必须有使条件最终改变的操作。

`break` 结束最内层循环；`continue` 跳过本轮剩余语句，进入下一轮。`&&` 表示且，`||` 表示或，`!` 表示非，例如 `x >= 1 && x <= 10`。不能用数学中的连写 `1 <= x <= 10` 表达范围。

### 2. 数组和 vector

数组可以保存一组同类型元素；本讲义主要使用长度可在运行时确定的 `vector`。

```cpp
#include <vector>
// 以下语句放在 main 等函数内部：
vector<int> a(5);       // 5 个元素，初始值都是 0
vector<int> b(5, -1);   // 5 个元素，初始值都是 -1
vector<int> c;         // 空 vector
c.push_back(7);        // 末尾追加 7，此时长度为 1
```

长度为 `n` 的 `vector`，合法下标为 `0` 到 `n-1`，`a[n]` 越界。`a.size()` 返回元素个数，`a.empty()` 判断是否为空。`vector<int> a(n)` 已经有 `n` 个元素，读入时可以写 `cin >> a[i]`；空 `vector` 要先追加元素，不能直接写 `c[0] = 7`。

### 3. 主例题：求和、最大值与正数个数

输入 `n`，再输入 `n` 个整数，满足 `1 <= n <= 10^5`，每个整数绝对值不超过 10⁹。依次输出总和、最大值、正数个数，各占一行。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }

    long long sum = 0;
    int mx = a[0];
    int positive = 0;
    for (int i = 0; i < n; ++i) {
        sum += a[i];
        if (a[i] > mx) mx = a[i];
        if (a[i] > 0) ++positive;
    }

    cout << sum << '\n';
    cout << mx << '\n';
    cout << positive << '\n';
    return 0;
}
```

输入：

```text
5
-3 0 7 2 -1
```

输出：

```text
5
7
2
```

这段代码遍历固定次数，每次只进行常数次操作，时间复杂度为 `O(n)`。数组占用 `O(n)` 空间。

### 4. 易错点

- 题目保证 `n >= 1`，才可以直接用 `a[0]` 初始化最大值。
- 不要习惯性把最大值初始化成 `0`：数组全为负数时会出错。
- `i < n` 与 `i <= n` 不同，后者会访问 `a[n]`。
- 访问 `a[i]` 前先确认 `i` 合法；空数组没有第一个元素。

### 5. 练习 2

读入 `n` 和 `n` 个整数，输出其中偶数的个数及偶数之和，用一个空格分隔。满足 `0 <= n <= 10^5`，每个整数绝对值不超过 10⁹。

输入 `5` 和 `-4 1 0 8 3`，应输出 `3 4`。注意 0 也是偶数；当 `n=0` 时应输出 `0 0`。

## 03｜11/19：排序为主，字符串和函数为辅

### 1. 排序是后续算法的准备步骤

```cpp
sort(a.begin(), a.end());
```

需要 `#include <algorithm>`。`a.begin()` 指向第一个元素，`a.end()` 指向末尾之后的位置。这里采用左闭右开的范围：包含起点，不包含终点。因此空 `vector` 也可以直接调用这行排序。

默认按从小到大排序。若要从大到小，可以写 `sort(a.rbegin(), a.rend());`。`sort` 会改变原数组顺序，时间复杂度为 `O(n log n)` 量级。

### 2. 主例题：排序输出

读入 `n` 和 `n` 个整数，按升序输出，以空格分隔。满足 `0 <= n <= 10^5`。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    sort(a.begin(), a.end());

    for (int i = 0; i < n; ++i) {
        if (i > 0) cout << ' ';
        cout << a[i];
    }
    cout << '\n';
    return 0;
}
```

输入：

```text
5
3 -1 3 0 2
```

输出：

```text
-1 0 2 3 3
```

### 3. 字符串：像处理字符数组一样遍历

`string` 需要 `#include <string>`。`string s = "hello";` 创建字符串，`s.size()` 得到长度，`s[i]` 得到一个字符。正常遍历范围是 `0 <= i < s.size()`。

`cin >> s` 读取一个不含空白的单词；`getline(cin, s)` 读取一整行，能够保留行内空格。两者混用时，前一次 `cin >> n` 通常会留下换行，紧接着的 `getline` 可能读到空行。

对“接下来读一行、且行首空白不重要”的常见输入，可以使用 `getline(cin >> ws, s)`，它会跳过前导空白，**也会跳过空行和行首空格**。若这些空白有实际含义，需要按输入格式单独处理，不能直接套用。

下面是只读取一行的完整示例，输出其中数字字符的个数：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    getline(cin, s);
    int count = 0;
    for (char c : s) {
        if (c >= '0' && c <= '9') ++count;
    }
    cout << count << '\n';
    return 0;
}
```

输入 `Room 203`，输出 `3`。`for (char c : s)` 的含义是逐个取出字符串中的字符。

### 4. 函数：把一段操作命名

```cpp
long long add(int a, int b) {
    return 1LL * a + b;
}
```

把函数定义放在 `main` 前面，就可以在 `main` 中写 `cout << add(3, 5);`。`long long` 是返回类型，`a、b` 是形参，`return` 给出调用结果。这里使用值传递，形参接收实参的副本；修改函数内的 `a` 不会改变调用者原来的整数变量。

本节先掌握“看懂简单函数、会调用、知道返回什么”。引用、指针和复杂比较器在用到时再补。

### 5. 易错点

- `'7'` 是一个字符；`"7"` 是字符串字面量；整数 `7` 又是另一回事。数字字符 `c` 转成对应整数可用 `c - '0'`，前提是确认 `c` 在 `'0'` 到 `'9'` 之间。
- `sort` 排序后，原下标与原顺序可能改变。题目要求原下标时，要额外保存位置信息。
- 写自定义比较器时不能把普通升序比较写成 `a <= b`；本轮优先使用默认排序。

### 6. 练习 3

输入 `n` 和 `n` 个整数，升序排序后输出不同整数的个数。满足 `0 <= n <= 10^5`。

输入 `6` 和 `3 1 3 2 2 1`，输出 `3`。提示：排序后，相等的数相邻；空数组要单独考虑。

## 04｜11/20：枚举、模拟与复杂度

### 1. 枚举：把所有可能依次检查

先问“答案可能在哪里”，再问“怎样不重不漏地遍历”。例如找两个不同位置的元素，可以用 `i` 表示第一个位置、`j` 表示第二个位置，并规定 `j > i`，避免重复统计同一对。

### 2. 主例题：统计和为目标值的下标对

读入 `n、target` 和 `n` 个整数，统计满足 `i < j` 且 `a[i] + a[j] == target` 的下标对个数。满足 `0 <= n <= 2000`，每个整数和 `target` 的绝对值不超过 10⁹。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    long long target;
    cin >> n >> target;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    long long answer = 0;
    for (int i = 0; i < n; ++i) {
        for (int j = i + 1; j < n; ++j) {
            if (1LL * a[i] + a[j] == target) ++answer;
        }
    }
    cout << answer << '\n';
    return 0;
}
```

输入：

```text
4 4
1 3 1 3
```

输出：

```text
4
```

统计的是下标对，不是不同数值组合。第一个 `1` 可以与两个 `3` 分别配对，第二个 `1` 也一样。

### 3. 模拟：按题目规则维护当前状态

模拟不一定有复杂公式，关键是正确表达“现在是什么状态，执行下一步后怎样变化”。例如从位置 `x=0` 出发，遇到 `'R'` 就 `++x`，遇到 `'L'` 就 `--x`，依次执行完所有指令。不要一次凭直觉猜最终结果，要明确每条指令怎样更新状态。

### 4. 复杂度：关注规模增大时，工作量如何增长

| 复杂度 | 典型结构 | n=10⁵ 时的量级 |
| --- | --- | --- |
| `O(1)` | 固定次数计算 | 常数量级 |
| `O(log n)` | 二分查找 | 约十几到二十次判断 |
| `O(n)` | 单次遍历 | 约 10⁵ 次基本步骤 |
| `O(n log n)` | 排序 | 约百万量级基本步骤 |
| `O(n²)` | 枚举所有元素对 | 约 10¹⁰ 量级，通常太大 |

这是估算，实际耗时还取决于时限、硬件、常数和操作内容，不能把某个操作次数当作必过保证。两重循环也不一定是 `O(n²)`，要看总执行次数；本例检查约 `n(n-1)/2` 对，所以确实是 `O(n²)`。

### 5. 易错点

- 内层从 `j = i + 1` 开始，保证两个位置不同，同时避免重复数一对。
- 题目若只问“是否存在”，找到一对后可以立即输出并结束；如果问“有多少对”，不能提前结束。
- 朴素算法不因“朴素”就无效。数据范围小且复杂度合适时，它就是可用解法。

### 6. 练习 4

输入一个只包含 `L` 和 `R` 的非空字符串，长度不超过 10⁵。从数轴原点出发，每个 `L` 向左走 1，每个 `R` 向右走 1。输出运动过程中距离原点的最大距离，包含出发时刻。

输入 `RRLLL`，输出 `2`。提示：最终位置是 −1，但过程中的最远距离是 2。

## 05｜11/21：一维前缀和

### 1. 什么时候想到前缀和

数组不变，要多次询问某一连续区间的总和。每次从头加一遍会重复工作，先保存从开头到各位置的累计和，就能用两次查询相减得到答案。

为了减少下标混乱，本节统一采用：原题位置从 1 开始，`pre` 的长度是 `n+1`。

- `pre[0] = 0`：前 0 个数的和为 0。
- `pre[i]`：第 1 个数到第 `i` 个数的和。
- 建立关系：`pre[i] = pre[i-1] + a[i]`。
- 闭区间 `[l, r]` 的和：`pre[r] - pre[l-1]`。

例如数组为 `[2, -1, 3, 4]`，前缀和依次为 `[0, 2, 1, 4, 8]`。第 2 到第 4 个数之和为 `pre[4] - pre[1] = 8 - 2 = 6`。减掉的是区间开始之前的累计和。

### 2. 主例题：多次区间求和

输入 `n、q`，接着输入 `n` 个整数，再输入 `q` 对 `l、r`。每次输出第 `l` 到第 `r` 个数的和。满足 `1 <= n <= 10^5`、`0 <= q <= 10^5`、`1 <= l <= r <= n`，每个整数绝对值不超过 10⁹。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<long long> pre(n + 1, 0);

    for (int i = 1; i <= n; ++i) {
        long long x;
        cin >> x;
        pre[i] = pre[i - 1] + x;
    }

    while (q > 0) {
        int l, r;
        cin >> l >> r;
        cout << pre[r] - pre[l - 1] << '\n';
        --q;
    }
    return 0;
}
```

输入：

```text
4 3
2 -1 3 4
2 4
1 1
1 4
```

输出：

```text
6
2
8
```

建表 `O(n)`，每次查询 `O(1)`，总时间 `O(n+q)`，额外空间 `O(n)`。相比每次遍历区间的最坏 `O(nq)`，避免了重复求和。负数不影响前缀和的正确性。

### 3. 易错点

- `[l,r]` 两端都包含，减的是 `pre[l-1]`，不是 `pre[l]`。
- 1-based 的题目位置与 0-based 的数组下标不能随意混用。本例直接读入前缀数组，统一了题目位置和前缀位置。
- 累计和可能超出 `int`，使用 `long long`。
- 这份简单前缀和表针对静态数组；原数组变化后，原表不会自动更新。

### 4. 练习 5

把查询改为：统计第 `l` 到第 `r` 个数中，偶数有多少个。输入格式与上例相同。

对数组 `2 -1 3 4`，查询 `[2,4]` 应输出 `1`，查询 `[1,4]` 应输出 `2`。

提示：不必累计原数值，可以把“是不是偶数”变成 0 或 1 再累计。

## 06｜11/22：排序后的相向双指针

### 1. 本节解决什么问题

给出数组和目标值，判断能否选择两个不同位置的元素，使和等于目标值。这里不要求原下标，也不统计配对数量，因此可以排序后只判断存在性。

排序后令 `l=0`、`r=n-1`：

- 若 `a[l]+a[r] == target`，找到答案。
- 若和太小，`++l`，尝试更大的左端元素。
- 若和太大，`--r`，尝试更小的右端元素。
- 当 `l >= r` 时结束，不能使用同一个位置两次。

### 2. 为什么能这样移动

若最小的 `a[l]` 加上当前最大的 `a[r]` 都太小，那么 `a[l]` 与当前范围内其他元素的和也都太小。因此可以排除 `l`。反过来，若当前最小元素加 `a[r]` 都太大，那么 `a[r]` 与当前范围其他元素配对也都太大，可以排除 `r`。

每一步都能证明某个端点不可能参与当前剩余范围内的答案，这才是移动指针的依据。

例如有序数组 `[1,2,4,7]`、目标值 6：先算 `1+7=8`，右指针左移；再算 `1+4=5`，左指针右移；最后 `2+4=6`，找到答案。

### 3. 主例题：判断是否存在两数之和

输入 `n、target` 和 `n` 个整数，存在两个不同位置之和等于 `target` 时输出 `YES`，否则输出 `NO`。满足 `0 <= n <= 10^5`，每个数和 `target` 的绝对值不超过 10⁹。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    long long target;
    cin >> n >> target;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    sort(a.begin(), a.end());

    int l = 0, r = n - 1;
    while (l < r) {
        long long sum = 1LL * a[l] + a[r];
        if (sum == target) {
            cout << "YES\n";
            return 0;
        }
        if (sum < target) ++l;
        else --r;
    }

    cout << "NO\n";
    return 0;
}
```

输入：

```text
4 6
7 1 4 2
```

输出：

```text
YES
```

排序 `O(n log n)`，双指针扫描 `O(n)`，总时间 `O(n log n)`；若输入已经有序，可省去排序，扫描只需 `O(n)`。指针每次只向内移动，合计移动次数不超过 `n` 量级。

### 4. 易错点与适用边界

- 本模板依赖数组有序；对无序数组直接比较端点，排除逻辑不成立。
- `[3]`、目标 6，答案是 `NO`；`[3,3]`、目标 6，答案是 `YES`。要求不同位置，不要求不同数值。
- 本题只问存在性。统计下标对数量时，重复值需要额外处理，不能照搬这个模板。
- 双指针还有滑动窗口等形式；本节只学相向双指针，不把所有形式混在一起。

### 5. 练习 6

仍输入 `n、target` 和 `n` 个整数，满足 `2 <= n <= 10^5`、所有数和 `target` 绝对值不超过 10⁹。输出两个不同位置元素之和与目标值之间的最小绝对差。

输入 `4 8` 和 `1 4 6 10`，输出 `1`，因为 `1+6=7` 与 8 相差 1。

提示：每次都先更新当前最优差值，再按和的大小移动指针；能否解释这样不会漏掉更好的答案？

## 07｜11/23：二分查找，只固定一种写法

### 1. 本节统一采用左闭右开区间

学习目标：在升序数组中，找到“第一个大于等于 `x` 的元素位置”。若所有元素都小于 `x`，返回 `n`。

令 `l=0、r=n`，搜索范围是 `[l,r)`：

- `mid = l + (r-l)/2`。
- 若 `a[mid] < x`，`mid` 及其左边都不可能是所找位置，令 `l=mid+1`。
- 否则，所找位置可能就是 `mid`，也可能更靠左，令 `r=mid`。
- `l==r` 时结束，答案是 `l`。

**不变量：**下标小于 `l` 的元素都小于 `x`；下标大于等于 `r` 且小于 `n` 的元素都大于等于 `x`。每次更新都保持这一点，直到两边相遇。

例：数组 `[1,3,3,7]`、查找 `x=3`。初始 `[0,4)`，`mid=2`，值为 3，令 `r=2`；接着 `mid=1`，值为 3，令 `r=1`；接着 `mid=0`，值为 1，令 `l=1`。最后返回 1，即第一个 3 的下标。

### 2. 主例题：找到 x 的第一次出现位置

输入 `n、x`，接着输入已按升序排列的 `n` 个整数。若 `x` 存在，输出它第一次出现的 0-based 下标；否则输出 `-1`。满足 `0 <= n <= 10^5`。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, x;
    cin >> n >> x;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    int l = 0, r = n;
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] < x) l = mid + 1;
        else r = mid;
    }

    if (l < n && a[l] == x) cout << l << '\n';
    else cout << -1 << '\n';
    return 0;
}
```

输入：

```text
4 3
1 3 3 7
```

输出：

```text
1
```

二分部分时间为 `O(log n)`；本完整程序还要读入 `n` 个数，所以整体时间为 `O(n)`，存储数组为 `O(n)` 空间。

### 3. 库函数写法：理解后再使用

下面是语法片段，需要包含 `<algorithm>`：

```cpp
int p = lower_bound(a.begin(), a.end(), x) - a.begin();
int q = upper_bound(a.begin(), a.end(), x) - a.begin();
```

- `lower_bound`：第一个大于等于 `x` 的位置。
- `upper_bound`：第一个严格大于 `x` 的位置。
- 两者都可能得到 `n`，表示末尾之后，不能访问 `a[n]`。
- 在升序数组里，`q-p` 就是 `x` 的出现次数。`p、q` 通过迭代器相减转换为下标，本讲义的数据规模可用 `int` 保存。

### 4. 易错点

- `r=n` 是合法的区间边界，但不是合法的元素下标。循环保证 `mid<n`，才可以访问 `a[mid]`。
- 这里固定使用 `[l,r)`，不要混入闭区间模板的 `r=mid-1`。
- 使用 `l + (r-l)/2`，避免直接计算 `l+r` 可能带来的整数溢出。
- `l < n && a[l] == x` 中，`&&` 短路求值：前面为假时不访问后面的 `a[l]`，这能避免越界；左右顺序不要颠倒。
- 本节输入已经有序；如果自己先排序，得到的下标就属于排序后的数组。

### 5. 练习 7

输入 `n、x` 和一个升序数组，输出 `x` 的出现次数。满足 `0 <= n <= 10^5`。

输入 `6 3` 和 `1 3 3 3 7 9`，输出 `3`；如果 `x=4`，输出 `0`。可以先使用库函数完成；有余力再独立写两个边界查找。

## 09｜配套练习参考答案

建议做完各节练习后再看这里。每题都是单独运行的完整程序。

### 练习 1：前 n 项和

思路：等差数列求和，`n(n+1)/2`。读入时直接使用 `long long`，让中间乘法也采用足够大的整数类型。在本题范围内，`n(n+1)` 不会超出常见 64 位有符号整数范围。时间 `O(1)`，空间 `O(1)`。

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    cout << n * (n + 1) / 2 << '\n';
    return 0;
}
```

边界：`n=0` 输出 0；`n=1` 输出 1；`n=10^9` 输出 `500000000500000000`。

### 练习 2：偶数计数与求和

思路：不需要保留所有数，读入一个就判断一个。时间 `O(n)`，额外空间 `O(1)`。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int count = 0;
    long long sum = 0;
    for (int i = 0; i < n; ++i) {
        int x;
        cin >> x;
        if (x % 2 == 0) {
            ++count;
            sum += x;
        }
    }
    cout << count << ' ' << sum << '\n';
    return 0;
}
```

边界：没有元素时输出 `0 0`；全为奇数时也输出 `0 0`；负偶数仍应计入。

### 练习 3：不同整数的个数

思路：排序后，每段相同元素只有第一个需要计数。时间 `O(n log n)`，存储数组为 `O(n)` 空间。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    sort(a.begin(), a.end());

    int count = 0;
    for (int i = 0; i < n; ++i) {
        if (i == 0 || a[i] != a[i - 1]) ++count;
    }
    cout << count << '\n';
    return 0;
}
```

`||` 也会短路：`i==0` 为真时，不会访问 `a[-1]`。空数组不进入循环，输出 0。

### 练习 4：运动过程中的最远距离

思路：每一步更新位置，再更新到原点的最大距离。时间 `O(n)`；除存储输入字符串外，额外工作空间 `O(1)`。

```cpp
#include <iostream>
#include <string>
#include <algorithm>
#include <cstdlib>
using namespace std;

int main() {
    string s;
    cin >> s;
    int position = 0, answer = 0;
    for (char c : s) {
        if (c == 'R') ++position;
        else --position;
        answer = max(answer, abs(position));
    }
    cout << answer << '\n';
    return 0;
}
```

这里题目保证只有 `L/R`，因此 `else` 可以直接表示向左。不要把这种假设用于允许其他字符的题目。

### 练习 5：区间内偶数个数

思路：把每个元素转换为“是否为偶数”的 0/1 标记，再计算标记的前缀和。时间 `O(n+q)`，空间 `O(n)`。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<int> pre(n + 1, 0);
    for (int i = 1; i <= n; ++i) {
        int x;
        cin >> x;
        pre[i] = pre[i - 1] + (x % 2 == 0);
    }
    while (q > 0) {
        int l, r;
        cin >> l >> r;
        cout << pre[r] - pre[l - 1] << '\n';
        --q;
    }
    return 0;
}
```

表达式 `(x % 2 == 0)` 成立时转换为整数 1，不成立时为 0。本题计数最多为 `n`，可以用 `int` 保存前缀计数。

### 练习 6：最接近目标值的两数之和

思路：排序后维护两端指针，每次更新差值。若当前和小于目标值，固定左端元素时，换用更小的右端元素只会使差值更大，所以当前左端可以排除；和大于目标值时同理排除右端。和正好等于目标时最小差为 0，可立即结束。时间 `O(n log n)`，存储数组为 `O(n)` 空间。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cstdlib>
#include <climits>
using namespace std;

int main() {
    int n;
    long long target;
    cin >> n >> target;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    sort(a.begin(), a.end());

    int l = 0, r = n - 1;
    long long answer = LLONG_MAX;
    while (l < r) {
        long long sum = 1LL * a[l] + a[r];
        answer = min(answer, llabs(sum - target));
        if (sum == target) break;
        if (sum < target) ++l;
        else --r;
    }
    cout << answer << '\n';
    return 0;
}
```

题目保证 `n>=2`，一定存在可选的一对；给定数值范围内，`sum-target` 和绝对值都不会溢出。

### 练习 7：目标值出现次数

思路：第一个大于 `x` 的位置减去第一个大于等于 `x` 的位置。两个二分查找各为 `O(log n)`；完整程序包含读入，整体时间为 `O(n)`，空间 `O(n)`。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n, x;
    cin >> n >> x;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    auto left = lower_bound(a.begin(), a.end(), x);
    auto right = upper_bound(a.begin(), a.end(), x);
    cout << right - left << '\n';
    return 0;
}
```

`auto` 让编译器推导变量类型，这里是迭代器。相减得到两个边界之间的元素数。空数组、没有目标值时均输出 0。
