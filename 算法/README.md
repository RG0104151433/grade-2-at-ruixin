## 约定速查

- **命名**：目录 `NNNN-中文标题`；档案 `NNNN.md`；代码 `vN-做法关键词.cpp`。禁止空格、全角标点、主观评价、作者名。
- **状态**：`独立AC` / `提示后AC` / `看题解后AC` / `未AC` / `待复核` / `待重做`。
- **错因**：`读题错` / `边界漏` / `复杂度没达标` / `数据结构选错` / `证明不出` / `模板忘` / `实现bug` / `看题解太快`。
- **代码不改写**：已知有错的代码保留原样，只在档案里标 `待重做`，复习时才写新版本 `vN`。
- **编码**：UTF-8（无 BOM）；行尾 CRLF。
- 详细规则见 [`整理原则.md`](整理原则.md)。

## 自检

```bash
python 算法/tools/check.py          # 全部检查
python 算法/tools/check.py --quiet  # 只输出问题
```

检查四件事：`g++ -fsyntax-only` 是否通过、文件是否 UTF-8、命名是否合规、每个题目目录是否有同号档案。
