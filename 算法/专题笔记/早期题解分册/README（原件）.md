## 文档与代码的对应关系

- `文档保存/leetcode N.md` 与 `逐题代码/leetcode N/` 使用同一编号。
- 文档中的 `## 题号+题名` 对应同名 `.cpp` 文件；没有题号的标题（如“最长公共前缀”）直接对应中文文件名。
- 同一题保留多版解法时，代码文件用 `_1`、`_2` 区分，文档中通常也保留多个代码块。
- 个别文件包含同一题的错解/正解对照，例如 `2563数对数目.cpp`；`堆／有限序列（若干基础题）.cpp` 则集中了多个基础题。
- 原先夹在 `2300` 小节里的 `2563` 内容已补上独立标题和代码文件。

## 使用说明

这些代码是 LeetCode/OJ 风格的提交片段，通常只保留 `class Solution` 或目标函数，省略了 `#include`、`using namespace std;` 和 `main()`，因此不能直接单独编译成可执行文件。需要时补上头文件和测试入口，或直接贴回 LeetCode 提交框。

- C++ 题解可能使用 C++17/20 特性（如 `ranges::sort`、`popcount`），编译时加 `-std=c++17` 或更高。
- C 风格题解需要按需补 `<string.h>`、`<stdlib.h>`、`<limits.h>` 等头文件。
