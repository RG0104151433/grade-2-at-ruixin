LESSON 01

先建立判断流程

关键词只负责产生候选，约束与正确性才负责做决定。

学完这课，你应该能在动手写代码前，用 1–2 分钟说清：要求什么、哪些方法太慢、选哪个方法、前提是什么、为什么不会漏答案。

01 / 把题目压成五项

输入结构（数组/字符串/网格/图/树）、输出目标（存在/数量/最优值/方案）、数据规模、特殊约束、操作方式。子数组必须连续；子序列可以跳过元素，但保留相对顺序；集合通常不关心顺序。

02 / 先想一个肯定正确的朴素解

两数配对就枚举所有对；区间问题就枚举左右端点；选择问题就枚举选与不选。朴素解让你知道“慢在哪里”，小数据时它可能已经够用。

03 / 用范围做复杂度预算

算最坏操作量和空间，不只看 n：还要看查询数 q、值域 V、容量 W、操作次数 k、边数 m、多组数据总量与输出量。

04 / 找能省掉重复工作的结构

反复求区间和 → 前缀和；反复找最值 → 堆；反复访问相同状态 → 记忆化/DP；有序性使候选区间单调缩小 → 双指针或二分。

05 / 检查前提，给出证明与反例

例如“和越大左端越该右移”是否依赖正数？排序是否破坏原顺序？图的边权是否允许 BFS？不能只说“我见过类似题”。

可直接照着口述：
题目要 ___，规模是 ___；朴素解 ___，需要约 ___ 次操作；因为有 ___ 条件，可以用 ___ 减少 ___ 的重复；总复杂度 ___；它成立的理由是 ___；要检查 ___ 边界。
LESSON 02

用数据量、时限和内存排除算法

从时限推测阶数：一个可调整的经验模型

模型预计时间 ≈ c·F/R
保守工作量预算 B = s·R·t/c
筛选条件：F ≤ B

t：C/C++实际适用的时限（秒）；F：全部数据的主导工作次数，如n²、nW、q·n、Σnᵢ²；R：每秒简单操作的参考吞吐量；c：每个模型步骤相当于多少基本工作；s：留余量系数。“一步”不是一行C++，也不是严格的CPU指令。

先记简化式：F ≤ 3×10⁷×t。
取R=10⁸、s=0.3、c=1：1秒先按约3000万步、2秒约6000万步筛候选。它是针对轻量计算的保守教学起点，不是评测机标定速度或AC保证，也会排除一些实际能过的实现。

G组同规模n，且每组F=nᵖ时：G·nᵖ≤B → p≤log(B/G)/log(n)（n>1，G≥1）。这只适用纯多项式候选；含log、指数、多参数的算法应直接代入全部F。初始化、I/O与输出也要计算，不能漏掉。

F的一步若包含m次操作，应把m计入F；不要又用c重复计算相同成本。哈希、字符串比较、树节点跳转、除法和内存分配不能按整数加法的速度直接估计。C与C++都应看具体操作，而非只按语言名折算。

按MiB换算：A = β·M·2²⁰ − H

二维数组：行数×列数×b ≤ A

三组检查

  • 5000²个long long约200MB≈190.7MiB；256MiB下超过默认70%主数组预算，且还未加其他对象。超保守预算不代表必定超硬限制，但应考虑压缩。
  • n=20时，2ⁿ个long long为8MiB；每个子集再存n个long long就是160MiB。状压不能只看位掩码本身。
  • 01背包从n×(W+1)滚动到W+1，long long约8(W+1)字节，时间通常仍O(nW)。需要输出方案时另计决策保存/重建。
时间与空间是两道门槛。多组逐组处理并复用时，时间相加、内存取峰值；若同时保存所有组/结果，空间也要累加。算法复杂度中的空间应明确是否包含输入、输出、辅助容器与递归栈。

时间＋内存预算实验台

假设G组同规模并逐组复用内存；K填写峰值同时存活的同类型元素数。真实多组不同规模请算ΣF(nᵢ)。

数据规模通常能排除算法，却不能单独确定算法。下面是竞赛中的粗略起点，不能作为“保证能过”的秒数表。

规模线索优先评估的量级为什么 / 注意
n ≈ 10阶乘、指数搜索也可估算10! ≈ 363 万；20! 已极大。还要乘每个方案的处理成本。
n ≈ 20子集枚举、状压 DP2²⁰ ≈ 105 万；n·2ⁿ ≈ 2100 万，和单纯 2ⁿ 不一样。

n ≈ 100,000优先 O(n log n) 或 O(n)n² = 100 亿，n log₂n ≈ 166 万。
n ≈ 1,000,000优先线性或接近线性读取本身就是 O(n)；排序也可能可行，要看时限和常数。
数值到 10⁹ / 10¹⁸对数级、数学或按位分析数值大不等于元素多；别直接开同等大小的数组。

六个容易漏掉的预算

  • 多组数据：总时间看 Σf(nᵢ)。若 T=100、每组 n=2,000，二次循环可能达到 4 亿级；若限制 Σn≤2,000，预算则不同。
  • 查询次数：静态数组 n=10⁵，q=10⁵ 次区间和；逐次扫描最坏 O(nq)，前缀和总 O(n+q)。有单点更新时，静态前缀和不再直接适用，可评估树状数组/线段树。
  • 值域：计数数组 O(n+V)，不是无条件 O(n)。n=10⁵、V=100 与 V=10⁹ 是两道不同的题。
  • 状态总数：01 背包通常 O(nW)；n 小但 W 极大也可能不行。“有 DP”不等于“DP 能过”。
  • 空间：常见 C++ 环境 10⁷ 个 4 字节 int 约 40 MB；二维 10⁵×10⁵ 不可直接开。再加上其他数组与容器开销。
  • 数值与输出：n=10⁵ 时，子数组个数 n(n+1)/2=5,000,050,000，超过 32 位有符号 int。若要输出所有方案，输出量本身也是时间下界。

LESSON 04

四组易混算法

① 滑动窗口 vs 前缀和

滑窗：维护一个可逐步移动的区间，依赖窗口状态能增删以及边界移动的依据。定长求和不依赖正负；变长和阈值窗口通常依赖正数/非负数等单调条件。

前缀和：把区间聚合转成两个前缀的关系。静态查询做差；“和等于 k 的个数”再配历史频次。

反例：在 [1,−1,5] 中找和 ≥5 的最短区间，常见正数模板第一次满足后删掉 1，和变成 4 就停，漏掉 [5]。负数破坏了该收缩规则。

② 二分查位置 vs 二分答案

位置二分：在已排序数据中找边界，一次查询 O(log n)。

答案二分：在容量/时间等数值范围中找可行边界，一次判断可能扫完整个数组；总复杂度 O(check 成本 × log U)。

例如 1011：容量变大不会让运输更困难，因此 check 呈“假…假、真…真”。“题目求最小”本身不能证明这个性质。

③ 堆 vs 单调栈 vs 单调队列

堆：维护动态集合中的全局最值。

单调栈：求每个位置左右最近满足大小关系的位置，常存下标。

单调队列：维护按顺序滑动窗口的最值，旧下标可从队头过期；在标准窗口最值问题中可做到 O(n)。

判断时补全一句：“最值是整个集合的、固定窗口的，还是每个位置的最近更大者？”

④ DFS / BFS vs 并查集

静态连通块：DFS、BFS、并查集都可能正确，选最简单且满足复杂度的实现。

无权最短路：BFS 分层第一次到达就是最少边数；普通 DFS 首次找到的路未必最短。

动态加边连通：并查集更自然；它维护“是否同组”，不记录一般最短距离。

深链/大网格递归可能过深，可改显式栈 DFS 或队列 BFS。

LESSON 05

用你的题目练判断

先读题设，自己说出候选与前提，再展开。这里明确标注的 n 为教学变式，不是对原题约束的转录。

案例 1｜0001 → 0167：只改“有序”条件

已知：无序数组，两数之和返回原下标。教学变式 n=10⁵。

推理链：暴力 O(n²) 太大；先查询 target−x 是否在历史哈希表中，再登记 x，期望 O(n) 时间、O(n) 空间。查询在登记前，避免复用自己。

改变条件再想：若题目已保证有序（0167），可用相向双指针 O(n)、额外 O(1)。若先排序来做 0001，需要同时保存原下标，并承担排序 O(n log n)。

回看资料：0001 → 0167

案例 2｜0209 → 0560：连续区间，目标却不同

已知：正数数组，求和 ≥S 的最短连续子数组。

推理链：0209 的变长滑窗：右扩增和，满足时不断左缩并更新；每个指针最多走 n 次，O(n)。

改变条件再想：0560 是“含负数、和恰好 k 的数量”，用 pre[r]−k 查历史前缀频次，期望 O(n)。不能把“连续”直接翻译成滑窗。

回看资料：0209 → 0560

案例 3｜1011：把求最优改成判断能否做到

已知：包裹按原顺序装船，D 天内完成，最小载重。

推理链：容量 C 越大越容易；check(C) 按顺序尽量装满当天，统计天数是否 ≤D。下界 max(w)，上界 sum(w)，总 O(n log U)，空间 O(1)，U 为搜索区间大小。

改变条件再想：若重新排序包裹，会破坏原顺序约束；若只说“最小所以二分”，就没有完成论证。容量和求和宜用 long long。

回看资料：1011

案例 4｜2530：静态排序还是动态最值？

已知：反复 k 次取当前最大值，计分后修改并放回。

推理链：用大顶堆。批量堆化 O(n)，每次弹出/插入 O(log n)，总 O(n+k log n)，空间 O(n)。逐个插入建堆则 O(n log n+k log n)。

改变条件再想：仅开始排序一次无法保证修改后的顺序；每轮重新排序 O(kn log n) 太贵。若 k=1，一次扫描通常更简单。

回看资料：2530

案例 5｜0015：降低候选数，而非只换容器

已知：三数之和，输出不重复的值三元组；教学变式 n=2,000。

推理链：三重枚举约 80 亿级；排序后固定 i，剩下两数用双指针，每轮 O(n)，总 O(n²)。对固定值及命中后的左右值分别跳过重复。

改变条件再想：用 set 事后去重会引入对数开销及结果存储。双指针扫描本身额外 O(1)，常见 std::sort 递归栈还需 O(log n)，输出空间另算。

回看资料：0015

案例 6｜0274：值很大，答案却很小

已知：n 篇论文的引用次数可能很大，求 H 指数。

推理链：h 不可能超过 n，所有引用数 >n 的值可合并到 n 桶。O(n) 时间和 O(n) 空间，倒序累计“至少 i 次引用”的篇数。

改变条件再想：不能机械地为原始值域开数组；能截断是因为 >n 的值对任何候选 h 都等价，不是因为“大数不重要”。

回看资料：0274

案例 7｜0563：递归并不自动等于线性

已知：每个树节点要左右子树和之差的绝对值，再求总和。

推理链：如果每个节点都重新求子树和，链状树最坏 O(n²)。后序递归返回子树和，顺便累加坡度，每个节点处理一次，O(n) 时间、O(h) 栈空间。

改变条件再想：平衡树 h≈log n，链状树 h=n。分析复杂度不能只画平衡树；需要时改迭代后序。

回看资料：0563

LESSON 06

证明、边界与反例

四种常用的正确性说明

  1. 排除法：有序配对中 a[l]+a[r]<target，则 a[l] 与区间内任一更小右端配对也太小，故可以舍弃 l。
  2. 不变量：扫描到 r 前，哈希表只记录左边的前缀；查 pre[r]−k 恰好数出以 r 结尾的合法区间，先查后存避免空区间混入。
  3. 单调性：容量 C 能完成运输，那么 C′≥C 也能复用同一装载方案，因此可行值形成后缀。
  4. 归纳 / 最优子结构：若左右子树和已正确，当前子树和与坡度可直接合成；贪心则需交换论证等理由，不能仅凭样例。

用最小反例拦住错误直觉

“最少硬币就每次取最大”

面额 [1,3,4]，金额 6：贪心取 4+1+1 共 3 枚，最优 3+3 共 2 枚。一般面额用 DP，时间 O(面额数×金额)。

“递增子序列可以先排序”

[3,1,2] 的 LIS 长度是 2；排序后变成 3。排序破坏了原来的相对顺序，改变了问题。

提交前的五个检查点

  • 空输入是否允许？单元素、全相同、全不满足、目标为 0 有没有处理？
  • 数组或网格被修改后，是否符合题目要求？原下标、顺序是否仍然可用？
  • 前缀和、答案数量、乘法中间值是否会溢出？C++ 中应在乘法发生前转成 long long。
  • 复杂度按最坏结构算了吗？双层 while 不一定二次：若每个元素仅入栈出栈一次，则总 O(n)。
  • 时间过关之外，是否能说明“不漏解、不重复、终止”？给不出时先用小反例挑战自己。
结合你的错因记录：每次先写三句话——我保留了哪些候选？为什么排除其余候选？最终算法为什么不会漏掉正确答案？这比只记模板更能训练判断。

算法概述：做法、前提与成本

概述不仅给算法名，还说明做法、前提和成本。扩展名词提供定位，不代表已完成对应复习。

排序、枚举、回溯与剪枝

怎么做：排序按键重排，使大小关系可利用；枚举列候选，回溯依次选择/深入/撤销，剪枝跳过已证明不可能或不优的分支。

适用条件：排序不得破坏原顺序；搜索适用于小解空间或有效且安全的剪枝。

成本与限制：排序常O(n log n)；子集2ⁿ、排列n!，还需乘每候选成本。递归空间随深度，不能凭“剪枝很多”声称多项式。

哈希、有序映射与计数桶

怎么做：哈希按键定位频率/位置；map用有序树维护键；桶将频次存到值对应的下标。

适用条件：等值查询可用哈希；有序边界考虑map/set；桶要求V可控或可证明截断等价。

成本与限制：哈希期望单次O(1)，最坏退化；map单次O(log n)；桶O(n+V)、空间O(V)。字符串键长度与节点/桶内存另算。

前缀和、前缀状态与差分

怎么做：前缀存前i项累计量，区间和由两前缀相减；异或/字符奇偶也可匹配历史状态；差分存相邻变化，把区间加改成两端修改后统一还原。

适用条件：区间信息必须能从前缀恢复；差分适合批量修改、最后输出。

成本与限制：静态查询总O(n+q)，前缀配哈希期望O(n)，空间O(n)。区间最小值不能由两个前缀最小值相减。

双指针与滑动窗口

怎么做：相向指针从有序两端靠近排除配对；快慢指针维护读写区域；滑窗维护连续区间状态并移动边界。

适用条件：先说明前进不漏解；变长窗口需有合法边界移动依据，定长求和允许负数。

成本与限制：端点只前进、状态O(1)更新时O(n)；先排序另加O(n log n)。频次或队列空间依维护状态而定。

二分位置与二分答案

怎么做：对单调真假边界比较中点并舍弃半段；位置二分查有序边界，答案二分猜容量/时间后执行check。

适用条件：先定义区间、真假方向、无解约定并证明单调，不能只因求最小就二分。

成本与限制：位置O(log n)，答案O(check×log U)；空间看check。上下界、mid与累计量防溢出。

普通栈、单调栈、单调队列与堆

怎么做：普通栈存最近未处理者；单调栈按大小保留候选下标，找最近更大/小；单调队列删除过期及被支配候选；堆维护集合全局动态最值。

适用条件：区分最近邻、窗口最值和集合全局最值，不因最大/最小字样混用。

成本与限制：标准栈/单调队列扫描O(n)，空间最坏O(n)；堆每次更新O(log n)，批量建堆O(n)，另计过期条目。

DFS、BFS、并查集与Dijkstra

怎么做：DFS深入分支再回退；BFS用队列分层；并查集用代表元与合并维护同组；Dijkstra每次弹最小暂定距离，再尝试用出边改善邻点距离（松弛）。

适用条件：静态遍历可DFS/BFS；等代价最短路用BFS；加边连通用并查集；Dijkstra要求非负权。

成本与限制：邻接表遍历O(n+m)，网格O(行×列)；并查集路径压缩加按大小合并单次均摊O(α(n))。堆版Dijkstra常写O((n+m)log n)，任意重边懒删除实现可保守写O((n+m)log(n+m))。空间含图和队列/堆。

树递归与树形DP

怎么做：确定给父节点返回的子树信息和向孩子传的路径状态；树形DP增加每节点选/不选等状态并合并子树。

适用条件：树结构/父子方向明确；状态覆盖影响上层的条件。

成本与限制：简单合并O(n)，栈O(h)，链状h=n；树形DP还要乘每节点状态及合并成本，非自动线性。

DP、记忆化、背包与计数DP

怎么做：缓存重复子问题，记忆化递归按需算、递推按依赖顺序算；01背包容量倒序防重取，完全背包可重取常用正序；计数将互斥来源方案数相加。

适用条件：先定义状态、初值、转移、顺序和答案位置；计数明确顺序是否区分方案。

成本与限制：常规背包O(nW)，滚动空间O(W)；一般看状态数×转移成本。求最小/最大/计数的初值和聚合不同。

贪心、模拟与LIS

怎么做：模拟按规则推进；贪心固定可证明不劣的局部选择；严格LIS的tails记各长度最小结尾，按原序扫描用lower_bound替换/追加。

适用条件：贪心需交换论证等理由；LIS不能先排序原数组，tails也未必是一条真实答案子序列。

成本与限制：排序贪心常O(n log n)，依实现而定；LIS二分法O(n log n)、空间O(n)。

树状数组、线段树与DP扩展

怎么做：树状数组用lowbit分块维护前缀；线段树递归存区间聚合，懒标记延后传播修改。区间DP用dp[l][r]枚举断点；状压用掩码存集合；DP队列优化维护滑动转移中的最优候选。

适用条件：动态结构需匹配修改/查询种类；区间可合并、小集合可编码、候选支配可证明时才用相应DP。

成本与限制：常见树状/线段树操作O(log n)、空间O(n)；区间DP常O(n³)/O(n²)空间；状压常O(n2ⁿ)或O(n²2ⁿ)。这里只定位，完整专题待复习。

快速幂、异或与按位分析

怎么做：快速幂按指数二进制逐次平方、按位乘入；异或同位相同为0不同为1，可消去成对同值；按位分析统计贡献或守恒。

适用条件：指数非负，取模mod>0；位运算各位独立不代表目标与操作可逐位独立优化。

成本与限制：快速幂O(log e)，统计n个B位数常O(nB)。模乘中间值先检查范围，%mod不能补救已溢出乘法。

置换环与环形移位

怎么做：固定目标位置时建立原位置→目标位置映射，长L的环需L−1次任意位置交换，总n−环数；环形移位可取模后三次反转。

适用条件：环公式须固定目标身份且允许任意交换；重复值可互换时随意按原下标定序未必全局最少，相邻交换也是不同模型。

成本与限制：数环O(n)、空间O(n)，先建排序映射另加O(n log n)；三次反转O(n)、额外O(1)。
