# 模式：在有序结构上二分

## 一句话

二分的本质不是"数组有序"，而是**一段区间上的判定具有单调性**。先把问题整理成"按某个键有序"，再在键上二分。

## 识别信号

- 题目问"最小的满足 …… 的位置 / 最大的满足 …… 的值"
- 能在 O(1) 或 O(log n) 内判定"位置 p 是否可行"
- 数据本身无序，但**排序后**可以二分；或者要反复查询"≥ x 的第一个元素"
- 常见变体：答案二分（二分答案后 check）、树上/矩阵上二分

## 模板

```cpp
// 写法一：闭区间，找第一个 >= aim 的位置
int l = 0, r = n - 1;
while (l < r) {
    int mid = l + (r - l) / 2;
    if (key(mid) < aim) l = mid + 1;   // mid 不满足 → 答案在右边
    else r = mid;                      // mid 满足 → 答案可能是 mid
}
if (key(l) >= aim) { /* l 就是答案 */ } // 注意：若全部不满足，l 会停在最后一个元素，必须再验一次
```

要"最后一个 <= x"时，把比较方向反过来，或者二分 `> x` 的第一个位置再减一。

## 我的易错点

- 二分完**没有再验一次** `key(l) >= aim`：如果全部不满足，`l` 会停在最后一个元素上，直接当成答案就错
- `mid = (l + r) / 2` 在 `l + r` 溢出时会挂，写 `l + (r - l) / 2`
- 排序会破坏下标：题目要原下标时，必须把下标打包进结构体/`pair` 一起排（`0436` 的 `record`）
- `while (l < r)` 的区间语义（闭/半开）必须从头到尾一致，别一半闭一半开
