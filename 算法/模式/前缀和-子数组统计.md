# 模式：前缀和 / 前缀状态 —— 子数组统计

## 一句话

"子数组的和/异或/某种状态等于目标"的问题，把"区间查询"变成"两个前缀之差"，再用哈希表或数组统计之前的每个前缀出现了几次。

## 识别信号

- 题目问"有多少个子数组满足 ……"、"最长的满足 …… 的子数组"
- 条件对区间**可减**（和、异或、出现次数），于是"区间 = 前缀 − 前缀"
- 直接枚举左右端点会到 O(n²)，而 n 到了 10⁵
- 出现"偶数次/奇数个"这种**只关心奇偶**的要求 → 前缀状态可以压成位

## 模板

> 【计挑赛补充 2026-11-21】“连续区间”还不足以决定滑窗或前缀统计；先检查负数、目标是最长/最短还是计数。下文末尾有反例。

**A. 前缀和 + 哈希计数**（子数组和 = k）

```cpp
unordered_map<long long,int> cnt{{0, 1}};   // 空前缀算 1 次
long long pre = 0, ans = 0;
for (int x : nums) {
    pre += x;
    ans += cnt[pre - k];                    // 之前有多少个前缀 = pre - k
    cnt[pre]++;
}
```

**B. 前缀状态 + 位压缩**（奇偶性）

```cpp
int mask = 0, ans = 0;
vector<int> first(1 << 5, -1);  // 每个状态第一次出现的位置
first[0] = 0;
for (int i = 0; i < n; i++) {
    mask ^= 1 << (s[i] - 'a');              // 翻转这一位
    if (first[mask] == -1) first[mask] = i + 1;
    else ans = max(ans, i + 1 - first[mask]);
}
```

## 我的易错点

- `cnt[0] = 1` 忘了写，会把"从下标 0 开始的子数组"漏掉
- 前缀和用 `int` 溢出（n·max 到 10¹⁰）
- 前缀和做差时的下标错位：`sum[i..j] = pre[j+1] − pre[i]`，用 `pre` 存"前 i 个"要小心
- "奇偶/出现次数"类：状态是**压缩后的**，不是原数组；`first[状态]` 存的是"这个状态第一次出现在第几个前缀"
- 2913 那种"值域小"的题，用 `pre[i][v]` 二维数组是 O(n·V)，值域大时会爆

## 【计挑赛补充 2026-11-21】前缀统计与滑窗的分界

审读顺序：是否连续？求数量还是长度？是否含负数？能否改变顺序？例如“允许负数、统计和为 k 的连续子数组”可写成 `pre[r]-pre[l]=k`，即查询历史 `pre[r]-k` 的出现次数。排序会破坏连续关系。

**先查后存：**先累加 `ans += cnt[pre-k]`，再 `++cnt[pre]`；`cnt[0]=1` 表示数组之前的空前缀。若 `a=[0], k=0`，答案应为 1；先存会把当前前缀与自己配成空区间，得到 2。空前缀是合法边界，空区间不是本题允许的答案。

**不要只记一个位置：**本题求数量，应存频次；同一前缀可有多个位置。若换成“最长和为 k 的区间”，才可考虑保存每个前缀最早出现的位置。维护什么由输出目标决定。

普通正数“和至少为 S 的最短区间”滑窗依赖扩张增和、收缩减和。改成允许负数后，这个规则可能失效；但不能泛化为“任何滑窗都不允许负数”，定长窗口求和仍可处理负数。

上文 B 仅是五位状态的结构示意，不能对任意字符直接执行 `1<<(s[i]-'a')` 后访问 32 个元素。用于 1371 时，应把五个元音映射到 0—4，其余字符不翻转；否则可能越界。这一提醒不改变 A 的子数组和模型。
