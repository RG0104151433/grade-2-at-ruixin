# 模式：前缀和 / 前缀状态 —— 子数组统计

## 一句话

"子数组的和/异或/某种状态等于目标"的问题，把"区间查询"变成"两个前缀之差"，再用哈希表或数组统计之前的每个前缀出现了几次。

## 识别信号

- 题目问"有多少个子数组满足 ……"、"最长的满足 …… 的子数组"
- 条件对区间**可减**（和、异或、出现次数），于是"区间 = 前缀 − 前缀"
- 直接枚举左右端点会到 O(n²)，而 n 到了 10⁵
- 出现"偶数次/奇数个"这种**只关心奇偶**的要求 → 前缀状态可以压成位

## 模板

**A. 前缀和 + 哈希计数**（子数组和 = k）

```cpp
unordered_map<long long,int> cnt{{0, 1}};   // 空前缀算 1 次
long long pre = 0, ans = 0;
for (int x : nums) {
    pre += x;
    ans += cnt[pre - k];                    // 之前有多少个前缀 = pre - k
    cnt[pre]++;
}
```

**B. 前缀状态 + 位压缩**（奇偶性）

```cpp
int mask = 0, ans = 0;
vector<int> first(1 << 5, -1);  // 每个状态第一次出现的位置
first[0] = 0;
for (int i = 0; i < n; i++) {
    mask ^= 1 << (s[i] - 'a');              // 翻转这一位
    if (first[mask] == -1) first[mask] = i + 1;
    else ans = max(ans, i + 1 - first[mask]);
}
```

## 我的易错点

- `cnt[0] = 1` 忘了写，会把"从下标 0 开始的子数组"漏掉
- 前缀和用 `int` 溢出（n·max 到 10¹⁰）
- 前缀和做差时的下标错位：`sum[i..j] = pre[j+1] − pre[i]`，用 `pre` 存"前 i 个"要小心
- "奇偶/出现次数"类：状态是**压缩后的**，不是原数组；`first[状态]` 存的是"这个状态第一次出现在第几个前缀"
- 2913 那种"值域小"的题，用 `pre[i][v]` 二维数组是 O(n·V)，值域大时会爆
