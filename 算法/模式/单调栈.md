# 模式：单调栈

## 一句话

要找每个元素"左边/右边第一个比它大/小的元素"时，用一个**单调**的栈，每个元素只入栈出栈一次，整体 O(n)。

## 识别信号

- 题目出现"下一个更大/更小的元素"、"左右最近的更大值"、"接雨水/柱状图面积"、"每日温度"
- 需要为每个位置找一个**最近的、满足大小关系的邻居**
- 朴素做法是"往两边扫"，最坏 O(n²)，而 n 到 10⁵
- 想用"两端的最大值/最小值"做哨兵（可以省掉边界判断）

## 模板

```cpp
vector<int> ans(n);
vector<int> st;                       // 存下标，不存值（方便算距离）
for (int i = 0; i < n; i++) {
    while (!st.empty() && nums[st.back()] < nums[i]) {  // 当前元素更大 → 栈顶的答案就是 i
        int j = st.back(); st.pop_back();
        ans[j] = i - j;                                    // 最近的更小/更大在 i
    }
    st.push_back(i);
}
// 栈里剩下的元素：右边没有比它更大的，按题目要求补默认值
```

要"左边第一个更小"就把遍历方向反过来；要"最长宽度坡"就维护一个**严格递减**的下标栈再反向扫。

## 我的易错点

- 栈里存**下标**还是**值**：要算距离/宽度就必须存下标
- 单调方向写反：找"下一个更大"时栈应**递减**（从栈底到栈顶递减），遇到更大的就弹
- 弹栈时忘记记录答案，或者记录的 `j` 与 `i` 弄反
- 收尾：遍历结束后栈里还有元素，它们"右边没有更大的"，要按题意补 0 / -1
- `0084` 的哨兵很好用，但要知道"多出来的哨兵不能算进答案里"
