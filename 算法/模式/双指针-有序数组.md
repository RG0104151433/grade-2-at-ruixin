# 模式：有序数组上的双指针

## 一句话

**先排序**，再把"枚举两个数"的 O(n²) 换成"左右指针各走一遍"的 O(n)，整体 O(n²) → O(n log n) 或 O(n²) → O(n)。

## 识别信号

- 题目要"两数 / 三数之和"、"配对"、"最大配对数"这类成对关系
- 数组本身有序，或**允许排序**（顺序不影响答案）
- 朴素做法是二重循环枚举下标对
- 需要原地、O(1) 额外空间

## 模板

```cpp
sort(nums.begin(), nums.end());
int l = 0, r = n - 1;
while (l < r) {
    int s = nums[l] + nums[r];
    if (s < target) l++;        // 和太小，只能让小的变大
    else if (s > target) r--;   // 和太大，只能让大的变小
    else { /* 命中 */ l++; r--; }
}
```

三数之和：外层固定 `i`，内层就是对 `[i+1, n-1]` 做上面的两数之和，`target = -nums[i]`。

## 例题

| 题号 | 这题贡献了什么 |
| --- | --- |
| `0015` 三数之和 | 排序 + 外层固定一个数 → 退化成 167；难点全在**去重**，不在指针 |
| `1679` K 和数对的最大数目 | 同一个模板，目标是"对数最多"；排序后贪心配对即最优，不需要考虑配给谁 |
| `0189` 轮转数组 | 反向用法：双指针是"反转"的实现手段，不是求和 |

## 我的易错点

- 去重的三处位置：外层 `nums[i] == nums[i-1]`、命中后 `l` 跳过相同值、`r` 跳过相同值。少一处就重复
- `while (l < r)` 不是 `l <= r`（`l == r` 时同一个元素用两次）
- 排序会打乱原下标 → 题目若要求返回下标，必须另外存 `(值, 原下标)` 再排（见 `0436`）
- 三数之和的两种等价写法：固定最左（`i, l, r`）或固定中间（`l, mid, r`）。后者也能做，但边界更容易写错，且去重要靠 `set`
