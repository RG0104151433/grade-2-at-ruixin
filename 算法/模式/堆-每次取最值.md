# 模式：堆 —— 每次取最值

## 一句话

需要**反复取当前最大/最小、取完再放回去**时，用堆（`priority_queue`）把每次 O(n) 的扫描降到 O(log n)。

## 识别信号

- 题目说"重复 k 次，每次选最大/最小的元素做某个操作"
- 要求"动态维护前 k 大 / 前 k 小"
- 每次都重新排序会超时（k 到 10⁵，n 到 10⁵）
- 需要"取最值 + 放回修改后的值"

## 模板

```cpp
// 每次取最大值：默认 priority_queue 就是大顶堆
priority_queue<int> pq(nums.begin(), nums.end());
while (k--) {
    int x = pq.top(); pq.pop();
    x = /* 对 x 做操作 */;
    pq.push(x);
}

// 需要区分"值相同但下标不同"时，把下标一起塞进去
priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq; // 小顶堆
```

要"原地堆化、省掉额外数组"时：`make_heap` / `pop_heap` / `push_heap`（`algorithm` 里的三件套）。

## 我的易错点

- 只存值不存下标 → 值相同的元素无法区分，改错元素（`3264` 就是为此要 `pair<int,int>`）
- 忘记把修改后的值推回堆（`1046` 的差值可能是 0，0 不用入堆；但 `2558`/`2530` 必须入）
- `priority_queue` 的第三个模板参数：**小顶堆要写 `greater<pair<int,int>>`**，写 `greater<int>` 配 `pair` 编译不过
- 结果要 `long long`（`2530`/`2558` 的和会超 `int`）
- 复杂度别算错：k 次操作 × O(log n) = O((n + k) log n)
