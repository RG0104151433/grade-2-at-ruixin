# 模式：按位独立 —— 每一位分别考虑

## 一句话

AND / OR / XOR 在**每一位上互不干扰**，所以"最大化某个位运算结果"的题可以先拆成 31 个独立的 0-1 问题，再把"每个数能贡献多少"重新组装。

## 识别信号

- 题目出现 AND / OR / XOR / 左移右移
- 操作是"两个数之间改成 AND/OR"，问最大和、最大平方和、最少次数
- 难度标着"困难"，但数据范围只到 10⁵，且值 ≤ 10⁹（↔ 31 位）
- 直觉想"排序"却说不清排什么 —— 因为真正该排序/统计的不是元素，是**位**

## 两种子型

**A. 位数统计 + 重新堆叠**（`2897`）

```cpp
vector<int> cnt(31);
for (int x : nums) for (int i = 0; i < 31; i++) cnt[i] += (x >> i) & 1;
// AND/OR 操作不改变每一位上 1 的总个数 → 想让平方和最大，就把 1 尽量堆到同一个数上
```

**B. 上界 + 可达性证明**（`3644`）

```cpp
int k = -1;                       // 全 1
for (int i = 0; i < n; i++) if (nums[i] != i) k &= nums[i];
return max(k, 0);
```

`k` 必须是每个错位元素的子集 → 上界是它们的 AND；再用"0 号元素做三次交换实现任意对换"证明上界可达。

## 我的易错点

- 位运算题别急着排序元素：`2897` 排序元素没有意义，元素身份会被操作打乱
- `1 << i` 在 `i = 31` 附近要用 `1LL << i`；答案对 1e9+7 取模时，`long long` 只在乘法处需要
- `k` 的初值必须是"全 1"（`-1`），不能是 `0`
- `(!cnt[i] == 0)` 这种写法虽然碰巧对（`!cnt[i]` 变成 bool 再和 0 比），但语义全绕，写成 `cnt[i] != 0`
