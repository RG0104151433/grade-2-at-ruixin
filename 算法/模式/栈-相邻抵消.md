# 模式：栈 —— 相邻抵消

## 一句话

一维序列里"相邻两个元素满足某条件就一起消失"，用栈维护"还没被消掉的元素"，新元素只和栈顶结算。

## 识别信号

- 题目出现"相邻的相同/相反元素可以消除"、"重复项删除"、"碰撞"
- 消除之后**可能产生新的相邻关系**（也就是说不能一趟扫描了事）
- 答案要求"剩下的序列"或"消除的步数"
- 数据是"一串"，且只在**相邻**之间发生交互

## 模板

```cpp
vector<int> st;
for (int x : seq) {
    if (!st.empty() && /* x 与栈顶满足消除条件 */) {
        st.pop_back();          // 结算栈顶
        // 如果需要连消，这里要 while 而不是 if
    } else {
        st.push_back(x);        // 入栈继续等
    }
}
// 栈里剩下的就是答案
```

判断"要不要 `while`"的问法：**消掉之后，新元素会不会和新的栈顶再次满足条件？** 会就用 `while`。

## 我的易错点

- **`if` 写成 `while` 或者反过来**：`1047` 用 `while` 也不会错（只是多做一次判断），但 `0735` 用 `if` 一定错
- 入栈条件写反：`0735` 里"栈空 / 同向"都应直接入栈，只有"栈顶向右、当前向左"才打
- 消掉一个之后忘了继续处理当前元素（存活标记 `alive`）
- 栈里存"字符"还是"计数"——连续 k 个的题必须存计数
