# 模式：树的递归 —— 返回值与传参设计

## 一句话

树上递归先回答两个问题：**需要子树给我什么**（返回值），**我需要带什么下去**（参数）。
把这两个方向定清楚，代码只剩三行。

## 识别信号

- 输入是 `TreeNode*`，要求整棵树的某个量（深度、和、路径、祖先、坡度……）
- 当前节点的答案能由**左右子树的同类答案**合并出来
- 或者答案依赖"从根走到当前节点"的路径信息（前缀和、前缀数字、路径字符串）
- 需要**修改树的结构**（翻转、删除、合并），并且改动只依赖左右孩子
- 题目里出现"两个目标节点"（LCA、距离），需要一次遍历同时找两个

## 三种模板

### A. 自下而上：返回值 = 以 root 为根的答案

适用：深度、节点数、子树和、坡度、直径、平衡判断。

```cpp
int dfs(TreeNode* root) {
    if (!root) return 0;              // 空树的答案
    int l = dfs(root->left);
    int r = dfs(root->right);
    return combine(l, r, root->val);  // 用左右答案合成当前答案
}
```

### B. 自上而下：参数 = 从根到当前节点的信息

适用：根到叶子的数字、路径和、路径字符串。

```cpp
void dfs(TreeNode* root, int prefix, /* 收集答案的引用 */) {
    if (!root) return;
    prefix = prefix * 10 + root->val;      // 边走边算
    if (!root->left && !root->right) {     // 叶子处结算
        ans += prefix;
        return;
    }
    dfs(root->left, prefix, ans);
    dfs(root->right, prefix, ans);
}
```

### C. 返回值编码"找到了什么"（LCA 型）

适用：普通二叉树上找两个目标节点的关系。

```cpp
TreeNode* dfs(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root;
    auto l = dfs(root->left, p, q);
    auto r = dfs(root->right, p, q);
    if (l && r) return root;      // 分居两侧 → 当前是答案
    return l ? l : r;             // 都在同一侧 → 把答案往上抛
}
```

### D. 后序 + 引用收集（A 的加强版）

当前节点既要给父节点返回值，又要把自己的贡献记进全局答案：

```cpp
int dfs(TreeNode* root, int& ans) {
    if (!root) return 0;
    int l = dfs(root->left, ans);
    int r = dfs(root->right, ans);
    ans += abs(l - r);            // 后序：左右都算完才结算当前节点
    return l + r + root->val;     // 返回值给父节点用
}
```

## 我的易错点

- **搞反信息流向**：129 需要把信息带下去，却写成返回子树和；104 需要返回深度，却想用参数带。
- **覆盖指针前没备份**：226 里 `root->left = dfs(root->right)` 之后原来的左孩子就丢了，必须先 `tmp = root->left`。
- **空节点的返回值不统一**：深度返回 0、和返回 0、LCA 返回 `nullptr`——先想清楚"空树对这个问题的答案是什么"。
- **重复遍历**：563 的 v1 在每个节点调用 `getSum`，链状树退化 O(n²)；能合并进一次后序就合并。
- **递归深度**：链状树 n = 10⁵ 时递归栈可能溢出；要么确认题目范围，要么改迭代。
- **多组数据残留**：不要把前缀和/答案放全局变量而不清零。
