# 模式：网格 DFS —— 连通块

## 一句话

网格上的"岛屿/区域"问题 = 求连通块。DFS/BFS 把**同一块**一次走完并打标记，剩下只要对块做统计。

## 识别信号

> 【计挑赛补充 2026-11-21】先读本页末尾的“审读与模型边界”，再决定用 DFS 还是 BFS。

- 输入是 `vector<vector<int>>` / 字符矩阵
- 出现"岛屿"、"封闭区域"、"连通"、"相邻（上下左右）"
- 要"数块数"或"对每一块求某个和"
- n·m ≤ 10⁶ 级别，允许 O(n·m)

## 模板

```cpp
int dir[4][2] = {{0,1},{0,-1},{1,0},{-1,0}};
int n, m;

void dfs(vector<vector<int>>& g, int i, int j, /* 统计量 */) {
    if (i < 0 || j < 0 || i >= n || j >= m) return;   // 越界
    if (g[i][j] != 1) return;                          // 不是目标 / 已访问
    g[i][j] = 0;                                       // ★ 立刻标记（按引用改原图）
    for (auto& d : dir) dfs(g, i + d[0], j + d[1], /* 统计量 */);
}
```

三个必须做对的点：**越界判断**、**标记时机**（进入就标，不是出去才标）、**参数按引用传**（否则标记丢失）。

## 我的易错点（`1254` 就是活教材）

- **`grid` 按值传** → 递归里做的标记全丢，会重复访问甚至无限递归
- **不标记访问** → 与上一条互为因果
- **`ans++` 写在循环里而不是"块处理完"之后** → 每块陆地都被算成一块"封闭岛屿"
- `col` / `row` 名字和实际的行列数对不上（`grid.size()` 是行数），调试时极易看反
- `3619` 的 `sum` 用 `long long`：网格值 × 面积会溢出 `int`

## 【计挑赛补充 2026-11-21】审读与模型边界

**先圈题眼：**“相邻”是否仅上下左右？“区域”是目标格连通块，还是求到目标的最少步数？网格里 0/1 分别代表什么？1254 的陆地为 0，不能直接套上文 `g[i][j] == 1`。

- 只统计连通块、面积、块内总和：DFS/BFS 均可。每个未访问的目标格启动一次遍历，块数仅在启动时加一。
- 无权/等代价的最少步数或每分钟同时传播：BFS 分层；多个初始源应全部以距离 0 入队。普通 DFS 第一次找到的路线不保证最短。
- 权值不同：不能原样套普通 BFS；非负权最短路可考虑 Dijkstra。状态若还包含钥匙、剩余次数等，访问标记也要包含这些状态，不能只记坐标。

**标记细节：**DFS 进入即标记，BFS 入队即标记；否则同一格可能从多条边重复进入。修改原图时要确认后面是否还需要原值；需要保留就另开 visited。大连通块可能导致深递归，显式栈/队列更稳妥。

**一分钟对比：**网格 `[2,1,1,1,2]`，2 为初始源、1 为待感染格，两端同时传播只需 2 轮。一个源搜索完再处理另一个源并累加时间，会改变“同时”的含义。详见 [994 补充](../题目/0994-腐烂的橘子/0994.md)。

闭卷检查：节点表示什么？一条边表示什么？求连通还是距离？每个状态会被访问几次？普通网格遍历时间 O(行数×列数)，访问数组或队列最坏空间同阶。
