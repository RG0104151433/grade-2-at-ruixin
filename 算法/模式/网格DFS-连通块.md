# 模式：网格 DFS —— 连通块

## 一句话

网格上的"岛屿/区域"问题 = 求连通块。DFS/BFS 把**同一块**一次走完并打标记，剩下只要对块做统计。

## 识别信号

- 输入是 `vector<vector<int>>` / 字符矩阵
- 出现"岛屿"、"封闭区域"、"连通"、"相邻（上下左右）"
- 要"数块数"或"对每一块求某个和"
- n·m ≤ 10⁶ 级别，允许 O(n·m)

## 模板

```cpp
int dir[4][2] = {{0,1},{0,-1},{1,0},{-1,0}};
int n, m;

void dfs(vector<vector<int>>& g, int i, int j, /* 统计量 */) {
    if (i < 0 || j < 0 || i >= n || j >= m) return;   // 越界
    if (g[i][j] != 1) return;                          // 不是目标 / 已访问
    g[i][j] = 0;                                       // ★ 立刻标记（按引用改原图）
    for (auto& d : dir) dfs(g, i + d[0], j + d[1], /* 统计量 */);
}
```

三个必须做对的点：**越界判断**、**标记时机**（进入就标，不是出去才标）、**参数按引用传**（否则标记丢失）。

## 我的易错点（`1254` 就是活教材）

- **`grid` 按值传** → 递归里做的标记全丢，会重复访问甚至无限递归
- **不标记访问** → 与上一条互为因果
- **`ans++` 写在循环里而不是"块处理完"之后** → 每块陆地都被算成一块"封闭岛屿"
- `col` / `row` 名字和实际的行列数对不上（`grid.size()` 是行数），调试时极易看反
- `3619` 的 `sum` 用 `long long`：网格值 × 面积会溢出 `int`
