# 模式：置换环 —— 最小交换次数与破环

## 一句话

"每次交换两个元素，把数组变成目标排列"的最少次数 = **n − 环的个数**（长度 L 的环需要 L−1 次交换）。求出"谁该去哪"的映射，数环就行。

## 识别信号

- 题目说"最少交换次数"
- 目标数组是**排序后的**数组 / 某个确定的排列
- 元素可能有重复（这时"目标位置"不唯一，必须带原下标定序）
- 数组首尾相接（"旋转"、"环形"）→ 破环成链 / 分类讨论

## 模板

```cpp
// 1. 造目标顺序：排序时把原下标一起带上
vector<array<int,3>> a(n);                 // {排序键, 值, 原下标}
for (int i = 0; i < n; i++) a[i] = {key(nums[i]), nums[i], i};
sort(a.begin(), a.end());

// 2. 原下标 → 目标位置
vector<int> to(n);
for (int i = 0; i < n; i++) to[a[i][2]] = i;

// 3. 数环
vector<char> vis(n, 0);
int circle = 0;
for (int i = 0; i < n; i++) {
    if (vis[i]) continue;
    circle++;
    for (int j = i; !vis[j]; j = to[j]) vis[j] = 1;
}
return n - circle;
```

## 我的易错点

- 用 `unordered_map<值, 位置>` 求 `to[]`：**值有重复时会被后者覆盖**。稳妥做法是把原下标作为排序键的一部分（上面的 `array<int,3>`）
- 环计数时 `visited` 的语义要想清楚：是指"原下标被处理过"还是"目标位置被处理过"，两种都能做，但同一个循环里不能混
- `vector<bool>` 是位压缩特化，取地址/引用都麻烦；用 `vector<char>` 更省心
- 环的入口 `j = i` 只对"朴素排列置换"成立；数组首尾相接时先确定"锚点"（如 0 的位置）再走
