# 模式：计数替代排序

## 一句话

值域有限、或者"超过某个上界就等价"时，用 `cnt[值]++` 代替排序，把 O(n log n) 压到 O(n)。

## 识别信号

- 题目要求（或存在）**O(n)** 的解法，而直觉第一步是排序
- 只关心"有多少个数 ≥ x / 等于 x / 落在某个区间"，不关心它们的具体顺序
- 值域有上界，或**超过上界之后全都等价**（这是最关键的信号）
- 要反复查询"阈值以上有多少个"

## 模板

```cpp
// 0274 H 指数：h 不可能超过 n，所以 >n 的引用次数一律看成 n
int n = a.size();
vector<int> cnt(n + 1);              // 下标 n 是"截断桶"
for (int x : a) cnt[min(x, n)]++;
int s = 0;
for (int i = n; i >= 0; i--) {       // 从大到小累加 = 后缀和
    s += cnt[i];                     // s = 值 >= i 的个数
    if (s >= i) return i;            // 第一次满足就是最大答案
}
```

## 我的易错点

- 累加方向：必须**从大到小**，才能保证第一次满足 `s >= i` 的 `i` 就是答案
- `cnt` 长度是 `n + 1`，"截断桶"放在下标 `n`，别忘了
- 别把 `n` 和 `len` 混用——`0274` 的 v2 就是这么挂的（编译不过，被 `check.py` 抓出来）
- 计数成立的前提是"值域可控"：值域到 10⁹ 又不可截断时，老老实实排序或哈希
