# 模式：计数替代排序

## 一句话

值域有限或可截断时，用 `cnt[值]` 代替排序，把 O(n log n) 压到 O(n)。

## 识别信号（什么时候该想到它）

- 题目要求 O(n)，但常规直觉是先排序
- 值的范围 / 关注的值有上界（如"大于 n 的一律视为 n"）
- 只关心"有多少个 ≥ x"，不关心它们的具体顺序
- 需要反复查询"某阈值以上有多少个"

## 模板

```cpp
// 例：统计 min(x, n) 的出现次数，再从大到小累加
int n = a.size();
vector<int> cnt(n + 1);
for (int x : a) cnt[min(x, n)]++;
int s = 0;
for (int i = n; i >= 0; i--) {
    s += cnt[i];          // s = 值 >= i 的元素个数
    if (s >= i) return i; // 第一个满足条件的就是最大答案
}
```

## 我的易错点

- 累加方向：必须**从大到小**，才能保证第一次满足 `s >= i` 的 i 就是答案
- `cnt` 长度是 `n + 1`，下标 `n` 是"截断桶"，别忘了
- 别把 `n` 和 `len` 混用（0274 v2 就是这么挂的）
