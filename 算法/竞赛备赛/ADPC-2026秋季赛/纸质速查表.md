## 4. 二分

```cpp
// 第一个 >= x 的下标；不存在返回 n（迭代器 end）
int p = lower_bound(a.begin(), a.end(), x) - a.begin();
// 第一个 > x
int q = upper_bound(a.begin(), a.end(), x) - a.begin();
// x 的个数 = q - p

// 手写：左闭右开，找第一个满足 check 的位置
int lo = 0, hi = n;
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (check(mid)) hi = mid;
    else lo = mid + 1;
}
// 答案 = lo；若 lo == n 表示无解
```

二分答案：

```cpp
ll lo = 下界, hi = 上界;
while (lo < hi) {
    ll mid = lo + (hi - lo) / 2;
    if (ok(mid)) hi = mid;   // mid 可行，尝试更小
    else lo = mid + 1;       // mid 不可行，必须更大
}
cout << lo;
```

前提：可行性单调。下界/上界要能覆盖所有答案；`mid` 用 `lo + (hi-lo)/2` 防溢出。

## 5. 双指针 / 滑动窗口

```cpp
// 有序数组配对
int l = 0, r = n - 1;
while (l < r) {
    ll s = a[l] + a[r];
    if (s == target) { /* ... */ l++; r--; }
    else if (s < target) l++;
    else r--;
}

// 正数数组，求和 >= target 的最短长度
int l = 0; ll s = 0; int ans = INT_MAX;
for (int r = 0; r < n; r++) {
    s += a[r];
    while (s >= target) {          // 满足条件持续收缩
        ans = min(ans, r - l + 1);
        s -= a[l++];
    }
}
```

滑窗前提：元素为正（或窗口扩张/收缩有单调性）。含负数不要硬套。

## 7. 单调栈 / 单调队列

```cpp
// 下一个更大元素的下标
vector<int> nxt(n, n);
stack<int> st;
for (int i = 0; i < n; i++) {
    while (!st.empty() && a[st.top()] < a[i]) {
        nxt[st.top()] = i; st.pop();
    }
    st.push(i);
}

// 滑动窗口最大值（下标队列，递减）
deque<int> dq;
for (int i = 0; i < n; i++) {
    while (!dq.empty() && dq.front() <= i - k) dq.pop_front();
    while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();
    dq.push_back(i);
    if (i >= k - 1) cout << a[dq.front()] << ' ';
}
```

## 8. 并查集

```cpp
struct DSU {
    vector<int> p, sz;
    DSU(int n) : p(n), sz(n, 1) { iota(p.begin(), p.end(), 0); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        if (sz[a] < sz[b]) swap(a, b);
        p[b] = a; sz[a] += sz[b];
        return true;
    }
};
```

## 10. 网格 BFS / DFS

```cpp
int dx[4] = {0, 0, 1, -1};
int dy[4] = {1, -1, 0, 0};

// BFS 最短路（无权）
queue<pair<int,int>> q;
dist[sx][sy] = 0; q.push({sx, sy});
while (!q.empty()) {
    auto [x, y] = q.front(); q.pop();
    for (int d = 0; d < 4; d++) {
        int nx = x + dx[d], ny = y + dy[d];
        if (nx < 0 || ny < 0 || nx >= m || ny >= n) continue;
        if (g[nx][ny] == '#' || dist[nx][ny] != -1) continue;
        dist[nx][ny] = dist[x][y] + 1;   // 入队时标记
        q.push({nx, ny});
    }
}

// DFS 连通块（引用传图，进入就标记）
function<void(int,int)> dfs = [&](int x, int y) {
    if (x < 0 || y < 0 || x >= m || y >= n || g[x][y] != '1') return;
    g[x][y] = '0';
    for (int d = 0; d < 4; d++) dfs(x + dx[d], y + dy[d]);
};
```

## 11. 树递归四模板

```cpp
struct TreeNode { int val; TreeNode *left, *right; };

// A. 自下而上：返回值 = 以 root 为根的答案（深度/和/节点数）
int dfsA(TreeNode* root) {
    if (!root) return 0;
    int l = dfsA(root->left), r = dfsA(root->right);
    return 1 + max(l, r);
}

// B. 自上而下：参数 = 根到当前的信息（路径数字/路径和）
void dfsB(TreeNode* root, int prefix, int& ans) {
    if (!root) return;
    prefix = prefix * 10 + root->val;
    if (!root->left && !root->right) { ans += prefix; return; }
    dfsB(root->left, prefix, ans);
    dfsB(root->right, prefix, ans);
}

// C. 返回值编码“找到了谁”（LCA）
TreeNode* dfsC(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root;
    auto l = dfsC(root->left, p, q);
    auto r = dfsC(root->right, p, q);
    if (l && r) return root;
    return l ? l : r;
}

// D. 后序 + 引用收集（子树和 + 全局答案）
int dfsD(TreeNode* root, int& ans) {
    if (!root) return 0;
    int l = dfsD(root->left, ans), r = dfsD(root->right, ans);
    ans += abs(l - r);
    return l + r + root->val;
}
```

- 改结构（翻转/删除）：先存 `tmp` 再覆盖指针。
- 空树返回什么，先想清楚：0 / `nullptr` / 空集合。
- 链状树 n 很大时，递归可能爆栈；确认范围或改迭代。

## 12. 背包 / LIS

```cpp
// 01 背包：容量 V，物品 (w, v)
vector<int> f(V + 1, 0);
for (int i = 0; i < n; i++)
    for (int j = V; j >= w[i]; j--)          // 倒序
        f[j] = max(f[j], f[j - w[i]] + v[i]);

// 完全背包：容量正序
for (int i = 0; i < n; i++)
    for (int j = w[i]; j <= V; j++)
        f[j] = max(f[j], f[j - w[i]] + v[i]);

// LIS O(n log n)：tails 存各长度最小结尾
vector<int> tails;
for (int x : a) {
    auto it = lower_bound(tails.begin(), tails.end(), x);
    if (it == tails.end()) tails.push_back(x);
    else *it = x;
}
// 答案 = tails.size()
```

## 14. 边界 / 溢出清单

- [ ] `int` 上限约 2.1×10⁹；`n × 值`、`前缀和`、`方案数`、`距离和` 先想 `long long`
- [ ] 乘法：`1LL * a * b`，不要先 `int` 乘再赋值
- [ ] 取模：减法 `+mod`；模数非零
- [ ] 多组：`ans`、数组、`vis`、`dist`、`parent` 重新初始化
- [ ] 下标：`0 <= i < n`；`r+1` 是否越界；`lower_bound == end()`
- [ ] 空容器：`a[0]`、`q.front()`、`dq.front()` 前判空
- [ ] 浮点：尽量转整数/二分；必须用 `double` 时加 `eps`
- [ ] 比较器：严格 `<`，不用 `<=`，不用相减
- [ ] 图：重边/自环/不连通；网格：边界、单行、单列
- [ ] 递归：深度是否可能 = n（链状树/链状图）
- [ ] 输出：只输出题目要求的内容；行末空格/换行按题面
