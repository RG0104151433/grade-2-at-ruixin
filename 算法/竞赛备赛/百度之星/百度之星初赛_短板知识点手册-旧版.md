> 覆盖你明确欠缺的六块：快速幂/模运算、异或、线段树/BIT、树形DP、区间DP、计数DP、贪心/模拟。
> 每个模块按「**识别特征 → 核心模板 → 进阶/变体 → 坑点 → 真题·力扣对照**」组织，

## 〇、考场查找顺序（先看这段）

看到题面时按顺序判断：

1. 有"模多少""取余""a 的 b 次方""组合数/C(n,k)" → **一、快速幂/模运算**
2. 有"异或/XOR/按位/出现奇数次" → **二、异或**
3. 有"区间求和/区间最值 + 修改操作，n≥1e5" → **三、线段树/BIT**
4. 是一棵树的题，问最值/计数/最大→DFS 递推 → **四、树形DP**
5. 是序列/区间合并/回文，问区间最优 → **五、区间DP**
6. 问"方案数/多少种"，带取模 → **六、计数DP**
7. 无算法门槛，考翻译题意 + 排序 + 特判 → **七、贪心/模拟**

## 一、快速幂 / 模运算

### 1.1 识别特征
- 求 `a^b mod m`，b 可达 1e9~1e18（直接乘会爆/超时）
- 组合数、逆元、Lucas、矩阵快速幂的底层构件

### 1.2 核心模板（O(log b)）
```cpp
long long qpow(long long a, long long b, long long mod) {
    long long res = 1 % mod;          // mod=1 时防坑
    a %= mod;
    while (b) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}
```

### 1.3 模运算四条性质（必须背）
```cpp
(a + b) % m = ((a%m) + (b%m)) % m
(a - b) % m = ((a%m) - (b%m) + m) % m   // 减法 +m，防负数
(a * b) % m = (a%m) * (b%m) % m
除法不能直接取模，要乘逆元：a / b ≡ a * inv(b) (mod m)
```

### 1.4 逆元（费马小定理，m 为质数）
```cpp
// m 为质数时：inv(a) = a^(m-2) mod m
long long inv(long long a, long long m) { return qpow(a, m - 2, m); }
```
- 百度之星约定俗成的质数模：**998244353**、**1e9+7**（看到这两个模数，逆元直接套费马小定理）。

### 1.5 线性求 1..n 逆元（O(n)，批量要用）
```cpp
inv[1] = 1;
for (int i = 2; i <= n; i++)
    inv[i] = (m - m / i) * inv[m % i] % m;
```

### 1.6 组合数（预处理阶乘 + 阶乘逆元）
```cpp
// 预处理
fac[0] = 1;
for (int i = 1; i <= n; i++) fac[i] = fac[i-1] * i % m;
ifac[n] = qpow(fac[n], m-2, m);
for (int i = n; i >= 1; i--) ifac[i-1] = ifac[i] * i % m;
// C(n, k) = fac[n] * ifac[k] % m * ifac[n-k] % m
```
- **Lucas**（n 很大、m 为质数且较小）：`C(n,k) mod p = C(n/p, k/p) * C(n%p, k%p) mod p`，递归算，配合预处理小组合数。百度之星数论难题（如 2025 Odd Occurrence 的 2^n-1 子序列）常踩这里。

### 1.7 坑点
- `res` 初始一定要 `1 % mod`，不是 `1`（mod=1 时错）。
- 阶乘数组按 **n 上限** 开；n 到 1e7 时注意内存，考虑边算边用、不开 fac/ifac 全量。
- 涉及 1e18 数量级两数相乘再取模：用 `__int128` 中转 `(long long)((__int128)a*b%mod)`。
- 百度之星喜欢在"看似暴力的题"里埋 mod，看题时先找 `998244353` 字样 → 立刻切数论。

### 1.8 对照
- 力扣：50 Pow(x,n)（快速幂思想）、119 杨辉三角II（组合数/滚动）、62 不同路径（组合数）。
- 真题：2024 跑步（LCM+线性逆元）、2025 Odd Occurrence（Lucas）、2023 糖果促销（公式）。

## 二、异或

### 2.1 识别特征
- 题面出现"异或 / XOR / 按位"；或"出现奇数次的数""两两配对后剩下哪个"。

### 2.2 核心性质（全背）
```cpp
a ^ a = 0
a ^ 0 = a
交换律、结合律（可任意重排）
a ^ b = c  →  a = b ^ c（自反）
前缀异或：a[l..r] 的异或 = pre[r] ^ pre[l-1]
每一位独立 → 可"拆位"逐位处理
```

### 2.3 高频套路
1. **找只出现一次的数**（其余都出现两次）：全体异或，剩下的就是答案（力扣 136）。
2. **缺失数字**（0..n 中缺一个）：`0..n` 全员异或再异或数组（力扣 268）。
3. **拆位统计**：求所有区间/子序列异或和之类，按每一位数 0/1 个数独立相加再拼起来。
4. **前缀异或 + 哈希**：统计"异或和为 k 的子数组个数"，`pre[i] ^ pre[j] = k` 即 `pre[j] = pre[i] ^ k`。

### 2.4 坑点
- 异或 `^` 别和按位或 `|`、按位与 `&` 写混。
- 拆位后每位贡献要乘回 `1<<bit`，且注意 `1 << bit` 超 int 时用 `1LL<<bit`。
- 前缀异或数组要用 `long long` 或按题意确定类型。

### 2.5 对照
- 力扣：136（只出现一次）、268（缺失数字）、260（只出现一次III，按某一位分两组）、137（出现一次的数，其余三次，拆位计数）。
- 真题：2025 GCD Xor MEX（数论构造，异或只是外壳）、2023 新材料（map 记录上次位置 + 异或模拟）。

## 三、线段树 / BIT 模板

### 3.1 什么时候用哪个
| 需求 | 选 | 理由 |
|---|---|---|
| 单点修改 + 前缀/区间和 | **BIT** | 代码短、常数小，优先写 |
| 区间修改（加/赋值/置换）+ 区间查询 | **线段树** | BIT 只支持可逆差分，区间操作必须线段树 |

### 3.2 BIT（树状数组，先背这个）
```cpp
struct BIT {
    int n; vector<long long> c;
    BIT(int n) : n(n), c(n + 1) {}
    void add(int i, long long x) {        // 单点 +x
        for (; i <= n; i += i & -i) c[i] += x;
    }
    long long sum(int i) {                // 前缀和 [1..i]
        long long s = 0;
        for (; i > 0; i -= i & -i) s += c[i];
        return s;
    }
    long long range(int l, int r) { return sum(r) - sum(l - 1); }
};
```
- 树状数组也能做"单点查询 + 区间加"（差分）：对区间 [l,r] 加 v，`add(l,v); add(r+1,-v)`；单点值 = `sum(i)`。

### 3.3 线段树（区间加 + 区间求和，含懒标记）
```cpp
const int N = /* 4 * 数据上限 */;
long long sum[N], tag[N];

void pushup(int o) { sum[o] = sum[o<<1] + sum[o<<1|1]; }

void build(int o, int l, int r, long long a[]) {
    if (l == r) { sum[o] = a[l]; return; }
    int m = (l + r) >> 1;
    build(o<<1, l, m, a);
    build(o<<1|1, m+1, r, a);
    pushup(o);
}

void apply(int o, int l, int r, long long v) {   // 给整段打标记
    sum[o] += v * (r - l + 1);
    tag[o] += v;
}

void pushdown(int o, int l, int r) {             // 懒标记下放
    if (tag[o]) {
        int m = (l + r) >> 1;
        apply(o<<1, l, m, tag[o]);
        apply(o<<1|1, m+1, r, tag[o]);
        tag[o] = 0;
    }
}

void update(int o, int l, int r, int ql, int qr, long long v) {
    if (ql <= l && r <= qr) { apply(o, l, r, v); return; }
    pushdown(o, l, r);
    int m = (l + r) >> 1;
    if (ql <= m) update(o<<1, l, m, ql, qr, v);
    if (qr > m)  update(o<<1|1, m+1, r, ql, qr, v);
    pushup(o);
}

long long query(int o, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return sum[o];
    pushdown(o, l, r);
    int m = (l + r) >> 1; long long s = 0;
    if (ql <= m) s += query(o<<1, l, m, ql, qr);
    if (qr > m)  s += query(o<<1|1, m+1, r, ql, qr);
    return s;
}
```

### 3.4 常见变体（换 tag/apply 即可）
- **区间赋值**：`apply` 改为 `sum[o] = v*(r-l+1); tag[o]=v;`（tag 表示"整个区间被改成 v"，下放时覆盖子区间）。
- **区间 01 置换/翻转**：`apply` 改为 `sum[o] = (r-l+1) - sum[o]; tag[o] ^= 1;`（对应 2024 小度的01串）。
- **区间最值**：把 `sum` 维护改成 `max/min`，`apply` 相应改。

### 3.5 坑点（线段树高频 WA 来源）
- **数组开 4n**（4 倍）。
- 区间修改**漏写 pushdown** → 必 WA；下放后记得 `tag[o]=0`。
- 大 n（如 2026 T3 的 n=1e6）卡常数，考虑**标记永久化**（不用 pushdown，query 时沿途累加 tag）；必要时手写非递归线段树。
- 值和标记都要 `long long`。

### 3.6 对照
- 力扣：307（区间和检索，BIT）、315（计数右侧小于，离散化+BIT）、327（区间和个数，BIT/归并）、493（翻转对）。
- 真题：2024 小度的01串（区间置换）、2024 三 T6（离散化+BIT 维护 DP）、2023 二 T4（矩阵乘+动态开点线段树）、2026 T3（换根 DP+线段树）。

## 四、树形 DP

### 4.1 识别特征
- 给一棵树（n 个点 n-1 条边），问最大/最小/计数，且状态要沿树自底向上递推。

### 4.2 通用框架（DFS 自底向上）
```cpp
void dfs(int u, int fa) {
    // 初始化 dp[u][...] 的叶子/自身值
    for (int v : g[u]) if (v != fa) {
        dfs(v, u);
        // 用 dp[v][...] 更新 dp[u][...]
    }
}
// 答案在 dp[root][...] 或对所有点取 max
```

### 4.3 最大独立集（选点互不相邻，权值和最大）
```cpp
// f[u][0] 不选 u；f[u][1] 选 u
void dfs(int u, int fa) {
    f[u][0] = 0;
    f[u][1] = w[u];
    for (int v : g[u]) if (v != fa) {
        dfs(v, u);
        f[u][0] += max(f[v][0], f[v][1]);
        f[u][1] += f[v][0];
    }
}
```

### 4.4 树的直径（两遍 DFS）
```cpp
// 第一遍从任意点找最远点 p；第二遍从 p 找最远距离 = 直径
void dfs(int u, int fa, int d) {
    if (d > maxd) { maxd = d; p = u; }
    for (auto [v, w] : g[u]) if (v != fa) dfs(v, u, d + w);
}
// 调用：maxd=-1; dfs(1,0,0); maxd=-1; dfs(p,0,0); 答案 = maxd
```

### 4.5 换根 DP（答案与"根"有关，需算子树外贡献）
两遍：
1. `dfs1(u,fa)`：算以 u 为根的**子树内**贡献（down[u]）。
2. `dfs2(u,fa)`：用父节点的全局信息，算"换成以 u 为根"时 u 的**子树外**贡献，合并出全局答案。

- 模板骨架：
```cpp
void dfs1(int u, int fa) { /* down[u] 由 down[v] 累加 */ }
void dfs2(int u, int fa) {
    // 用 fa 的答案 + down 信息反推 u 的全局值
    // 常见需要维护"前缀和 + 后缀和"来批量移除某个子 v 的贡献
}
```
- 高频考点：树上组合计数（按度数奇偶做双阶乘配对，如 2025 Bus Station）、叶子数乘法原理（2025 Pair Counting）。

### 4.6 坑点
- 无向树 DFS 必须传 `fa` 判重，否则死循环。
- 树上合题数据范围大（n 可达 1e6），DFS 递归层数过深会爆栈 → 用 `std::function` 或手写栈 / 开编译优化，必要时改迭代。
- 计数类树形 DP 记得一路取模。

### 4.7 对照
- 力扣：543（二叉树直径）、337（打家劫舍III=最大独立集）、834（树中距离之和=换根DP）、968（监控二叉树）。
- 真题：2026 T3（树上换根 DP+线段树）、2025 Bus Station（度数双阶乘配对）、2025 Pair Counting（叶子计数+容斥）。

## 五、区间 DP

### 5.1 识别特征
- 序列/环上的区间问题，`dp[i][j]` 表示区间 [i,j] 的最优解；常伴随"合并相邻、回文、取两端"。

### 5.2 通用枚举顺序（先长度，再起点，再断点）
```cpp
// dp[i][j]：区间 [i,j] 的答案
for (int len = 2; len <= n; len++)              // 区间长度
    for (int i = 1; i + len - 1 <= n; i++) {
        int j = i + len - 1;
        dp[i][j] = INF;                          // 初始化
        for (int k = i; k < j; k++)              // 枚举断点
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i, j));
    }
```

### 5.3 经典：合并石子（环形→破环成链复制一倍）
```cpp
// 前缀和 sum[]；dp[i][j] = 合并 [i,j] 最小代价
dp[i][j] = min(dp[i][k] + dp[k+1][j]) + sum[j] - sum[i-1]
// 环形：数组复制一倍，枚举长度 n 的窗口取 min
```

### 5.4 变体
- **回文相关**：`dp[i][j]` 表 [i,j] 是否回文 / 删除成回文的最小代价（力扣 516 最长回文子序列、1312）。
- **观察性质再套区间 DP**：2026 T4（权值可拆为两矩形和 → 观察后跑 O(n³) 区间 DP），这类题难点在"先看出性质"，区间 DP 本身是模板。

### 5.5 坑点
- 枚举顺序**一定是 len 从小到大**，否则子区间未算好。
- 复杂度 O(n³)：n 超过 1500 基本超时（2026 T4 n=1500 压线，注意常数和剪枝）。
- 环上题记先破环成链（数组复制一倍）。

### 5.6 对照
- 力扣：516（最长回文子序列）、312（戳气球）、1000（合并石头最低成本）、1312（让字符串成为回文串的最少插入）。
- 真题：2026 T4（观察性质 + 区间 DP）、2023 蛋糕划分（二分 + 状压 + 贪心，区间 DP 的亲友）。

## 六、计数 DP

### 6.1 识别特征
- 问"方案数 / 多少种 / 计数"，并带 `998244353` 或 `1e9+7` 取模。

### 6.2 通用套路
1. 明确**状态**：`dp[i]` 或 `dp[i][j]` 表示"前 i 个元素满足约束的方案数"。
2. 明确**转移**：从哪个上一状态能到达，逐项累加。
3. **不漏不重**：每个方案恰好被计算一次；模一路取。

### 6.3 模板：路径计数（62 不同路径）
```cpp
dp[i][j] = dp[i-1][j] + dp[i][j-1];   // 每个格子来自上方/左方
// 障碍物位置置 0；全程 % mod
```

### 6.4 进阶：带约束的多状态计数（2025 Yummy 型）
- 关键在**状态设计**：把"当前项 vs 历史累计"的约束编码进状态维度。例：第 i 项绝对值要大于前 i-1 项和，可设 `dp[i][s]` 表示前 i 项和为 s 的方案数，转移时枚举新项取值并判断约束。
- 常用技巧：前缀和优化转移（把 O(n) 求和压成 O(1)）、滚动数组压一维省内存。

### 6.5 坑点
- 计数题**几乎必带模数**，漏取模会溢出、会 WA。
- 状态含义不唯一时最容易"算重"——先想清楚"到底在数什么"，再动笔写转移。
- 大状态空间用滚动数组 / map 稀疏存储，别直接开大二维爆内存。

### 6.6 对照
- 力扣：62（不同路径）、96（不同二叉搜索树）、115（不同的子序列）、518（零钱兑换II）。
- 真题：2025 Yummy（三状态计数 DP，前 i-1 项和约束）、2024 T4（DP）。

## 七、贪心 / 模拟

### 7.1 贪心
**识别**：无后效性、局部最优可推出全局最优；常见"排序 + 枚举""选 a 还是选 b 的决策"。

**套路**：
1. 按某关键字排序后贪心选（如性价比、区间右端点、差值）。
2. 交换论证 / 反证法证明：假设不是这样会怎样 → 发现不会更优。
3. 常用实现件：`sort` + 优先队列 `priority_queue` + set/multiset。

**示例（区间调度 / 最多不重叠区间）**：按右端点升序，贪心取最早结束的：
```cpp
sort(a, a+n, [](auto&x, auto&y){ return x.r < y.r; });
int cnt = 0, last = -INF;
for (auto&e : a) if (e.l >= last) { cnt++; last = e.r; }
```

**坑点**：
- 贪心不是"感觉能贪就贪"，**必须能证明**；证明不了时考虑 DP/二分兜底。
- 排序的"比较键"选错是最大失分点——动手前先问"按什么排能保证最优"。

### 7.2 模拟
**识别**：签到题主力，题面长、规则多、"按规则一步步做就可"。

**策略清单**：
1. **先读清题意再写**：把输入、输出、每一步规则用注释列出来。
2. 找**特判**：n=0、n=1、全相等、l=r、（2025 Left and Right 的 l=1 与 l=r 特判）。
3. **边界与类型**：下标、开闭区间、`long long`（数据可能 1e18）。
4. **多测**：`T` 组测试，每轮**清空所有容器/变量**。
5. 输出格式：空格、换行、大小写，照抄样例。

**坑点**：
- 长时间卡题多数不是不会，是**没读懂题意或漏特判**——先把样例手推一遍再写。
- 签到题丢分几乎都是罚时（long long、多测没清空、边界没判），不是能力。

### 7.3 对照
- 力扣：435（无重叠区间，贪心）、455（分发饼干）、56（合并区间）、12（整数转罗马，模拟/贪心）。
- 真题：2026 T1（贪心）、T7（模拟）、T5（简单）；2025 GCD Maximum（打表找规律+构造）、2025 Left and Right（数学特判）、2024 补给（排序+贪心+枚举半价）、2023 新材料（map 模拟）。
