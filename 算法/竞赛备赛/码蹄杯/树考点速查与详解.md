## 1. 二叉树遍历

### 1.1 前/中/后序遍历（递归）

**核心逻辑：** 递归遍历是树题的基础，所有树上的递归问题都基于这个框架。

```cpp
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

// 前序遍历（根 → 左 → 右）
void preorder(TreeNode* root) {
    if (!root) return;
    cout << root->val << " ";   // 前序：先处理根
    preorder(root->left);
    preorder(root->right);
}

// 中序遍历（左 → 根 → 右）
void inorder(TreeNode* root) {
    if (!root) return;
    inorder(root->left);
    cout << root->val << " ";   // 中序：中间处理根
    inorder(root->right);
}

// 后序遍历（左 → 右 → 根）
void postorder(TreeNode* root) {
    if (!root) return;
    postorder(root->left);
    postorder(root->right);
    cout << root->val << " ";   // 后序：最后处理根
}
```

### 1.2 层序遍历（BFS）

**核心逻辑：** 用队列逐层推进，每层处理完再进入下一层。

```cpp
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> res;
    if (!root) return res;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int sz = q.size();
        vector<int> level;
        for (int i = 0; i < sz; i++) {
            TreeNode* node = q.front(); q.pop();
            level.push_back(node->val);
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        res.push_back(level);
    }
    return res;
}
```

### 1.3 题目判断

| 题目特征 | 用哪种遍历 |
|----------|-----------|
| 逐层输出、每层单独处理 | 层序 BFS |
| 先处理根再处理子树 | 前序 |
| 需要子树信息来计算当前节点 | 后序（最常用！） |
| BST 中求有序序列 | 中序 |

## 2. 树的深度与直径

### 2.1 最大深度

**核心逻辑：** 当前节点深度 = max(左子树深度, 右子树深度) + 1

```cpp
int maxDepth(TreeNode* root) {
    if (!root) return 0;
    return 1 + max(maxDepth(root->left), maxDepth(root->right));
}
```

**时间复杂度：** O(n)

### 2.2 树的直径（任意两节点最长距离）

**核心逻辑：** 直径 = 经过某个节点的左子树深度 + 右子树深度 的最大值。在求深度的过程中顺便统计。

```cpp
int diameter = 0;
int depth(TreeNode* root) {
    if (!root) return 0;
    int L = depth(root->left);
    int R = depth(root->right);
    diameter = max(diameter, L + R);  // 经过当前节点的最长路径
    return 1 + max(L, R);             // 返回当前节点的深度
}
int diameterOfBinaryTree(TreeNode* root) {
    depth(root);
    return diameter;
}
```

**关键理解：** 这里不是求"经过根的最长路径"，而是求"所有节点中，经过该节点的最长路径"的最大值——所以要在遍历每个节点时都更新一次。

### 2.3 题目判断

| 题目特征 | 思路 |
|----------|------|
| 树的最大深度 / 高度 | 递归 max(左,右)+1 |
| 树中任意两点的最长距离 | 树的直径，遍历中统计 L+R |
| 求二叉树是否平衡 | 递归检查左右子树深度差 ≤ 1 |

## 3. BST 二叉搜索树

### 3.1 核心性质

**BST 定义：** 左子树所有节点 < 根节点 < 右子树所有节点，且左右子树也是 BST。

**最重要的性质：BST 的中序遍历结果 = 递增有序序列**

### 3.2 验证 BST

**核心逻辑：** 中序遍历时，检查当前节点值是否大于前一个节点值。

```cpp
long long prev = LLONG_MIN;  // 用 long long 防 int 边界
bool isValidBST(TreeNode* root) {
    if (!root) return true;
    // 先检查左子树
    if (!isValidBST(root->left)) return false;
    // 检查当前节点
    if (root->val <= prev) return false;
    prev = root->val;
    // 再检查右子树
    return isValidBST(root->right);
}
```

**另一种写法（范围传递法）：** 每个节点传一个可取值范围 (min, max)

```cpp
bool check(TreeNode* root, long long min, long long max) {
    if (!root) return true;
    if (root->val <= min || root->val >= max) return false;
    return check(root->left, min, root->val) &&
           check(root->right, root->val, max);
}
bool isValidBST(TreeNode* root) {
    return check(root, LLONG_MIN, LLONG_MAX);
}
```

### 3.3 BST 查找 / 插入 / 删除

**查找：** 比根大往右走，比根小往左走，O(log n)

```cpp
TreeNode* searchBST(TreeNode* root, int val) {
    while (root && root->val != val) {
        root = (val < root->val) ? root->left : root->right;
    }
    return root;
}
```

**插入：** 同理，找到空位插入

```cpp
TreeNode* insertBST(TreeNode* root, int val) {
    if (!root) return new TreeNode(val);
    if (val < root->val) root->left = insertBST(root->left, val);
    else root->right = insertBST(root->right, val);
    return root;
}
```

### 3.4 题目判断

| 题目特征 | 思路 |
|----------|------|
| 判断一棵树是否是 BST | 中序遍历看是否递增 |
| 求 BST 的第 K 小元素 | 中序遍历到第 K 个 |
| 在 BST 中查找 / 插入 | 利用大小关系左右走 |

## 4. 最近公共祖先 LCA

### 4.1 递归版（推荐，树题够用）

**核心逻辑：** 后序遍历。如果当前节点是 p 或 q 就返回自身；然后看左右子树找到的情况——如果左右各找到一个，当前就是 LCA；如果只在一边找到，就返回那一边的结果。

```cpp
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root;
    TreeNode* left = lowestCommonAncestor(root->left, p, q);
    TreeNode* right = lowestCommonAncestor(root->right, p, q);
    // p 和 q 分别在左右子树 → 当前节点是 LCA
    if (left && right) return root;
    // 只在一边找到 → 返回那一边
    return left ? left : right;
}
```

**为什么是后序？** 因为要先知道左右子树的情况，才能判断当前节点是不是 LCA。

**时间复杂度：** O(n)

### 4.2 倍增法（了解，多组查询时用）

**适用场景：** 多次查询（1e5 次），n 也很大（1e5），递归版每次 O(n) 会超时。

**核心思想：** 预处理每个节点的第 2^k 级祖先，查询时 O(log n)。

```cpp
const int LOG = 20;  // 2^20 > 1e6
int up[N][LOG], depth[N];

// DFS 预处理（从根节点 root 开始）
void dfs(int u, int p) {
    up[u][0] = p;
    for (int i = 1; i < LOG; i++)
        up[u][i] = up[up[u][i-1]][i-1];
    for (int v : g[u]) {
        if (v == p) continue;
        depth[v] = depth[u] + 1;
        dfs(v, u);
    }
}

int lca(int u, int v) {
    if (depth[u] < depth[v]) swap(u, v);
    // 把 u 提到和 v 同一深度
    int diff = depth[u] - depth[v];
    for (int i = 0; i < LOG; i++)
        if (diff >> i & 1) u = up[u][i];
    if (u == v) return u;
    // 一起往上跳
    for (int i = LOG - 1; i >= 0; i--)
        if (up[u][i] != up[v][i])
            u = up[u][i], v = up[v][i];
    return up[u][0];
}
```

### 4.3 题目判断

| 题目特征 | 思路 |
|----------|------|
| 二叉树中找两个节点的最近公共祖先 | 递归版 |
| 树上任意两点距离 | depth[u] + depth[v] - 2*depth[lca] |
| 多次查询 + 大 n | 倍增法 |

## 5. 路径问题

### 5.1 路径总和

**核心逻辑：** 从根到叶子，累加节点值，看是否有等于 target 的路径。

```cpp
bool hasPathSum(TreeNode* root, int targetSum) {
    if (!root) return false;
    // 到达叶子节点
    if (!root->left && !root->right)
        return targetSum == root->val;
    // 递归检查左右子树
    return hasPathSum(root->left, targetSum - root->val) ||
           hasPathSum(root->right, targetSum - root->val);
}
```

### 5.2 对称二叉树

**核心逻辑：** 比较左子树的左孩子和右子树的右孩子，以及左子树的右孩子和右子树的左孩子。

```cpp
bool isMirror(TreeNode* left, TreeNode* right) {
    if (!left && !right) return true;
    if (!left || !right) return false;
    return left->val == right->val &&
           isMirror(left->left, right->right) &&
           isMirror(left->right, right->left);
}
bool isSymmetric(TreeNode* root) {
    return isMirror(root->left, root->right);
}
```

### 5.3 题目判断

| 题目特征 | 思路 |
|----------|------|
| 是否存在根到叶子的路径和等于某值 | 路径总和，递归传 target - val |
| 判断树是否左右对称 | 对称二叉树，递归比较左右子树 |
| 求所有根到叶子的路径 | DFS + 回溯，记录路径 |

## 6. 树形 DP（了解）

### 6.1 选与不选模型

**经典题：打家劫舍 III**——不能同时选相邻节点，问最大价值。

**核心逻辑：** 每个节点返回两个值：{不选当前节点的最大值, 选当前节点的最大值}

```cpp
pair<int, int> dfs(TreeNode* root) {
    if (!root) return {0, 0};
    auto [l_not, l_yes] = dfs(root->left);
    auto [r_not, r_yes] = dfs(root->right);
    // 不选当前节点：子节点可选可不选
    int not_choose = max(l_not, l_yes) + max(r_not, r_yes);
    // 选当前节点：子节点必须不选
    int choose = root->val + l_not + r_not;
    return {not_choose, choose};
}
int rob(TreeNode* root) {
    auto [a, b] = dfs(root);
    return max(a, b);
}
```

### 6.2 题目判断

| 题目特征 | 思路 |
|----------|------|
| 树上相邻节点不能同时选，求最大价值 | 选与不选模型 |
| 树上路径和最大（任意节点到任意节点） | 二叉树中的最大路径和（124） |
