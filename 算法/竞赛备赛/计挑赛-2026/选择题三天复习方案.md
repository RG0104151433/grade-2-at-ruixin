## 优先级怎样定

### 第一优先 程序阅读与基础语言规则

先练循环执行次数和结束后的变量值、continue/break、前后置自增、短路、数组下标与二维存储、字符与字符串、函数传参、递归。这些既有历史题面线索，也能直接检验“基础会写但细节能否看准”。

每题先判断是否合法，再写三项：进入本次判断时的状态；本次执行及副作用；下一次状态。输出题先自行写输出再看选项，减少被相似选项带偏。

### 第二优先 C++ 专项

指针与引用、const、作用域、重载、构造析构、成员初始化顺序、class/struct 默认访问权限、继承与虚函数基础、inline 的含义。这些在原基础讲义中覆盖较少；按小题逐项检查，不临时读整本 C++ 教材。

重点问“限制的是指针还是对象”“函数操作的是副本还是实参”“构造/析构的对象与顺序是什么”。重载自增中的前置/后置签名可作辨认，不要求考前设计复杂运算符重载类。

### 第三优先 数据结构与算法性质

栈队列堆、树的基本性质、排序稳定性与复杂度、二分的条件与 check 代价、BFS/Dijkstra 的适用边权、最短路与生成树的目标区别。它们来自大纲和现有诊断，不声称是已核实的历年出题频率。

原学习报告第 14、21、24、27 题用于回查：check 复杂度、无权最短路、链状树重复求和、值域截断理由。不能只记正确选项，必须解释一个反例。

### 余量再扫 数学与环境细节

基本计数、gcd、质数、取模；类型大小要区分语言保证与指定环境，数组地址题要看是否给了元素大小。C 风格文件模式等仅快速辨认，不因某套 C 卷出现过就投入大量时间。操作系统、网络、数据库等泛计算机知识不列为这三天新增重点，现有材料不足以支持铺开复习。

## 每道题的作答方式

先给 `选项 + 一句话理由 + 确定/犹豫/猜测`，再看解释。反馈顺序为“相关原理 → 逐步推导 → 错项为什么诱人 → 改条件再问一次”。

循环题区分条件求值次数、循环体次数和循环后的变量；字符串先逐个解析转义，再辨 sizeof 对象和 strlen 长度；对象题按实际构造与销毁顺序走；复杂度题写次数与每次成本。不要用“看起来像某个模板”代替推导。

错题只留一句可迁移提醒，如“while 末次失败判断也执行 x++”“sizeof 数组包含终止符和其后元素”“比较的是集合根”。隔天关闭解释再回答。

## 今天的六道起步题

全部为自编同考点练习，不是往年原题。默认需要的标准头文件与 using namespace std 已提供；所有输出中的空格按代码处理。题目保持定义明确，不用有争议的表达式制造单选。

### 1 循环退出时的变量

```cpp
int x = 0, count = 0;
while (x++ < 3) ++count;
cout << count << ' ' << x;
```

A. `3 3`　B. `3 4`　C. `4 4`　D. `4 3`

### 2 短路与副作用

```cpp
int a = 0, b = 2;
bool ok = (a != 0 && ++b > 2);
cout << ok << ' ' << b;
```

A. `0 2`　B. `0 3`　C. `1 2`　D. `1 3`

### 3 const 限制的对象

已声明 `int a=1,b=2; const int* p=&a;`，各选项独立考虑，哪条语句不合法？

A. `p=&b;`　B. `int x=*p;`　C. `*p=5;`　D. `bool same=(p==&a);`

### 4 字符数组与终止符

```cpp
char s[] = "A\0BC";
cout << strlen(s) << ' ' << sizeof(s);
```

A. `1 2`　B. `4 5`　C. `1 5`　D. `4 4`

### 5 递归返回过程

定义 f：n 为 0 时返回 1，否则返回 `f(n-1)+n`。求 f(3)。

A. 4　B. 6　C. 7　D. 10

### 6 二维数组地址

某环境中 int 占 4 字节，`int a[2][3]` 的首元素起始地址为 1000。`a[1][1]` 的起始地址为多少？地址均用十进制表示。

A. 1008　B. 1012　C. 1016　D. 1020

先独立作答，再展开核对。仅有字母而没有理由，不能用来定位真正的薄弱点。
