## 一 类型 运算符与控制流程

### 类型和计算先后

- 整数除法向零截断：5/2 为 2，-5/2 为 -2。`double x=5/2` 仍先做整数除法；要在运算前把一个操作数变成浮点数。
- 接收变量的类型不改变右侧已发生的运算。`long long x=a*b` 不保证 int 乘法安全；先提升为 `1LL*a*b`，并检查 long long 也够用。
- `sizeof(char)==1` 是语言保证；int、指针、double 等具体大小要看题目指定环境，不能一律当作所有平台上的定理。
- 浮点数一般不能精确表示任意十进制小数；直接相等比较需结合题意，不能用浮点替代精确整数计数。
- 字符 `'7'` 与整数 7 不同，十进制数字字符转数值可用 `c-'0'`，前提是已经确认是数字字符。

### 运算符的三个区别

- `=` 赋值，`==` 比较；`if(x=1)` 通常可以编译，含义是赋值后按结果判断，不能自动当成语法错误。
- 内置 `&&`、`||` 有短路，位运算 `&`、`|` 没有同样的短路规则；`^` 是按位异或，不是乘方。
- `++x` 先改再提供新值，`x++` 为表达式提供旧值但仍修改 x。复杂表达式还要检查求值顺序，不能只靠“先乘除后加减”推算含多次修改的表达式。

优先级决定表达式怎样分组，不保证所有操作数从左到右执行。不要用包含未定义行为的程序某次运行结果记“固定输出”。位移要检查位数与类型，不把超出类型位宽的移动当作普通乘法。

### 循环和分支

`for(初始化;条件;更新)` 的普通顺序为初始化一次、判断、循环体、更新、再次判断。for 内 continue 会进入更新部分；while 内 continue 会回到条件判断。break 退出最近一层循环或 switch，不会自动退出所有嵌套循环。

do-while 先执行再判断，循环体至少一次。无 break 的 switch 可能继续执行后续 case。if 的空语句分号、else 与最近未匹配 if 的关系也会改变执行过程。

```cpp
int x=0, count=0;
while (x++<3) ++count;
// count=3，x=4：最后一次失败判断也执行了自增。
```

## 二 数组 字符串 指针与引用

### 数组与地址

数组下标从 0 开始；长度 n 的合法元素下标是 0..n−1。二维原生数组按行连续存储，若每行有 C 列，a[i][j] 相对 a[0][0] 的字节偏移为 `(i*C+j)*sizeof(元素类型)`。

原生二维数组的常见初始化声明可以省第一维，由初始值推导；后续维度要明确，编译器才知道一行的跨度。指针加 1 前进一个所指类型的元素，不一定是一个字节；二维数组的行指针前进一行。

指针加减限定在同一数组对象及其尾后位置的合法范围内；尾后位置可以用于比较，但不能解引用。`int* p,q;` 只把 p 声明为指针，q 仍是 int。

### sizeof 与 strlen

- sizeof 看对象或类型的字节大小；数组对象上得到整块数组大小，结果类型是 size_t。
- strlen 读取 C 字符串，到第一个零字符停止，不计终止符，要求内存中确实有合法可达的终止符。
- 普通 C++ 的 sizeof 表达式不求值，例如 `sizeof(x++)` 不会使 x 自增。
- 函数参数写成 `int a[]` 时会调整为指针参数，函数内 sizeof(a) 不能再求出调用者原数组长度。
- `string.size()` 是字符串存储的字符数，`sizeof(string对象)` 不是文本长度。

```cpp
char s[]="A\0BC";
// sizeof(s)=5：A、显式零、B、C、隐式结尾零。
// strlen(s)=1：读取到显式零时停止。
char t[8]="abc";
// sizeof(t)=8，strlen(t)=3。
```

转义序列要先解析，再数实际字符；`'\0'` 是零字符，`'0'` 是数字字符，`"0"` 是包含终止符的字符串字面量。cin >> string 通常以空白分隔；getline 读取一行，混用时留意此前输入剩余的换行符。

### 指针 引用与 const

- 指针保存地址，`*p` 访问所指对象，`&x` 取得 x 的地址；空指针和悬空指针不能解引用。
- 普通引用声明时需要绑定对象，之后给引用赋值是在改被引用对象，而不是把引用重新绑定到另一个对象。
- `const int* p`：不能通过 p 改对象，但 p 可改指向。它不保证非 const 对象不会经其他途径被修改。
- `int* const p`：p 的指向固定，可通过 p 修改其指向的非 const 对象。
- `const int* const p`：两项都限制。
- `const vector<int>& a` 可避免复制且不通过该引用修改元素；只传值时，修改的是副本。

这部分最重要的区分是“原对象、地址、副本、访问权限”。[sizeof 规则](https://eel.is/c++draft/expr.sizeof)、[指针 const 规则](https://eel.is/c++draft/dcl.ptr)可用于核对语言语义。

## 三 函数 作用域与递归

### 函数调用如何影响外部变量

按值参数是副本，修改副本不直接改原对象；引用参数操作原对象。指针参数虽然按值复制地址，仍可通过该地址修改对象；但仅给形参指针另赋地址，通常不会改变调用者的指针变量。

函数重载可按参数列表区分，不能仅靠返回类型区分。普通默认实参一般从右侧连续提供；调用时由右侧省略，不能任意跳过中间参数。inline 不保证编译器一定展开函数。

### 作用域与生命周期

内层同名变量可能遮蔽外层变量，改变内层不等于改变外层。普通自动局部变量每次进入对应调用重新建立；局部 static 变量跨调用保留状态。静态存储期变量的初始化与普通未初始化局部标量不同，不能一概认为局部 int 初始为 0。

```cpp
int nextValue() {
    static int x=0;
    return ++x;
}
// 连续调用两次得到 1、2；x 不会每次重置为 0。
```

### 递归的三种问题不能混答

“返回多少”“调用几次”“使用多少栈空间”要分别计算。先写出口，再由小状态推大状态；每次调用的普通局部变量是独立的，不要把不同层当成共用一个变量。

一次遍历树每点处理一次可为 O(n)；每点重新扫描子树，链状树可为 O(n²)。递归深度等于调用链长度，二叉树不保证平衡，所以不能见到二叉树就写 O(log n) 空间。

## 四 类 对象 继承与多态

### 构造与析构

构造函数与类同名、没有返回类型，可以重载。普通析构函数名为 ~类名，没有参数和返回类型；不能像普通函数那样提供不同参数的多个析构重载。

简单非虚继承场景：先构造基类，再按成员声明顺序构造成员，最后执行派生类构造函数体。成员初始化顺序不由初始化列表书写顺序决定。销毁时先执行派生类析构函数体，再逆序销毁成员及基类；简单局部对象通常后构造先析构。[基类与成员初始化规则](https://eel.is/c++draft/class.base.init)

```cpp
struct Box {
    int a, b;
    Box() : b(2), a(1) {}
};
// a 仍先于 b 初始化；不能根据列表中的 b,a 判断先后。
```

不要用一个尚未初始化的成员去初始化另一个成员。对象拷贝与引用绑定也不同：前者可能建立新对象，后者只是别名；不确定的拷贝次数还要考虑拷贝消除及题目使用的标准，不靠“遇到返回就一定多拷贝一次”数输出。

### 访问权限与静态成员

class 默认成员访问为 private，struct 默认是 public；默认继承访问方式也分别为 private、public。public/private/protected 影响可访问性，不代表对象里不存在该数据。

派生类不能直接访问基类的 private 成员。static 数据成员由该类对象共享；静态成员函数没有 this，不能在没有具体对象时直接使用非静态成员。

### 重载与重写 多态与虚析构

重载主要看同名函数的不同参数；虚函数重写用于基类接口下调用派生行为，不能只因函数同名就判定重写。通过基类指针或引用调用虚函数，可按实际动态对象选择重写；普通非虚函数调用不按同一规则动态分派。

抽象类不能直接建立对象，但可以声明指向它的指针或引用。采用普通 delete 经基类指针删除派生对象时，需要关注基类虚析构；有其他虚函数不等于析构函数自动变成虚函数。

new/delete 与 new[]/delete[] 要配对。malloc/free 不承担与 new/delete 相同的构造和析构职责，不能互相随意替换。

## 五 STL 排序与二分查找

### 容器的访问规则与成本

- vector 支持 O(1) 下标访问，尾部 push_back 摊还 O(1)，中间插入删除一般 O(n)；一次扩容时 push_back 本身可能 O(n)。
- `reserve(n)` 预留容量，不把 size 变成 n；`resize(n)` 改变元素个数。`vector<int> a(n)` 已有 n 个值初始化为 0 的元素。
- stack 后进先出；queue 先进先出；默认 priority_queue 是大根堆，top 通常 O(1)，push/pop 为 O(log n)。
- map/set 按键的比较关系有序，常见查找与单元素插入删除为 O(log n)。平衡树是常见实现，不把“必须某一种具体树”当成接口保证。
- unordered_map/unordered_set 不提供同样的键排序；典型查询平均 O(1)，最坏可为 O(n)，哈希不等于“永远常数时间”。
- `mp[key]` 在键不存在时会插入默认值；想只判断存在可用 find，不要把下标访问当成只读查询。

迭代器 end 表示尾后，不是最后一个元素，不能解引用。vector 扩容会使旧迭代器、指针和引用失效；erase 等操作也要看具体失效规则，不能边无保护遍历边随意删除。

### 排序性质

稳定排序保持关键字相等的元素原相对顺序，不能误解为“数值结果总是相同所以都稳定”。常见实现的直接插入、冒泡与归并可以稳定；普通选择、堆与典型快速排序通常不稳定，要看题目指定实现。

典型快速排序平均 O(n log n)，最坏 O(n²)；堆排序最坏 O(n log n)；归并排序最坏 O(n log n)，常见数组版辅助空间 O(n)。冒泡最好 O(n) 需有“本轮无交换就提前停止”的优化，不能套给所有实现。

std::sort 不保证稳定，比较次数要求 O(n log n)；自定义比较器必须满足严格弱序，不能用 `a<=b` 充当严格“小于”。典型冒泡的结论不能直接当作 std::sort 的结论。[标准排序接口与要求](https://eel.is/c++draft/alg.sorting)

### 查找边界

在升序 vector 的常见使用下，lower_bound 找首个 ≥x，upper_bound 找首个 >x，二者差可计 x 的个数。调用前要满足相应有序/划分条件，不能对随意无序数据套结果。

有序数组二分 O(log n)；如果先排序再查一次，总成本还包含 O(n log n) 排序。对非随机访问迭代器使用通用 lower_bound，不能只凭比较次数就把所有移动成本也算成 O(log n)。

## 六 树 图与算法适用条件

### 基本结构

非空树有 n 个节点时有 n−1 条边，且连通无环；一般无向图仅有 n−1 条边还不足以证明它是树，仍需连通等条件。森林与一棵树也要区分。

二叉树每点至多两个孩子，不保证平衡或有序。完全二叉树、满二叉树、二叉搜索树是不同约束；二叉搜索树在相应有序定义下中序遍历有序，但普通二叉树没有这个保证。堆只保证父子间堆序，整个底层数组不必全局有序。

若二叉树的度只计孩子数，叶子数 n0、单孩子数 n1、双孩子数 n2，则边数一方面为 n−1，一方面为 n1+2n2，结合 n=n0+n1+n2 可得 n0=n2+1。先说明度的含义，不与无向图节点度数混用。

### 搜索与最短路

- DFS/BFS 都能遍历连通区域；普通 DFS 首次到达不保证最短路线。
- 普通 BFS 适合无权或等代价最少边数问题；多源仅改变初始起点集合。
- Dijkstra 的通常正确性依赖非负边权，零权可用；第一次入堆不是确定最短距离。
- Floyd 求任意两点距离，常见时间 O(n³)、空间 O(n²)，经典原地转移中中转点 k 在最外层；负边可处理，但相关负环会使最短距离不再有限。
- Bellman-Ford 允许负边并可检测源点可达的负环，常见复杂度 O(nm)；知道用途即可，不必临时新增模板。

### 生成树 并查集与拓扑

最小生成树优化连通所有点的总建边成本；最短路优化源点到目标的路径长度，二者目标不同。连通无向图的生成树取 n−1 条边；不连通时没有覆盖全部节点的一棵生成树。

Kruskal 按权选边并防环；并查集维护集合与连通性，不直接维护最短距离，也不能直接用无向判环方法判断有向环。拓扑排序适用有向无环图：顺序可能不唯一；若不能取完全部顶点，说明存在有向环。

## 七 复杂度 动态规划与基础数学

### 复杂度从总工作量计算

嵌套循环不是机械相乘：内层跑 i 次时总量是求和；两指针都只向前移动时，总移动可能只有 O(n)。数值翻倍或减半通常对应对数轮数。二分答案的总复杂度为 check 代价乘二分轮数，不能漏掉每次 check。

多组数据要算各组总量；输入本身也有成本。算法时间与额外空间分别计算，递归调用栈也算额外空间。O(1) 不代表零操作，O(log n) 查找不代表包含读入的整个程序只有 O(log n)。

### DP 和贪心的条件

0/1 背包每件只取一次，一维压缩常倒序读取上一轮状态；完全背包允许重复取，常正序读取本轮状态。求最少枚数 dp[0]=0，组合计数 dp[0]=1；同样的循环骨架不代表同样的状态含义。

组合忽略顺序，排列区分顺序。金额外层、硬币内层的对应计数常得到排列；不能从求最小值题的一种正确写法，推断计数题交换循环也不影响结果。

贪心需要论证某次局部选择不会破坏全局最优；二分答案需要可行性单调。连续子数组不能随意排序；有负数可能破坏特定和阈值滑窗的单调性，但不代表所有滑窗都禁止负数。

### 数学保底

- 1 不是质数，2 是最小质数且是唯一偶质数。试除到平方根；避免 d*d 溢出可用 d<=n/d，但先处理 n<2。
- gcd 用辗转相除；正整数 lcm 可用 a/gcd(a,b)*b，先除只能降低中间溢出风险，结果仍需检查范围。
- 快速幂来自指数二进制展开与反复平方，乘法次数 O(log 指数)；模幂乘法的中间值仍可能溢出。
- 正模数下，先计算 `r=x%m`，若 r<0 再加 m，可把余数规范为非负；取余时除数不能为零。常见 `(x%m+m)%m` 写法还要检查中间加法是否会溢出。
- 选 r 个不计顺序是组合数 C(n,r)，计顺序是排列数；一般 C(n,r) 不等于 n/r。组合数也可用杨辉递推，不必背复杂数论模板。
- 子数组必须连续，共 n(n+1)/2 个非空子数组；子序列可不连续，n 个位置的子集含空集共 2^n 个，不能混为一个数量。
- 样本空间等可能时，概率可由有利情况数/总情况数得到；条件概率、独立性都需要题目条件，不能想当然相乘。
