## 统一约定与基础片段

下面函数共用这些头文件和类型；均按节点 0..n−1 编号。题目输入若为 1..n，要统一减一或统一改为 n+1 容器。不要混用两套编号。G++ 下可用以下常见标准头文件；这里避免依赖新标准写法。

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
#include <numeric>
#include <functional>
#include <utility>
#include <climits>
#include <cstdlib>
using namespace std;
using ll = long long;
```

完整程序入口是 `int main()`；常用 `ios::sync_with_stdio(false); cin.tie(nullptr);`，输出后写 `'\n'`。读取 vector 前先确定大小；一维前缀和开 n+1 项，`pre[i+1]=pre[i]+a[i]`，闭区间 [l,r] 的和为 `pre[r+1]-pre[l]`。这些不是可以复制提交的整题答案，仍需自己写符合题面格式的输入输出。

库函数只固定一种写法：`sort(a.begin(),a.end())`；`lower_bound` 找首个 ≥x，`upper_bound` 找首个 >x。找不到会返回 end，不能直接解引用。乘积在计算前用 `1LL*a*b` 提升类型；long long 也有范围上限。

## A 无权图 BFS

记忆顺序：**距离全未到达 → 源点置零入队 → 出队 → 未到达邻居置距离并入队**。单源时传 `{s}`；多源传所有源点。源点和邻接点均须为有效编号。

```cpp
vector<int> bfs(const vector<vector<int>>& g, const vector<int>& sources) {
    vector<int> dist(g.size(), -1);
    queue<int> q;
    for (int s : sources) {
        if (dist[s] != -1) continue;
        dist[s] = 0;
        q.push(s);
    }
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v : g[u]) {
            if (dist[v] != -1) continue;
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }
    return dist;
}
```

距离数组兼作 visited；不是出队后才首次标记。用于等代价最短路，不用于任意带权图。时间 O(n+m)，额外空间 O(n)。网格版本把“枚举邻居”替换为四方向、越界与障碍判断，其余骨架不变，不再背第二份 BFS。

自测：三点链从左端出发，距离 0、1、2；从两端同时出发，距离 0、1、0；独立点保持 -1。若题目求全部传播结束时间，再根据距离和题意取答案，模板本身不替你决定输出目标。

## B 后序返回子树和

以下 TreeNode 只是训练用节点定义；力扣通常已提供，独立比赛可能给的是边或其他编码，要按输入建结构，不能把 TreeNode 接口视为输入格式。

```cpp
struct TreeNode {
    ll val;
    TreeNode* left;
    TreeNode* right;
    explicit TreeNode(ll x) : val(x), left(nullptr), right(nullptr) {}
};

ll subtreeSum(TreeNode* u, ll& answer) {
    if (u == nullptr) return 0;
    ll left = subtreeSum(u->left, answer);
    ll right = subtreeSum(u->right, answer);
    answer += std::abs(left - right);
    return left + right + u->val;
}
```

调用前 `ll answer=0;`，调用后输出 answer；函数返回值供父节点使用。一次后序 O(n)，递归栈 O(树高)。节点总和、差和累计答案都须在 ll 范围内；长链深递归可能需要改迭代。

自测：根 1、左 2、右 3，函数返回 6、answer 为 1；空树返回 0、answer 保持 0；单节点坡度为 0。不要把“返回子树和”背成所有树题的通解，高度、路径等问题需重新定义信息。

## C 基础背包

只记“**状态含义 → 初值 → 能否复用 → 转移目标**”。以下硬币均为正、金额非负，金额规模需允许开数组；组合版本假设面值互异，所有中间计数均能装入 ll。

```cpp
int minCoins(const vector<int>& coins, int amount) {
    const int INF = amount + 1;
    vector<int> dp(amount + 1, INF);
    dp[0] = 0;
    for (int coin : coins)
        for (int s = coin; s <= amount; ++s)
            dp[s] = min(dp[s], dp[s - coin] + 1);
    return dp[amount] == INF ? -1 : dp[amount];
}

ll coinCombinations(const vector<int>& coins, int amount) {
    vector<ll> dp(amount + 1, 0);
    dp[0] = 1;
    for (int coin : coins)
        for (int s = coin; s <= amount; ++s)
            dp[s] += dp[s - coin];
    return dp[amount];
}
```

每种物品只用一次的最大价值背包，核心是按物品外层、容量倒序：`for(int c=capacity;c>=weight;--c) dp[c]=max(dp[c],dp[c-weight]+value);`。这是“容量不超过 c”的最大值模型，不能照搬给恰好装满问题而忽略不可达状态。

组合计数以硬币外层固定处理顺序；金额外层、硬币内层的相应计数通常得到排列数。求最少枚数时，多种正确遍历方式可能存在，不背“完全背包必须 coin 放某一层”的口诀。

自测：{1,2} 凑 3，最少 2 枚、组合数 2；{2} 凑 3，最少 -1、组合 0；金额 0，最少 0、组合 1。每个函数时间 O(硬币数×金额)，空间 O(金额)。

## D 最小可行容量

限定：非空、正整数重量、保持顺序、物品不可拆、days≥1、所有和在 ll 范围内。记忆顺序：**可行判定 → 左界最大单件 → 右界总和 → 可行收右，不可行越过 mid**。

```cpp
bool canShip(const vector<int>& w, int days, ll capacity) {
    int used = 1;
    ll load = 0;
    for (int x : w) {
        if (x > capacity) return false;
        if (load + x > capacity) {
            ++used;
            load = 0;
        }
        load += x;
        if (used > days) return false;
    }
    return true;
}

ll minCapacity(const vector<int>& w, int days) {
    ll lo = *max_element(w.begin(), w.end());
    ll hi = accumulate(w.begin(), w.end(), 0LL);
    while (lo < hi) {
        ll mid = lo + (hi - lo) / 2;
        if (canShip(w, days, mid)) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
```

必须能解释容量增大后旧分组仍可用。下界不保证可行，当前 mid 可行也不保证最小。时间 O(n log(U+1))，U 为候选范围宽度，额外空间 O(1)。

自测：{1,2,3}、days=1 返回 6，days=3 返回 3；{5}、days=1 返回 5。修改为求最大可行值时，不能只改比较符而不重新检查区间与中点。

## E 并查集

记忆顺序：**每点自成集合 → find 找根并压缩 → 两根相同拒绝合并 → 小集合挂到大集合**。

```cpp
struct DSU {
    vector<int> parent, size;
    explicit DSU(int n) : parent(n), size(n, 1) {
        iota(parent.begin(), parent.end(), 0);
    }
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b) return false;
        if (size[a] < size[b]) swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};
```

适用合并与连通性查询。无向图逐边加入时，unite 返回 false 可用于发现成环边；不能据此判断有向环或最短距离。初始化 O(n)，路径压缩与按大小合并的单次操作摊还 O(α(n))，空间 O(n)。

自测：3 点依次合并 (0,1)、(1,2)、(0,2)，返回 true、true、false；新一组数据要重新构造 DSU。

## F 非负权 Dijkstra

按条件复写，不作为前五组都不熟时的新负担。记忆顺序：**距离无穷 → 源点零 → 小根堆取最小距离 → 丢过期项 → 松弛后入堆**。

```cpp
const ll DIST_INF = LLONG_MAX / 4;
using Edge = pair<int, ll>;   // 邻接表：邻居、权值
using HeapItem = pair<ll, int>;  // 堆：距离、节点

vector<ll> dijkstra(const vector<vector<Edge>>& g, int source) {
    vector<ll> dist(g.size(), DIST_INF);
    priority_queue<HeapItem, vector<HeapItem>, greater<HeapItem>> pq;
    dist[source] = 0;
    pq.push({0, source});
    while (!pq.empty()) {
        ll d = pq.top().first;
        int u = pq.top().second;
        pq.pop();
        if (d != dist[u]) continue;
        for (const Edge& e : g[u]) {
            int v = e.first;
            ll weight = e.second;
            if (d + weight < dist[v]) {
                dist[v] = d + weight;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}
```

要求非负边权，权值与所需有限距离均小于 DIST_INF，保证加法不溢出。输入是有向图时不自动加反向边。距离是中间结果，题目求最大延迟、某个终点或不可达个数，要另行处理。

自测：0→1 权 10、0→2 权 1、2→1 权 1，结果为 0、2、1；另加独立点，其距离保持 DIST_INF。使用允许重复入堆的写法，通用复杂度可估为 O(n+m log(m+1))，空间 O(n+m)。
