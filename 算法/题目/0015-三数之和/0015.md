# 15. 三数之和

## 0. 一句话题意

找出所有**互不重复**的三元组 `(a, b, c)`，使 `a + b + c = 0`。

## 1. 做题前 30 秒的第一反应

（当时未留记录。两版代码相隔约 1 分钟，看得出是**先写了"枚举中间"的版本，紧接着换成"枚举左侧"**，属于同一次做题里的自我修订）

- 直觉：先排序，然后双指针；难点不在求和，在**去重**
- 想抓的工具：`sort` + 双指针 + 一个去重容器

## 2. 卡点与尝试轨迹

| 版本 | 做法 | 结果 | 为什么不行 / 为什么行 |
| --- | --- | --- | --- |
| v1 `v1-枚举中间.cpp` | 排序后**固定中间元素** `mid`，左右指针在 `[0, mid)` 和 `(mid, n-1]` 上逼近；结果塞进 `set<vector<int>>` 去重 | 正确但笨 | ①`set` 去重把复杂度推到 O(n² log n)；②固定中点时两个指针活动范围被 `mid` 切开，`while (left < mid && mid < right)` 稍不注意就死循环 |
| v2 `v2-枚举左侧.cpp` | 排序后固定最左 `i`，问题退化成 167 两数之和；命中后左右各自跳过相同值，**去重做在过程中**，不用 `set` | 正确且标准 | 天然 O(n²) / O(1)；去重三处都在循环里 |

**v1 → v2 的转变就是这题的全部收获**：同样能过，但"用 `set` 事后去重"和"排序后跳过重复"是两种思维——前者是"先全做出来再收拾"，后者是"一开始就不产生重复"。

## 3. 关键洞察（题眼）

**排序 + 固定一个数 = 两数之和 II**。去重的本质是：排序后相同的值挨在一起，所以"跳过与前一个相同的值"就等于"跳过重复的解"。

## 4. 正确性与复杂度

- 为什么对：固定 `i` 后 `nums[l] + nums[r]` 关于 `l` 单调增、关于 `r` 单调减，双指针不会漏解；每处跳过相同值保证每个三元组只被输出一次。
- v1：时间 O(n² log n)（n² 个候选 × `set` 插入 log），空间 O(n)（`set` 里最多 O(n²) 个元素，实际更少）。
- v2：时间 O(n²)，空间 O(1)（不计返回值）。
- 边界清单：`n < 3`（直接返回空）／全 0（只有一个 `[0,0,0]`）／大量重复元素／`i` 与 `i-1` 相同要 `continue`。

**要点**

1. 排序 → 枚举 `nums[i]`，问题变成"在有序数组里找两数和为 `-nums[i]`"，即 167 题。
2. **外层去重**：`nums[i] == nums[i-1]` 直接 `continue`（否则同一组解会被 `i-1` 也枚举一遍）。
3. **内层去重**：命中后跳过相同的 `nums[j]` 与 `nums[k]`（只跳过 `j` 也可以）。
4. **优化一**：`nums[i] + nums[i+1] + nums[i+2] > 0` → 后面最小的两个都超了，`break` 整个外层。
5. **优化二**：`nums[i] + nums[n-2] + nums[n-1] < 0` → 当前 `i` 配最大的两个都不够，但 `i` 变大还有机会，`continue` 外层。

> 优化一/二是"用当前区间的极值先做一次判定"，属于双指针题通用的剪枝套路：**极值都满足/都不满足时，整段可以跳过**。

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        ranges::sort(nums);
        vector<vector<int>> ans;
        int n = nums.size();
        for (int i = 0; i < n - 2; i++) {
            int x = nums[i];
            if (i && x == nums[i - 1]) continue; // 跳过重复数字
            if (x + nums[i + 1] + nums[i + 2] > 0) break; // 优化一
            if (x + nums[n - 2] + nums[n - 1] < 0) continue; // 优化二
            int j = i + 1, k = n - 1;
            while (j < k) {
                int s = x + nums[j] + nums[k];
                if (s > 0) {
                    k--;
                } else if (s < 0) {
                    j++;
                } else { // 三数之和为 0
                    ans.push_back({x, nums[j], nums[k]});
                    for (j++; j < k && nums[j] == nums[j - 1]; j++); // 跳过重复数字
                    for (k--; k > j && nums[k] == nums[k + 1]; k--); // 跳过重复数字
                }
            }
        }
        return ans;
    }
};
```
