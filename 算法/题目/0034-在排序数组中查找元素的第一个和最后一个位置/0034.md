#### 答疑

**问**：如何理解 `end = lowerBound(nums, target + 1) - 1` 这段代码？

**答**：要想找到 $\le \textit{target}$ 的**最后一个数**，无需单独再写一个二分。我们可以先找到这个数的右边相邻数字，也就是 $> \textit{target}$ 的**第一个数**。在所有数都是整数的前提下，$> \textit{target}$ 等价于 $\ge \textit{target}+1$，这样就可以**复用**我们已经写好的二分函数了，即 `lowerBound(nums, target + 1)`。然后将其减一，就得到 $\le \textit{target}$ 的最后一个数的下标。

**问**：如果 $\ge \textit{target}+1$ 的第一个数不存在怎么办？

**答**：这说明数组中的数都 $\le \textit{target}$。如果数组中有 $\textit{target}$，那么数组的最后一个数（下标 $n-1$）就是 $\textit{target}$（因为数组是递增的）。`lowerBound(nums, target + 1)` 在这种情况下会返回 $n$，减一得到 $n-1$，这正是我们要计算的下标。

**问**：为什么要写 `left + (right - left) / 2`？

**答**：在面试或者实际场景中，你不一定知道输入的数组有多长，万一数组长度达到 $\texttt{int}$ 最大值，`left + right` 可能会发生加法溢出。当然，如果只看本题的数据范围，写 `(left + right) / 2` 也可以。对于 Python 来说，由于没有溢出这个概念，所以可以直接相加。

**问**：怎么判断我写的是哪一种二分？

**答**：看 $\texttt{while}$ 循环的条件，如果是 `left <= right`，就是闭区间；如果是 `left < right`，就是半闭半开区间；如果是 `left + 1 < right`，就是开区间。

**问**：关于闭区间写法，为什么 `nums[mid] >= target` 成立的时候要写 `right = mid - 1`？此时的 $\textit{mid}$ 不是有可能是答案吗？这样写不会错过答案吗？

**答**：「二分范围」和「答案所在范围」是两个概念。设现在二分的范围是闭区间 $[L,R]$，如果下标在 $[L,R]$ 中的数都小于 $\textit{target}$，根据循环不变量，答案是 $R+1$。由此可见，当我们在闭区间 $[L,R]$ 中二分时，答案所在范围是 $[L,R+1]$。顺带一提，如果题目保证答案在闭区间 $[a,b]$ 中，则可以在 $[a,b-1]$ 中二分，如果这个范围内的数都不满足要求，那么剩下的 $b$ 就是答案（排除所有错误答案后，剩下的一定是正确答案）。

**问**：我看到一种二分的写法，在二分的过程中，额外记录答案的值。如何评价这种写法？

**答**：喜欢这种写法的同学，推荐写开区间二分。开区间二分 $\texttt{if}$ 条件成立时更新的是哪个变量，最后返回的就是哪个变量。这和记录答案的做法如出一辙。

**问**：关于开区间二分，如何理解 $-1$ 和 $n$ 这两个下标？

**答**：可以假设 $\textit{nums}[-1] = -\infty$ 以及 $\textit{nums}[n]=\infty$，此时 $\textit{nums}$ 仍然是有序的。在这种情况下，$\textit{nums}[-1] < \textit{target}$，所以 $-1$ 是红色；$\textit{nums}[n] \ge \textit{target}$，所以 $n$ 是蓝色。这个思想可以推广到二分答案，见本文末尾的二分题单。

- 空间复杂度：$\mathcal{O}(1)$。
