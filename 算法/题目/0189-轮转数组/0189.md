# 189. 轮转数组

## 0. 一句话题意

把数组**原地**右移 `k` 位（`k` 可能大于 `n`），要求 O(1) 额外空间。

## 1. 做题前 30 秒的第一反应

（当时未留记录）从代码看，直接用了"整体反转 + 两段分别反转"的方案，并且用了 `ranges::reverse`（C++20）。

- 直觉：把 `A+B` 变成 `B+A`
- 没有走"用辅助数组/环状覆盖"的路线，说明知道这个技巧

## 2. 卡点与尝试轨迹

| 版本 | 做法 | 结果 | 说明 |
| --- | --- | --- | --- |
| v1 `v1-三次反转.cpp` | `k %= n`；`reverse(nums)`；`reverse(nums[0..k))`；`reverse(nums[k..n))` | 通过 | 三行，O(1) 空间 |

## 3. 关键洞察（题眼）

**反转两次 = 不变，所以"反转整体"相当于先把两段的位置交换，再各自反转回来。**

`[A|B] --整体反转--> [rev(B)|rev(A)] --分别反转--> [B|A]`。

## 4. 正确性与复杂度

- 为什么对：每次反转都是双射，组合后等价于把前 `n-k` 个与后 `k` 个整体互换，且各自内部顺序恢复。
- 时间 O(n)，空间 O(1)。
- 边界清单：`k = 0`（`k %= n` 后为 0，`reverse(begin, begin+0)` 安全）／`k = n`（同 0）／`k > n`（必须取模）／`n = 1`／空数组（`nums.size()` 为 0 时 `k %= 0` 会崩，LeetCode 保证非空但本地测试要注意）。

**要点**

1. 结论：`A+B → B+A` 可以"三次反转"完成。
2. 直觉："负负得正"——一个子数组反转两次就复原，所以第一次整体反转的作用其实是**交换两段的位置**。
3. 严格推导：`rev(A+B) = rev(B) + rev(A)`；再分别反转 `rev(B)`、`rev(A)`，即得 `B + A`。
4. `k %= n` 把 `k ≥ n` 化归到 `0 ≤ k < n`。

```cpp
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        k %= nums.size(); // 轮转 k 次等同于轮转 k % n 次
        ranges::reverse(nums);
        reverse(nums.begin(), nums.begin() + k);
        reverse(nums.begin() + k, nums.end());
    }
};
```
