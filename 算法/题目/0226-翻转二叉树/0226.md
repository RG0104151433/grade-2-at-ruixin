# 226. 翻转二叉树

## 0. 一句话题意

把二叉树每个节点的左右孩子互换，返回翻转后的根。

## 1. 做题前 30 秒的第一反应

（当时未留记录。以下是回看代码时的复盘，**不是当时的想法**。）

- 直觉：整棵树的翻转 = 根的两个孩子互换 + 两棵子树各自翻转
- 复杂度预算：节点数 ≤ 100，怎么写都行，但应该练成 O(n) 的模板
- 想抓的工具：递归

## 2. 卡点与尝试轨迹

| 版本 | 做法 | 结果 | 为什么行 |
| --- | --- | --- | --- |
| v1 `v1-递归交换.cpp` | 先存 `tmp = root->left`，交换左右，再递归翻转两边，返回 root | 能过 | 交换与递归互不影响；先存 tmp 避免覆盖 |

## 3. 关键洞察（题眼）

**"翻转"是可交换的：先交换再递归，和先递归再交换，结果一样。**

真正容易错的是**指针覆盖**：

```cpp
root->left = invertTree(root->right);   // 原来的 left 已经丢了
root->right = invertTree(tmp);          // 所以必须先存 tmp
```

这和数组里的 `swap(a, b)` 是同一件事——先备份再赋值。

## 4. 正确性与复杂度

- 为什么对：对节点数归纳。空树翻转还是空树；非空树翻转后，根的左子树 = 原右子树翻转，右子树 = 原左子树翻转，归纳假设保证子树内部也正确。
- 时间 O(n)：每个节点访问一次。
- 空间 O(h)：递归栈。
- 边界清单：空树（返回 `nullptr`）／单节点（交换两个空指针，返回自己）／只有一边孩子／链状树。
