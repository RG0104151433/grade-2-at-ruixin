# 236. 二叉树的最近公共祖先

## 0. 一句话题意

给一棵二叉树和两个节点 `p`、`q`（保证都在树里），求它们的最近公共祖先（LCA）。

## 1. 做题前 30 秒的第一反应

（当时未留记录。以下是回看代码时的复盘，**不是当时的想法**。）

- 直觉：从根往下找，如果 p、q 分居两侧，当前节点就是答案；如果都在同一侧，就往那一侧走
- 复杂度预算：节点数 ≤ 10⁵，只能 O(n)，不能每个节点都去搜一遍
- 想抓的工具：后序递归，一次遍历

## 3. 关键洞察（题眼）

**递归函数的返回值不是 bool，而是"这个子树里能找到的答案节点"。**

定义 `dfs(root)`：

- 返回 `nullptr`：子树里 p、q 都没有；
- 返回 `p` 或 `q`：子树里只找到了其中一个；
- 返回其他节点：这个节点就是子树内的 LCA（p、q 都在里面且已分叉）。

于是在当前节点：

```cpp
if (!root || root == p || root == q) return root;  // 找到 p/q，或空
left  = dfs(root->left);
right = dfs(root->right);
if (left && right) return root;   // 分居两侧 → 当前就是 LCA
return left ? left : right;       // 都在同一侧 → 把那一侧的结果往上抛
```

**为什么 `root == p` 可以直接返回？** 因为题目保证 q 也在树里：
如果 q 在 p 的子树里，p 就是 LCA；如果 q 不在，那么另一侧会返回 q，上一层会因 `left && right` 把 LCA 判出来。
所以"提前返回 p"不会漏答案。

## 4. 正确性与复杂度

- 为什么对：对子树大小归纳。若 p、q 分居当前节点两侧，最近公共祖先只能是当前节点；若同侧，LCA 必在那一侧，另一侧返回 `nullptr`，`return left ? left : right` 把它带上来；若当前节点本身是 p 或 q，它一定是 LCA 或 LCA 的祖先，提前返回后由上层判定。
- 时间 O(n)：最坏每个节点访问一次。
- 空间 O(h)：递归栈；链状树 h = n，10⁵ 时要注意栈深度（本题一般能过，但本地可改迭代/手动栈）。
- 边界清单：p 是 q 的祖先（示例 2：p=5, q=4 → 5）／root 就是 p／只有两个节点／p、q 分别在根的两侧。
