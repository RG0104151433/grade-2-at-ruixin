# 274. H 指数

## 0. 一句话题意

给每篇论文的引用次数，求最大的 `h`，使得**至少有 h 篇**论文的引用次数 **≥ h**。

## 3. 关键洞察（题眼）

**`h` 不可能超过论文总数 `n`，所以引用次数大于 `n` 的论文可以一律看成 `n`。**

于是"值域"被压到 `[0, n]`，可以直接开桶计数；再从 `h = n` 往下累加，累加值 `s` 第一次 `>= h` 时就是答案。

## 4. 正确性与复杂度

- 为什么对：倒序累加时，`s` 的含义是"引用次数 ≥ i 的论文数"；从大到小找，第一个满足 `s >= i` 的 `i` 必然最大。
- v1：时间 O(n log n)（排序）+ O(log n)（二分），空间 O(1)。
- v2：时间 O(n)，空间 O(n)。
- 边界清单：空数组（n=0，`cnt` 只有长度 1）／全部为 0（答案 0）／全部相同／超大值（必须靠 `min(x, n)` 截断，否则越界）。

**要点**

1. 先把题意翻译成：求最大的 `h`，使得数组中至少有 `h` 个数 `>= h`。
2. `h` 不超过 `n`，所以"引用次数 > n"统一记作 `n`——反正只关心有多少个 `>= i`。
3. `cnt` 长度 `n + 1`，统计 `min(citations[i], n)`。
4. 从 `i = n` 倒序累加 `s`；第一次 `s >= i` 即为答案（因为是从大到小找，第一个满足的就是最大值）。

```cpp
class Solution {
public:
    int hIndex(vector<int>& citations) {
        int n = citations.size();
        vector<int> cnt(n + 1);
        for (int c : citations) {
            cnt[min(c, n)]++; // 引用次数 > n，等价于引用次数为 n
        }
        int s = 0;
        for (int i = n; ; i--) { // i=0 的时候，s>=i 一定成立
            s += cnt[i];
            if (s >= i) { // 说明有至少 i 篇论文的引用次数至少为 i
                return i;
            }
        }
    }
};
```
