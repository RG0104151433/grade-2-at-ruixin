# 419. 棋盘上的战舰

## 0. 一句话题意

棋盘上有一堆 `'X'` 组成的战舰，每艘只能是横着或竖着的一条，舰与舰之间至少隔一个空格。求战舰数量。

## 1. 做题前 30 秒的第一反应

（当时未留记录。以下是回看代码时的复盘，**不是当时的想法**。）

- 直觉：数连通块 → DFS/BFS 淹掉每一艘
- 复杂度预算：m、n ≤ 200，O(mn) 没问题
- 题目的进阶要求：一次扫描 + O(1) 额外空间 + 不修改棋盘 → 说明存在更巧的数法

## 2. 卡点与尝试轨迹

| 版本 | 做法 | 结果 | 为什么行 |
| --- | --- | --- | --- |
| v1 `v1-只数左上角.cpp` | 只统计"上方不是 X 且左方不是 X"的 X | 能过 | 每艘战舰恰好有一个这样的"起点" |

## 3. 关键洞察（题眼）

**不用淹连通块，只数每艘船的"左上角起点"。**

一艘横船：最左边的格子左边是空的（或边界），它上面的格子也不是 X（因为船只有一行）。
一艘竖船：最上面的格子上边是空的（或边界），它左边的格子也不是 X。
所以条件

```cpp
board[i][j] == 'X'
&& (i == 0 || board[i-1][j] != 'X')   // 上面不是船身
&& (j == 0 || board[i][j-1] != 'X')   // 左边不是船身
```

对每艘船**恰好成立一次**。这正好满足进阶要求：一次扫描、O(1) 空间、不修改棋盘。

> 题目保证舰与舰之间至少隔一个空格，所以不会出现"两艘船挨着"导致起点数错的情况；
> 即使没有这个保证，这个条件数的也是"连通块的左上角"，对 L 形等形状才会失效——本题限定是直线。

## 4. 正确性与复杂度

- 为什么对：每艘直线战舰有且只有一个格子同时满足"上面不是 X、左边不是 X"（它的两端中朝上/朝左的那一端）；不同战舰的起点不同，所以计数 = 战舰数。
- 时间 O(mn)：每个格子常数次判断。
- 空间 O(1)：不修改棋盘、不用 visited。
- 边界清单：全空（0）／全 X 的一行（1）／全 X 的一列（1）／单格 `'X'`（1）／单格 `'.'`（0）／边界上的船（`i==0`、`j==0` 要短路）。

## 6. 可迁移

- 触发信号：网格里数"形状规则的块"，且题目要求 O(1) 空间/不修改原图
- 关键手法：**数代表元**——给每个块选一个唯一的"起点"，只数起点，不做搜索
- 同类思想：数岛屿时只数"左、上都不是陆地的陆地"（但那只适用于不能有 L 形/复杂形状的情况）；数逆序对时数"每个元素作为右端点"的贡献
- 下次见到"数连通块 + 形状受限 + 要求 O(1) 空间"先想：能不能只数每个块的某个特征位置？
