# 462. 最小操作次数使数组元素相等 II

> 文件名标注是"不整理"，所以这里只留**一句话题意 + 题眼 + 边界**，不写长篇。
> 代码原样保留，不改写。

## 0. 一句话题意

每次可以让一个元素 +1 或 −1，求让所有元素相等的最少操作次数。

## 1. 代码

| 文件 | 思路 | 复杂度 | 备注 |
| --- | --- | --- | --- |
| `v1-中位数.cpp` | 排序后取中位数，累加 `abs(a[i] - median)` | O(n log n) / O(1) | 偶数个时取中间两数的平均值 |

## 2. 题眼

**最小化 `Σ|a[i] - x|` 的 `x` 是中位数。**

偶数个元素时，任意介于中间两个数之间的 `x` 都最优，代码取平均值也可以。
操作数就是每个元素到中位数的距离之和。

## 3. 边界清单

- n = 1 → 0
- 全部相等 → 0
- 偶数个：中间两数取平均不改变最优值
- 负数：`abs` 正常处理
- 题目保证答案在 32 位内，所以 `int ans` 够用；但若自己改题扩大范围，累加要换 `long long`

## 4. 与 453 的区别（最容易混）

| | 453 | 462 |
| --- | --- | --- |
| 一次操作 | n−1 个元素 +1 | 1 个元素 ±1 |
| 等价于 | 1 个元素 −1 | 直接改一个元素 |
| 目标值 | 最小值 | 中位数 |

## 5. 可迁移

- 触发信号："每次 ±1 使所有元素相等" → L1 距离最小 → 中位数
- 下次见到"选一个点使总距离最小"先想：中位数；如果是二维曼哈顿距离，就是两个维度分别取中位数
