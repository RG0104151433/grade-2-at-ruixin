## 【计挑赛补充 2026-11-21】先分清组合与排列

> 【建模提醒 2026-11-22】码蹄杯 DP 合集在 322 的文字中写“coin 放在内层”，但代码实际以 coin 为外层。不要把循环位置当作完全背包的定义：优化题与计数题需分别分析状态与顺序。先根据题意明确“优化/计数、组合/排列、一次/无限”，再用下文核对；已看到标签与骨架的旧题只算复习，不作为独立建模证据。

读题圈出“每种面值可无限使用”“凑成总金额”“组合数”。518 不区分硬币的排列顺序，面值应为正且互不相同。若换题允许重复面值，须先明确同面值是否视作同一种，不能照搬计数。

`dp[s]` 表示只使用当前已经处理的面值，凑出金额 s 的组合数。初始 `dp[0]=1`，其余为 0；空选择是后续方案的起点，不是错误多计。

```cpp
// 类型仍需按具体题目的答案范围选择。
vector<long long> dp(amount + 1, 0);
dp[0] = 1;
for (int coin : coins)
    for (int s = coin; s <= amount; ++s)
        dp[s] += dp[s - coin];
```

外层面值固定了组合的处理次序，内层金额递增允许重复取当前面值。改为金额外层、面值内层，会按“最后一个硬币”区分不同顺序，通常统计排列（377 型）；改成每个面值外层、金额递减，则每轮只允许该物品用一次，是 0/1 背包方向。

**最小反例：**面值 {1,2}、金额 3，组合为 {1,1,1}、{1,2} 共 2；排列多出 {2,1}，共 3。金额 0 返回 1；面值 {2}、金额 3 返回 0。322 求最少枚数，转移用 min，并设不可达值，不能照抄这里的累加。

金额 0 并不意味着数组长度为 0，dp 要有 amount+1 项。计数题即使最终答案有限，中间状态也要检查范围；没有取模要求不能自行取模。时间 O(面值种数×金额)，空间 O(金额)。
