# 563. 二叉树的坡度

## 0. 一句话题意

每个节点的坡度 = 左子树节点和与右子树节点和之差的绝对值；求整棵树所有节点坡度之和。

- 直觉：要算一个节点的坡度，得先知道左右子树的节点和 → 需要一个"求子树和"的函数

## 3. 关键洞察（题眼）

**父节点需要的"子树和"正好可以由子节点返回——所以一次后序遍历就够了。**

`dfs(root)` 返回"以 root 为根的子树节点和"，同时在返回前把 `|左和 - 右和|` 加到全局答案：

```cpp
int dfs(TreeNode* root, int& ans) {
    if (!root) return 0;
    int l = dfs(root->left, ans);
    int r = dfs(root->right, ans);
    ans += abs(l - r);      // 后序：左右都算完了，才轮到当前节点
    return l + r + root->val;
}
```

v1 的问题不是错，而是**重复计算**：`getSum` 在每个节点上把整棵子树再走一遍，链状树退化成 O(n²)。

## 4. 正确性与复杂度

- 为什么对（一次后序版）：后序遍历保证进入当前节点时，左右子树的和已经算好；当前节点的坡度只依赖这两个和；每个节点贡献一次，累加即总和。
- v1 时间：平衡树 O(n log n)，链状树 O(n²)；空间 O(h)。
- 优化版时间 O(n)，空间 O(h)。
- 边界清单：空树（0）／单节点（0）／只有一边孩子（另一边和按 0 算）／节点值为负（坡度和仍是绝对值和，不要假设正数）／链状树（节点数 10⁴，递归深度可能偏大）。
- v1 代码里 `root->left == nullptr && root->right == nullptr` 的优先级是对的（`&&` 高于 `||`），叶子提前返回不影响答案（叶子坡度本来就是 0）。
