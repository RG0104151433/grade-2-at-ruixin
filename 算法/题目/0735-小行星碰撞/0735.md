# 735. 小行星碰撞

## 0. 一句话题意

数组里正数向右飞、负数向左飞，绝对值是大小。相遇时小的爆炸、相等同归于尽，求剩下的。

## 1. 做题前 30 秒的第一反应

代码里的注释留下了当时的判断顺序，可以还原：

> `// 注意负数也有可能可以直接入栈`
> `// 到后面会发现需要一个变量来维护该小行星是否爆炸`

- 直觉：用栈维护"还没爆炸的、在左边等着被撞的"小行星
- 踩到的第一层：以为负数一律要打架，其实**栈顶也是负数时不会撞**（同向飞）
- 踩到的第二层：撞完一颗之后自己可能还活着，要继续撞 → 需要一个 `alive` 标记

## 2. 卡点与尝试轨迹

| 版本 | 做法 | 结果 | 说明 |
| --- | --- | --- | --- |
| v1 `v1-栈模拟.cpp` | 入栈条件写成 `stk.empty() \|\| a > 0 \|\| (a < 0 && stk.back() < 0)`；否则进 `while` 与栈顶对撞，`alive` 决定最后是否入栈 | 通过 | 逻辑覆盖完整，但条件写得很长 |

当时留下的两处可以优化的写法（复盘时改）：

- 入栈条件可以简化：**只有"当前向左 且 栈顶向右"才需要打**，其余一律直接入栈
- `int len = stk.size(); if (stk[len-1] > 0 && ...)` → 直接 `stk.back()`
- 用 `a + stk.back()` 的正负判断大小关系，不如直接比较 `|a|` 与栈顶，语义更直观

## 3. 关键洞察（题眼）

**只有"栈顶向右、当前向左"这一种组合会碰撞。** 于是：
栈顶向右且 `|栈顶| <= |a|` → 栈顶爆炸、继续；栈顶向右且 `|栈顶| > |a|` → 当前爆炸、结束；其余情况直接入栈。

## 4. 正确性与复杂度

- 为什么对：栈里始终保存"处理到当前位置为止，仍然存活的小行星"，且顺序与真实位置一致；新来的只会和最右的存活者相撞，所以只查栈顶就够。
- 时间 O(n)：虽然写了两层循环，但每颗小行星最多入栈一次、出栈一次，总循环次数是 O(n)。
- 空间 O(n)。
- 边界清单：空数组／全正（原样）／全负（原样）／`[1,-1]`（空）／`[-1,1]`（不撞）／`[10,2,-5]`（`2` 没了，`10` 还在）。

**要点**

1. 向右的小行星**无条件入栈**；只有向左的才可能要打。
2. 向左时：`while` 栈顶向右，比较 `top` 与 `-x`：
   - `top <= -x`（含相等）→ 栈顶爆炸，`pop`；相等时不会 `break`，会接着往下打
   - `top >= -x` → `x` 爆炸，`ok = false`，`break`
3. 循环结束 `ok` 为真才入栈。

> 与我的 v1 相比，他把"相等"塞进了两个 `if`（既 pop 又置 `ok=false`），省掉了单独的分支；本质仍是"用绝对值比较"。这种"一个分支顺带处理边界"的写法值得学，但可读性要靠注释兜住。
