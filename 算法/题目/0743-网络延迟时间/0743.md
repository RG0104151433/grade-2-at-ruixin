## 【计挑赛补充 2026-11-21】传播时间与模型边界

**审读：**一条 `(u,v,w)` 只表示 u→v，不能补成无向边；源点为 k，信号可以向不同方向传播，不要求一条路线经过所有点。求全部节点收到信号的最早时间，因此答案为 `max(dist[v])`；存在不可达点则 -1，不是 `sum(dist)`。

本题非负边权，可用 Dijkstra；若改为所有边代价相同，可考虑 BFS；出现负权边就要重新选算法。不能因为题目有“传播”二字直接照搬 994 的普通队列分层。

只重写下面一段（需已建好 g，并初始化 dist 为 INF；节点按原题编号）：

```cpp
using P = pair<long long, int>;  // 距离在前，节点编号在后
priority_queue<P, vector<P>, greater<P>> pq;
dist[k] = 0;
pq.push({0, k});
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d != dist[u]) continue;  // 丢弃旧距离
    for (auto [v, w] : g[u])
        if (d + w < dist[v]) {
            dist[v] = d + w;
            pq.push({dist[v], v});
        }
}
```

默认 priority_queue 是大根堆；距离更新就重新入堆，不能在第一次入堆时认为该点已经求得最短距离。旧模板若迁移到大权值题，应把 dist 和加法都按范围升级为 long long，并选择有余量的 INF。

反例：1→2 权 10，1→3 权 1，3→2 权 1；dist[2]=2，全部完成时间为 2。只有 1→2 而 n=3 时返回 -1；不要把未到达点的初始值当作有效时间。

本题可按简单图范围估算堆实现为 O((n+m)log n)，邻接表与堆的最坏额外空间 O(n+m)。若迁移到允许大量平行边的通用实现，逐次入堆的复杂度可写得更保守为 O(n+m log(m+1))。
