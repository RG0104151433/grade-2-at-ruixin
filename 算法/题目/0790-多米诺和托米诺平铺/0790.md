# 790. 多米诺和托米诺平铺

## 0. 一句话题意

用 `1×2` 的多米诺和 L 形托米诺，铺满 `2×n` 的板子，求方案数（对 1e9+7 取模）。

## 1. 做题前 30 秒的第一反应

（当时未留记录。从代码看，是**直接写出了递推式** `dp[i] = 2*dp[i-1] + dp[i-3]` 和初值 `dp[0]=dp[1]=1, dp[2]=2`，没有推导过程）

- 这说明当时的做法是"记得这个递推式"，而不是"能推出来"

真正的卡点不是代码，而是**为什么是 2f[i-1] + f[i-3]**。这个问题当时没有回答，记在 §3/§4 待补。

## 3. 关键洞察（题眼）

**按"最右边能独立切出来的那一块"分类**（末尾分割法），只有三种情况：

1. 最右一块是竖着的 `1×2` → 剩 `f[i-1]`
2. 最右是两块横着的 `2×1` → 剩 `f[i-2]`
3. 最右是一对 L 形（必须一左一右，中间全是横着的 `2×1`，个数 `0..i-3`）→ `2·(f[i-3] + f[i-4] + ... + f[0])`

累加得 `f[i] = f[i-1] + f[i-2] + 2Σf[j]`，再用 `f[i-1]` 的同类式子相减，就化简成 `f[i] = 2f[i-1] + f[i-3]`。

**这一步"化简"才是本题的题眼**，只背最后那行等式等于什么都没学到。

## 4. 正确性与复杂度

- 为什么对：末尾分割是**互斥且完备**的划分（最右可独立切出的块只能是一竖、两横、一对 L 形三种之一），所以不重不漏。
- 时间 O(n)，空间 O(n)（可滚动数组压到 O(1)）。
- 边界清单：`n = 1`（1）／`n = 2`（2）／`n = 3`（5）／取模别在 `int` 里做乘法（`2 * f[i-1]` 可能溢出 `int`，用 `long long`）。

**要点**

1. 定义 `f[i]` 为铺满 `2×i` 的方案数，答案 `f[n]`。
2. 考虑最右边能独立切出的矩形，三种情况：一竖（`f[i-1]`）、两横（`f[i-2]`）、一对 L 形（中间夹 `0..i-3` 个横块，每种子问题分别是 `f[i-3], f[i-4], ..., f[0]`，且每种有上下对称两种）。
3. 累加：`f[i] = f[i-1] + f[i-2] + 2Σ_{j=0}^{i-3} f[j]`；与 `f[i-1]` 的同式相减化简为 `f[i] = 2f[i-1] + f[i-3]`。
4. 定义 `f[0] = 1`，可统一从 `f[3]` 开始算（`f[2] = 2`）。
