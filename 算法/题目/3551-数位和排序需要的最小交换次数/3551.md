# 3551. 数位和排序需要的最小交换次数

## 0. 一句话题意

按"数位和"升序（数位和相同则按数值升序）给数组排序，每次可交换任意两个元素，求最少交换次数。

顺带记一个自己踩的编译级小坑（v1 注释里写的）：

> `// 在这里犯了个孩童般的错误：如果初始化了，就不能pushback了`

—— `vector<pair<int,int>> a;` 后 `push_back({...})` 是 O(1) 追加；但若写成 `vector<pair<int,int>> a(len);` 再 `push_back`，前 `len` 个默认元素会留下来，后面排序时全部错位。

## 3. 关键洞察（题眼）

**最少交换次数 = n − 置换环个数。**（长度 L 的环需要 L−1 次交换，所有环加起来就是 n − 环数。）

第二个洞察是数据结构：环的走法需要"我现在在位置 i，元素值 x，x 应该去位置 pos[x]"——所以必须维护 `值 → 目标位置`，而**排序键里必须带上原下标**，否则重复值无法区分。

## 4. 正确性与复杂度

- 为什么对：目标排列确定后，元素的位置构成若干置换环；环内一次交换最多让一个元素归位，且总能做到，故恰好 L−1 次。
- 时间 O(n log n)（排序）+ O(n)（数环）；空间 O(n)。
- 边界清单：已有序（环数 = n，答案 0）／只有一个环（答案 n−1）／**数位和相同的元素**（必须用值升序做二级键）／**数组里有重复值**。
- **⚠️ 已确认的错误**：v1 用 `unordered_map<值, 位置>`，**数组里有重复值时 `pos[值]` 会被后一个下标覆盖**，数环会数错。
  反例：`nums = [12, 12]`（两个数位和都是 2，已有序），正确交换次数 **0**，v1 返回 **1**（两个元素被数成一个环）。
  结论：重复值场景必须用 `值 + 原下标` 做键（v2 的做法），不能只拿值做键。
