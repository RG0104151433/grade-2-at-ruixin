# 3578. 统计极差最大为 K 的分割方式数

## 0. 一句话题意

把数组分割成若干**非空连续段**，要求每段的最大值 − 最小值 ≤ k，求分割方案数（对 10⁹+7 取模）。

## 1. 做题前 30 秒的第一反应

（当时未留记录。以下是回看代码时的复盘，**不是当时的想法**。）

- 直觉：分割方案数 → DP，`f[i]` 表示前缀 `nums[0..i-1]` 的方案数
- 转移：枚举最后一段的起点 `l`，`f[i] = Σ f[l]`，其中 `nums[l..i-1]` 的极差 ≤ k
- 难点：合法 `l` 是一个区间，如果每个 i 都重新扫一遍就是 O(n²)，需要 O(1) 维护这个区间的和

## 2. 卡点与尝试轨迹

| 版本 | 做法 | 结果 | 为什么行 |
| --- | --- | --- | --- |
| v1 `v1-单调队列DP.cpp` | 两个单调队列维护窗口最大/最小；`cur` 维护合法起点的 `f` 之和；窗口越界时从左边减掉 `f[left]` | 能过 | 合法起点左端单调右移，`cur` 可以增量维护 |

## 3. 关键洞察（题眼）

**对每个右端点 i，合法的最后一段起点构成一个区间 `[left_i, i-1]`，且 `left_i` 随 i 单调不减。**

于是：

1. 用两个**单调队列**维护当前窗口 `[left, i]` 的最大值和最小值：
   - `mx` 递减，队头是最大值；
   - `mn` 递增，队头是最小值。
2. 当 `nums[mx.front()] - nums[mn.front()] > k` 时，`left` 必须右移，同时把 `f[left]` 从 `cur` 里减掉。
3. `cur` 就是当前所有合法起点的 `f` 之和，于是 `f[i+1] = cur`。

代码里的顺序是：

```cpp
cur = (cur + f[i]) % mod;     // 先把"以 i 为起点"这一段算进来
push i into mn/mx;            // 更新极值
while (极差 > k) {
    cur = (cur - f[left++] + mod) % mod;  // 把不合法的起点移出
    pop fronts < left;
}
f[i+1] = cur;
```

**为什么要先加 `f[i]` 再收缩？** 因为最后一段至少包含 `nums[i]` 本身，起点 `i` 永远合法（单元素极差为 0），先把它加入候选，再处理更早的起点。

## 4. 正确性与复杂度

- 为什么对：任何分割方案按"最后一段的起点 l"唯一分类；`f[l]` 是前缀方案数，最后一段合法当且仅当 `l >= left_i`。`left_i` 单调是因为窗口右端右移时，极差只可能变大，左端不可能往左退。因此 `f[i] = Σ_{l=left_i}^{i-1} f[l] = cur`。
- 时间 O(n)：每个下标最多进/出每个队列一次，`left` 只增不减。
- 空间 O(n)：`f` 数组 + 两个队列。
- 边界清单：`k = 0`（每段只能全相等，示例 2）／n = 2／所有元素相同／极差刚好等于 k（**可以**分割，条件是 `> k` 才收缩）／取模减法要 `+mod` 再 `%mod`，避免负数／`nums` 值到 10⁹，差用 `int` 不会溢出（≤10⁹），但换成更大范围时要 `long long`。
- 答案对 10⁹+7 取模；`cur` 用 `long long` 存中间值。

## 6. 可迁移

- 触发信号："分割成连续段 + 每段满足极值/和/长度约束 + 求方案数"
- 关键手法：**DP + 合法转移区间 + 增量维护区间和**；区间端点单调时用双指针/单调队列
- 单调队列的适用信号：窗口在滑动，需要 O(1) 取最大/最小值
