# 3644. 排序排列

## 0. 一句话题意

`nums` 是 `0..n-1` 的排列。每次可选一个整数 `k` 和两个下标，交换的条件是 `nums[i] AND nums[j] = k`。问**最大的 k**，使得排列能被排成升序。

## 1. 做题前 30 秒的第一反应

（当时未留记录）从代码看：遍历一遍，把"错位位置"上的东西 AND 起来。

- 直觉：`k` 越大限制越松，所以想要一个"尽量大的可行 k"
- 想到的：所有错位元素都必须参与交换，所以 `k` 必须是它们的公共子集 → AND

## 3. 关键洞察（题眼）

**上界**：每个错位元素都必须被交换，所以 `k` 是每个错位元素值的子集 → `k` 最大只能是它们的 AND。

**可达性**：`k = 0` 时一定可行——`0 AND x = 0`，所以用 `0` 可以做"中转站"，三次交换实现任意一对元素的互换。`k = 上界` 时同理：`k` 是所有错位元素的子集，所以 `k AND x = k`，用它当中转站依然合法。

**我的实现与灵神的一处差异**：我 AND 的是**下标** `i`，他 AND 的是**值** `nums[i]`。两者等价，因为对排列而言"错位下标集合" = "错位值集合"：

> 若 `nums[i] ≠ i`，则值 `nums[i]` 也不在自己的位置上（否则 `nums[nums[i]] = nums[i]` 会让两个位置同值），所以 `nums[i]` 也是错位下标；两边集合大小相同，故相等。

## 4. 正确性与复杂度

- 为什么对：上界由"必须参与交换"给出；可达性由"用 k 当临时位置做三次交换"构造给出；两者相等即为答案。
- 时间 O(n)，空间 O(1)。
- 边界清单：已升序（返回 0，注意 `ans` 初值 `-1` 要特判）／`n = 1`／`k` 可能为 0。
- 小坑：`ans` 初值是 `-1`（二进制全 1）而不是 `0`，否则 AND 出来永远是 0。

**要点**

1. 已有序返回 0。
2. 先问"一定有解吗？"——有：`k = 0` 一定可以排好。
3. 构造：找到值为 `0` 的位置，若 `nums[0] ≠ 0` 就先与 `nums[0]` 交换（`0 AND 任何数 = 0`，合法）。
4. **三次交换实现任意一对元素的交换**：目标是 `0,a,b → 0,b,a`：交换 `0` 与 `a` → `a,0,b`；交换 `0` 与 `b` → `a,b,0`；交换 `0` 与 `a` → `0,b,a`。注意三次之后 `0` 的位置不变。（这就是 `k=0` 时一定可行的证明。）
5. 上界：`k` 是每个 `nums[i] ≠ i` 的 `nums[i]` 的子集，所以答案 ≤ 这些值的 AND（记为 `k`）。
6. 可达：`nums[k] ≠ k` 时，`nums[k] AND k = k`（因为 `k` 是 `nums[k]` 的子集），所以先把 `nums[k]` 与 `k` 换位，再用上面的三次交换技巧。
7. 注：参与的数的 AND 只会越来越小，所以 `0 ≤ k ≤ n-1`，`k` 一定在数组中。
