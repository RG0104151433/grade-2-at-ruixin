# 3942. 排序排列的最少操作数

## 0. 一句话题意

`nums` 是 `0..n-1` 的排列。允许两种操作：①反转整个数组；②整体循环移位（左/右旋）。求把它排成 `[0,1,...,n-1]` 的最少操作数，不行则 -1。

## 1. 做题前 30 秒的第一反应

代码里的注释留下了判断顺序：

> `// 看看左边绕一圈行不行`
> `// 再看看右边行不行`

- 直觉：先找到 `0` 的位置，作为锚点
- 想到的关键一步：把"环形"问题变成**从 `0` 出发沿一个方向检查相邻差是否为 1**
- 两个方向各算一种代价，取较小

## 3. 关键洞察（题眼）

**操作 1（反转）不改变元素的相邻关系，操作 2（循环移位）也不改变**——所以能排成升序的数组，只能是"某个升序环"或"某个降序环"的旋转。

我从 `0` 出发向两侧检查差值是否为 1：
- 向右一路 `+1` → 递增环（左旋/反转两次内解决）
- 向左一路 `+1` → 降序环（等价于"向左走数值递增"，就是灵神说的递减情形）

**与灵神的写法对照**：他找"唯一的断点 `p`"再判断端点关系，我用"从 `0` 出发走一圈"。两者等价——`p` 恰好等于 `0` 的下标 `pos + 1`，代入他的公式 `min(p, n-p+2)` / `min(p, n-p)+1` 就得到我的 `min(pos, n-pos+2)` / `min(pos+2, n-pos)`。**这说明两种表达都完整覆盖了 4 种情况**，不是漏解。

## 4. 正确性与复杂度

- 为什么对：可达的终态只有"两段有序"这一种结构，从 `0` 出发绕一圈检查差值即可唯一确定属于哪一类；每类的两种操作序列代价都被枚举，取最小即最优。
- 时间 O(n)，空间 O(1)。
- 边界清单：`n = 1`（答案 0）／已升序（0）／已降序（1）／全乱（-1）／`0` 在首尾时两个方向的代价是否会重复计算。
- 实现细节：`INT_MAX` 作哨兵，最后判 `ans == INT_MAX` 返回 -1；取模用 `(pos + n - 1) % n` 这类写法避免负数。

**要点**

1. **念珠比喻**：操作 2 是旋转念珠，操作 1 是把念珠翻面；两者都不会拆开念珠、不改变相邻关系。
2. 所以从 `[0,1,...,n-1]` 倒推，`nums` 只能是"某个递增排列的旋转"或"某个递减排列的旋转"。
3. **递增旋转**：设 `i` 是第一个 `nums[i-1] > nums[i]` 的下标。
   - 不存在 → 已递增，0 次
   - 只有一个且 `nums[0] > nums[n-1]` → `min(i, n-i+2)`
4. **递减旋转**：设 `i` 是第一个 `nums[i-1] < nums[i]` 的下标。
   - 不存在 → 已递减，1 次（反转）
   - 只有一个且 `nums[0] < nums[n-1]` → `min(i, n-i) + 1`
5. 两类都没有满足的 `i` → -1。

> 我的 v1 没直接找断点，而是从 `0` 出发走一圈；好处是不用单独讨论"端点关系"，坏处是 `pos` 的含义要自己记清楚（`0` 的位置 vs 断点位置）。

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums) {
        int n = nums.size();
        int cnt = 0;
        int p = 0;
        for (int i = 1; i < n && cnt < 2; i++) {
            if (nums[i - 1] > nums[i]) {
                cnt++;
                p = i;
            }
        }

        if (cnt == 0) { // 已是递增
            return 0;
        }
        int ans = INT_MAX;
        if (cnt == 1 && nums[0] > nums[n - 1]) { // 两个递增段
            ans = min(p, n - p + 2);
        }

        cnt = p = 0;
        for (int i = 1; i < n && cnt < 2; i++) {
            if (nums[i - 1] < nums[i]) {
                cnt++;
                p = i;
            }
        }

        if (cnt == 0) { // 已是递减
            return 1;
        }
        if (cnt == 1 && nums[0] < nums[n - 1]) { // 两个递减段
            ans = min(ans, min(p, n - p) + 1);
        }

        return ans == INT_MAX ? -1 : ans;
    }
};
```
