# 第一部分 · 方案总览

## 1.1 本方案回答什么

上一版方案（20261005）在「0 新图 / 四布尔零改动 / 预算封顶」的硬约束下，把第五结局做成了**四协议之上的元结局**：把已有的零件拼起来，不新增任何世界。本轮解除开发量约束后，问题升级为三个：

1. **同一主线四个结局，是不是最优结构？** —— 不是。四个协议里混着一个语义异质的成员（协议二 · 穹顶托管），它本质是"外部力量锁死的结果"，不是玩家的自由裁决。放在同一个裁决台上会让玩家误以为"四选一"，实际其中一档根本不由玩家决定。
2. **剧情还能不能挖出新的世界？** —— 能。原作与电影里还有一整片未被使用的素材（见第二部分），足以支撑一条独立于主线、也独立于七条扩展线的新故事线。
3. **结局体系的上限在哪里？** —— 本方案给出最终形态：**三协议（主线自由裁决）+ 穹顶线（合同锁死结局）+ 第五协议（共同署名）+ 第六协议（归还）＝ 6 个结局**，各居其位、互不打架。

## 1.2 动与不动清单

| 对象 | 处理 | 说明 |
| --- | --- | --- |
| 协议一 · 个人继承（inherit） | **保留** | 未签合同前提下的自由裁决之一 |
| 协议三 · 公共能源（public_energy） | **保留** | 同上 |
| 协议四 · 玩家公约（charter） | **保留** | 主线真结局，判定与 reviews 全部不动 |
| 协议二 · 穹顶托管（dome） | **单独分出** | 从童年房间裁决台移出，独立成「穹顶线」结局（见第三部分） |
| 第五协议 · 共同署名（fifth） | **保留不动** | resonance 轨道、第五信物、五段演出、排除项全部沿用 20261005 方案 |
| 新第六剧情线「第零线」 | **新增** | 全新场景「第零章」+ 全新角色「归零者」+ 全新结局（见第四部分） |
| 主流程段落 | 不动 | 三钥三关 → 水泵站 → 签约厅 → 童年房间 → 结局 的骨架保持 |
| 现有七条扩展线（K/M/D/N/F/X/E） | 不动 | 不重写、不删改；新线与既有线只在 reviews 层交叉引用 |
| 现有引擎判定 | 最小改动 | 仅童年房间热区集合减少一档；advanceIf / key 原子提交机制不动 |

## 1.3 结局体系最终形态（改动前后对照）

**改动前（20261005）**：

```
未签合同 ──→ 裁决台 ──→ 协议一 inherit（自由）
                   ├──→ 协议二 dome ── 唯一结果 ─────┐ ← 语义异质：与"自由裁决"并列
                   ├──→ 协议三 public_energy（自由）  │
                   └──→ 协议四 charter（自由）        │
签合同 ───────────────→ 同上，但被 buyoutBinding 锁死 ┘
第五协议（元结局，解除约束后仍独立）
```

**改动后（20261008）**：

```
未签合同 ──→ 童年房间（三热区）──→ 协议一 inherit
                              ├──→ 协议三 public_energy
                              └──→ 协议四 charter
签合同 ──→ 穹顶线（独立终局演出）──→ 协议二 · 穹顶托管（唯一结局，独立呈现）
第六剧情线（另一入口，选择驱动）──→ 第六协议 · 归还
第五协议 · 共同署名（元结局，四线合流，任意三协议之上）
```

结构收益：**裁决台的三个选项回归同质**（都是玩家价值观的自由裁决）；**被锁死的结局获得独立的叙事空间**（穹顶线不需要再和其他结局挤一屏正文）；**第六线获得独立入口**，不与主线裁决竞争。

# 第二部分 · 原作与电影灵感素材清单（本轮新增六项）

> 上一版已使用：三钥三门价值观阶梯、阿诺克年鉴、Warren Robinett 彩蛋（被藏起来的作者签名）、25 美分硬币、哈利迪遗言「现实是唯一真实的东西」、「谢谢你玩我的游戏」、电影三关=三次遗憾、配角即真相传递者、排行榜与被看见。
> 本轮新增六项，全部用于**穹顶线收束**与**第六线「第零章」**的设计。延续三原则：只映射不翻译、不新增原作事实、不剧透触发方式。

## 2.1 小说素材（四项）

### 2.1.1 绿洲的例行停机维护（The Scheduled Downtime）
- **原作事实**：小说中的绿洲设有固定时段的系统维护窗口，服务器短暂离线，玩家被强制登出，维护结束后再次登入——这是绿洲里唯一"世界不存在"的时间。
- **映射落点**：**第零章（Chapter Zero）只能在世界离线时抵达**。它不是地图、不是关卡，是**旧测试服的存档层**——正常在线时它不存在，维护窗口打开时它才"短暂醒来"。这给"另一个地方"提供了世界观内的合法性：**玩家不是去到一个新地点，而是去到一个"不该存在的时间"**。呼应彩蛋原初形态（Robinett 的房间是"程序不知道的地方"）——第零章是"服务器不知道自己还留着的地方"。

### 2.1.2 记忆录放设备 ONI 的禁忌（小说设定）
- **原作事实**：小说中存在可记录/回放感官记忆的设备（ONI），默认固件屏蔽记忆回放——"偷看记忆"是黑市行为，也是被系统禁止的边界操作。
- **映射落点**：第零章的核心冲突工具。归零者不是幽灵，而是**一段被离线备份的、无人有权回放的记忆**。玩家打开服务器柜＝非法接入记忆层；进入第零章＝观看一段"系统判定不该被看"的旧日志。这让第六线天然带有"你正在越界"的压力，与主线"把被丢掉的捡起来修好"形成对位：**母亲修的是实物，你接的是记忆**。

### 2.1.3 《战争游戏》（WarGames）的"不发射"抉择（小说第三关）
- **原作事实**：小说水晶钥关致敬《战争游戏》：胜利不是发射，而是**拒绝发射**——"赢的唯一办法，是不玩"。
- **映射落点**：第六协议「归还」的价值观根基。第五协议回答"记忆该由谁署名"；第六协议回答**"记忆该不该被拥有"**——归零者最后的请求不是继承、不是公开、不是署名，而是**让第零章随维护窗口自然消逝**（或按玩家 Z3 选择另两种结局）。"赢的唯一办法，是不玩"被改写为"保存的唯一办法，是放手"。

### 2.1.4 年鉴与"作者把自己写成谜语"（延续 20261005）
- **原作事实**：阿诺克年鉴＝作者把自己写进作品；读懂年鉴＝读懂作者。
- **映射落点（延伸）**：第零章里玩家读到的是**绿洲最早版本的登录日志**——那不是写给人看的日记，是写给机器的记录。归零者的"署名"不在任何年鉴页上，而在**一行从未被任何人读过的系统注释里**。这与 Warren Robinett 彩蛋同构：被保存下来的，是"作者留在作品里的存在痕迹"。

## 2.2 电影素材（两项）

### 2.2.1 结局的"停机日"意象（电影终局）
- **原作事实**：电影结尾，韦德做出与哈利迪遗言一致的裁决——绿洲不是遗产、不是私有物，玩家"回到现实"。片中多次出现"绿洲关闭/维护"作为世界边界的意象（IOI 计划中攻打前也利用维护时机）。
- **映射落点**：第六结局「归还」的终局画面——**停机日的绿洲**：空无一人的街道、定格在旧版本的广场、只有风循环的渲染器。正文以"谢谢你玩我的游戏"反转收束（见 4.4 结局正文）。

### 2.2.2 "谢谢你玩我的游戏"的镜像台词（电影 Aech/哈利迪）
- **原作事实**：电影终局哈利迪的告别语是"谢谢你玩我的游戏"——谢的不是胜利，是**有人认真玩了**。
- **映射落点**：第六结局的告别句改一字：「**谢谢你，让它休息**」——第五协议谢的是"被记住"，第六协议谢的是"被放手"。两枚镜面对着同一句台词，构成结局体系的情感闭环。

## 2.3 素材使用三原则（沿用 20261005，微调第 2 条）

1. **只映射不翻译**：停机维护→第零章、ONI→记忆接入、WarGames→归还抉择、谢幕词→让它休息。不出现"WarGames 决战"式的直接翻拍。
2. **不新增原作事实**：所有引用以上述已确认为准；不虚构小说/电影未出现的情节细节（如具体停机时刻、ONI 型号），文档内部同样不写死具体数值，留给落码确认。
3. **不剧透触发方式**：玩家未接触第六线前，主线无任何明示；服务器柜在未触发时以普通调查点形态存在（见 4.2）。

# 第三部分 · 结局体系重构：四协议 → 三协议 + 穹顶线

## 3.1 为什么单独分出的是协议二 · 穹顶托管

四协议中，其余三档（inherit / public_energy / charter）的达成路径全部以**未签合同**为前提，是玩家价值观的自由裁决：

| 协议 | 前提 | 性质 |
| --- | --- | --- |
| 一 · 个人继承 | 未签合同 | 自由裁决：把世界签成自己的名字 |
| 三 · 公共能源 | 未签合同 + 证据 | 自由裁决：供能归还公共 |
| 四 · 玩家公约 | 未签合同 + 三残页 + 在线见证 | 自由裁决：共同署名 |
| 二 · 穹顶托管 | **签任何合同（buyoutBinding）** | **唯一结果：被锁死，非裁决** |

协议二在语义上不属于"裁决台"：它没有选项，只有后果。把它与其他三档并列，是当前结构唯一的硬伤——玩家在童年房间看到四件童年物件，以为有四种未来，其中一种其实在签约厅就已经被决定了。**拆出的收益**：

1. 裁决台三热区恢复同质（都是价值观裁决）；
2. 穹顶托管获得独立的叙事分量——它不再是一屏正文，而是完整的"世界被托管"终局演出；
3. N 线（诺兰动机）与 D 线（债务）的收束从"条件化差分行"升级为**结构内必然落点**，合同线的正反馈完整闭合。

# 第四部分 · 第六剧情线「第零线 · 归零者」

## 4.1 定线与命名

| 项 | 定稿值 |
| --- | --- |
| 线名 | **第零线 · 归零者**（The Zero Line · The Reset）——内部代号 `zero_line` |
| 编号逻辑 | 七条既有扩展线（K/M/D/N/F/X/E）编号从 1 开始，本线取"第零章"的零，作为**编号之外的一条线**；对外称"第六剧情线"（按玩家可感知的剧情线数量序） |
| 主题钉法 | 主主题"谁该拥有记忆与遗产"的第二极回答：**遗产不仅该被正确分配，也该被允许完整放手** |
| 与主线关系 | 不竞争：主线裁决的是"绿洲归谁"；第六线裁决的是"一段不该被拥有的记忆归谁" |
| 与第五结局关系 | **同级隐藏结局、可兼得、不互斥**（详见第五部分） |
| 资源 | 新图 1 张（第零章，线框/文本风格残次世界）＋ 服务器柜子场景（复用 library 内嵌子场景，按 0.5 图折算申报）＋ 演出 2 段＋ 结局正文 1 段＋ reviews 增量 |

## 4.2 入口与选择（"另一处地方"的两段式进入）

### 4.2.1 第一段选择：发现（第三幕 · 图书馆）

library 主路上新增一个**可选调查点**「落灰服务器柜」（非主线热区，不做任何引导标注）：

| 玩家行为 | 结果 |
| --- | --- |
| 打开柜门 | 看到一台贴着「DO NOT POWER ON」标签的黑机箱与一卷落灰的旧备份磁带 → 获得 clue `zero_backup_tape`（「第零章的备份磁带」） |
| 离开 | 无变化；下一次经过仍可选（不剧透、不惩罚） |
| 反复打开（>2 次） | 机箱风扇会短暂转动一次——仅演出差异，不写状态（纯彩蛋，呼应 M 线"硬币回应"浮字体例） |

- 目的：把选择权完全交给玩家，主线零感知；同时埋下"服务器/备份/退役"的词汇域，为 4.4 voice 做铺垫。

### 4.2.2 第二段选择：进入（终局过渡点 · finale_transition）

持有 `zero_backup_tape` 后，终局过渡点（finale_transition）出现第二个选择项「下行：离线湾」：

| 玩家行为 | 结果 |
| --- | --- |
| 选择「下行」 | 触发停机转场（黑场 + 风扇声） → 进入第零章（zero_line 地图） |
| 不选（走主线） | 不影响三协议/第五协议任何判定；第零章可留待下周目（若做多周目）或错过（叙事上自洽：维护窗口过了） |

- 两段式设计的收益：发现（图书馆）与进入（终局前）分离，**玩家在"看到了不该看的东西"和"决定要不要去看"之间有一段完整的主线缓冲**，符合 ONI 禁忌素材的越界压力。

### 4.2.3 进入时机与世界规则

- **世界规则**：第零章＝绿洲最早测试服的存档层。地图以**淡出线框 + 文本注释叠加**呈现（呼应玉钥关 Zork 式文本意象，但不做完整文字冒险）：墙、门、地板全部是未上灰的网格，屏幕角落滚动系统日志。
- **时间规则**：进入后第零章内倒计时（维护窗口剩余时间，以"风扇声渐弱"作隐式表达，不显示数字）；倒计时耗尽则自动登出回 finale_transition——**错过即错过**，强化"该存在的窗口"叙事。
