#### V1 母亲（Mother）——已定稿回录（P0-1）

- **身份锚**：北区水泵站抢修人员，工号 0417。
- **语言基调**：工程直觉 + 克制的温情。她谈修理多于谈感情；把爱藏在指令与留白里，不用"我爱你"这类直给句。

- **词汇域**：供电、旁路、胶带、落盘、稳定供能、对价；不出现虚拟层词汇（绿洲/猎人/排行榜）——现实层人物只用现实层词汇。

- **已有范例（沿用）**：
  - 「欠款单上的数字是 4,312。可这笔债真正要还的，不是钱。」
  - 「留两圈。等一个愿意接手的人来证明：这里还能修。」
  - 「设备会找到那个人的。它只认一件事：谁把被丢掉的东西捡起来修好。」

#### V2 基拉·奈特利（Kira）——已定稿回录（K1-K4）

- **身份锚**：绿洲创始人之一，署名被抹去的共同设计者。
- **语言基调**：平静的背负者。不控诉、不煽情，擅长"后来才明白"式的回顾句；对仗工整，句尾常收束成格言。
- **句式习惯**：多用"曾以为/后来才/不是…是…"结构；爱把抽象命题压进一句话（"名字要记在别人心里，才算真的被保存了"）；偶用第二人称赠句（"这句话留给你"）——她习惯把自己的伤口变成可传递的经验。
- **词汇域**：名字、署名、序号、服务器、白纸、存档；虚拟层词汇，但语气是创世者的平静而非玩家的兴奋。
- **情绪上限**：最深情绪用"我怨过他"四字封顶；不用激烈动词（愤怒/恨透）；"怕"是唯一允许直接说出的强烈情绪（"不是恨我。是怕。"）。
- **已有范例（沿用）**：
  - 「被抹去的人，往往自己也曾沉默。这句话留给你，或许哪天用得上。」
  - 「绿洲不该是任何人的私产。它是我、他、莫罗一起做出来的。」
  - 「封存也是保存。有些名字适合慢一点被看见。」

#### V3 奥格登·莫罗（Morrow）——已定稿回录（M1-M4）

- **身份锚**：年鉴馆管理员，实为绿洲创始人之一；见证席持有者。
- **语言基调**：档案管理员式的压抑。话少、留白多、停顿长；用"档案/账/字"做隐喻；承认与回避交替出现，回避时用"随你/留着也不算错"收场。
- **句式习惯**：以"……"起始的沉默开场（"……（停顿）那张署名。"）；人称爱用"她/他"代替名字（"她还留着这个"）；句尾倾向开放式（"问不问，随你"）。
- **词汇域**：档案、账、签、席位、硬币、验证、记录；"共同设计，共同署名"是他的母题，只在最关键处整句说出。
- **情绪规则**：他的崩溃永远用"声音低下去"标注而非台词本身；最重的原话里不出现"恨"，只有"划掉"（"他在最后一版里划掉了我的名字"）。
- **已有范例（沿用）**：
  - 「有些话，留着比说出来更干净。你替她补全了署名，这已经够了。」
  - 「有些账，记在档案里才算数。问不问，随你。」
  - 「绿洲第一笔'公共股份'，现在归你。」

#### V4 诺兰·索伦托（Nolan）——新定（N 线）

- **身份锚**：穹顶集团 CEO；早期玩家 Soron，年轻时 ID「塞壬」。
- **语言基调**：商人的压迫感 + 短暂自白。常态是冷静的契约语言——条件句包装威胁、数据句压垮对手、用"条款/对价/违约"把一切人性话题翻译成成本问题；裂缝时刻（谈及年轻、绿洲、哈理迪照片）闪回老玩家的怀旧与自嘲，语速放慢、人称从"你"滑向"我们"。
- **句式习惯**：压迫时用"合同不会逼任何人，它只是…"式反诘；报价式句式（"你拿到 X，我拿到 Y，两清"）；裂缝时用"那会儿"开头的倒叙句，句末常自我收煞（"…老话而已"）。
- **词汇域**：合同、条款、对价、估值、托管、违约、审计、序号、第几个；怀旧时出现"年轻时/旧终端/排行榜/没人记住的第二名"。
- **分级规则（写作铁律）**：
  1. 公开场合：绝不直接威胁；所有压迫借合同与数据之口（"前面二十六个都签了"是威胁，但被包装成统计）。
  2. 私人场合（N2/N4）：允许一句不设防的自白，且**每线仅一句**（防洗白——他仍选择资本）。
  3. 永不使用虚拟层玩家的兴奋语（如"太酷了"）；即使回忆绿洲，语气也是"我见过它最旧的样子"而非怀念。
- **范例（新定）**：
  - 「你是第二十七个走到这里的猎人。前面二十六个都签了。」（沿用 N1）
  - 「合同不会逼任何人。它只是把后果，写得比决心更清楚。」
  - 「那会儿排行榜上还没有名字，只有服务器和你自己。……后来才明白，名次这东西，攒够了就是筹码。」
  - 「我年轻时也玩过绿洲——比你们都早。只是你们管那叫梦想，我管那叫评估对象。」

#### V5 弗娜莱（F'Nale）——新定（F 线）

- **身份锚**：契约中心执行者，动摇的「第六人」主管。
- **语言基调**：规章复读机 + 裂缝。表面是条款朗读机——编号、流程、标准用语，语音平稳、无情绪；裂缝时出现极短的私人句，且通常以"我"开头就收住、随即转移话题。**停顿是她的标志动作**。
- **句式习惯**：规章句用祈使/陈述（"押送过程不对话""签字后请按流程离场"）；裂缝句短到 2-6 字（"…我也是。"）；转移句用最轻的搭话（"今天轮到你值班了？"）盖过裂缝。
- **词汇域**：规章、条款、流程、签字、值班、押送记录；私人语域仅三个词——"债、家、夜班"。
- **分级规则（写作铁律）**：
  1. 每节点规章句 ≥ 台词量一半——她是系统的人，语言首先属于系统。
  2. 每节点裂缝 ≤ 1 句，且必须跟随"停顿"舞台指示；说破即转移。
  3. 她从不评价系统好坏（"这是流程"是她的世界观句），只做行为裂缝（拖延签字、多留一栏）。
- **范例（新定）**：
  - 「契约中心规章第 7 条：押送过程不对话。你有问题，走申诉通道。」
  - （停顿）「……你也被债压进来过？"——"……值班签到在这边。流程。先走流程。」
  - 「那天夜班签退表我多留了一栏。既然你信得过这个人，这一栏给你看。」（沿用 D3 联动定稿）
  - 「制度是还债的。人是会打折的。……这条不写进规章。」

#### V6 阿尔忒弥斯（Art3mis）——已立基座 + 新定（X 线）

- **身份锚**：绿洲同伴、排行榜玩家。
- **语言基调**：排行榜焦虑 + 共情。自我怀疑但真诚；用"排行榜/名字/匿名/追"为核心意象；与她相处时语速由快转慢——对话前半是猎人式的警觉与玩笑，渐入后才出现停顿与真话。
- **句式习惯**：自问句多（"我是不是…？"）；"名字"是她的最高频词；共情时爱用镜子式表达（把对方的话换成自己的处境再说一遍）。
- **词汇域**：排行榜、名次、ID、匿名、收藏、掩护、署名；负面词汇是"配不上/不知道自己是谁"。
- **情绪规则**：她不哭诉，用行动拆解焦虑（匿名收藏、假遥测并行）；对埃尔最深的一句感谢用玩笑包装；信任 ≥2 才出现"下次换我掩护你"的直接承诺——**数值轨道与台词温度严格挂钩（0 档客气 / 1 档自白 / 2 档承诺 / 3 档署名）**。
- **范例（新定 + 沿用）**：
  - 「排行榜刚出现的时候，我还是一个不知道用什么名字登录的人。」（沿用 X1 独白）
  - 「在排行榜上待久了，反而不知道自己是谁。」（沿用 X2 描述）
  - 「你为什么要追这些过去？……别误会，我不是说过去不重要——我只是想知道，追它的人是谁。」（X1 新写）
  - 「下次换我掩护你。……这是承诺，不是战术。」（trust≥2 赠言新写）

#### V7 艾奇 / 海伦·哈里斯（Aech / Helen）——新定（E 线，双声线）

- **身份锚**：工坊机械师，绿洲身份（游戏壮汉艾奇）与现实身份（黑人女孩海伦）分离。
- **语言基调**：**双声线同一身体**——绿洲嗓门（艾奇）：豪爽、夸张、技术黑话、大笑标识（"哈！"），把不安捂进玩笑；现实心声（海伦）：短、低、自疑，涉及"身体/声音/照片/现实"时切换，句长骤减。
- **句式习惯**：艾奇模式——命令他人干活+自夸+哈哈（"螺丝钉不是拧上去的，是谈出来的，哈！"）；海伦模式——以"其实/如果有一天/你问我为什么"开头，句尾常悬空（"…先做给自己看"）。

- **范例（新定）**：

  - 〔切换到海伦〕「在现实里，没人听一个女孩讲轴承。……在绿洲里，声音能替身材说话。」（E2）
  - 「如果有一天你知道我长什么样，还会来这个工坊吗？」（沿用 E1 定稿）
  - 「外壳拆开就回不去了。……所以你先看模型，名字的事，我们以后再说。」（E3 新写）

### 第二部分 · 扩展线对白体例规范（写作必须遵守）

#### C1 双语格式
- 每个对白单元：中文原句 + 空行 + 英文译文，英文以 `[Speaker]` 开头（说话人英文名，如 `[Nolan]`、`[F'Nale]`、`[Aech]`、`[Art3mis]`）。
- 中英文义对齐：不逐字直译，保语气与语域（翻译腔越少越好；中文的"停顿/裂缝"须在英文用断句、破折号或括号体现）。
- 标点：中文用全角【】与"…"；英文用标准半角与 —/…；舞台指示统一（中文）（全角括弧），英文 (半角括弧)。

#### C2 说话人分层
| 层 | 中文标记 | 英文标记 | 用途 |
| --- | --- | --- | --- |
| 旁白 | 【旁白】 | `[Narrator]` | 场景动作、气氛、转场描述 |
| 系统 | 【系统】 | `[System]` | 界面/数据/条款播报（合同、权限、记录） |
| 角色 | 【角色名】 | `[Name]` | 角色台词 |
| 特类 | 【批注】【标语】 | `[Annotation]` | 墙贴、手写批注、涂鸦等环境文本 |
- 例外：P0-1 既有体例中【系统】下直接写 `[Mother]` 台词（系统播报的红字与母亲台词同段）——保留原体例，不强行拆层。

#### C3 舞台指示
- 情绪/动作：角色台词行内或行尾（全角/半角括弧）标注，如（声音低下去）（停顿）（他把硬币按进埃尔掌心）。
- 场景动作：归【旁白】行，动词明确、可演出（"她一顿，转移话题"→"她把签到表翻回第一页，顿住"）。


- 反馈句不得泄露数值（不显示 +1/-1），用行为化描述（"她把那行字另存了一份"）。

#### C5 演出段
