# 第一部分 · 采纳决策记录

## 1.1 决策

项目方于 2026-10-17 **确认采纳**《THE-OASIS-剧情结局重构与第六剧情线方案-20261008》。

- 方案层文件（PROPOSAL-20261008）原约定"落码以后续授权为准"，本次决策即**落码授权**。
- 自此，20261008 方案由"提案/待审"状态转为**执行基线**：后续剧情补写、数据契约、代码落码、资产制作一律以本基线 + 20261005 剧本为准。

## 1.2 决策生效范围

| 对象 | 生效结果 |
| --- | --- |
| 结局体系 | 同一主线四协议 → **三协议 + 穹顶线独立结局**；最终形态为 **6 个结局** |
| 新增剧情线 | 第六剧情线「第零线 · 归零者」正式立项（内部代号 `zero_line`），含新场景「第零章」、新角色「归零者」、新结局「第六协议 · 归还」 |
| 主流程 | 三钥三关 → 水泵站 → 签约厅 → 童年房间 → 结局 的骨架**不动** |
| 现有扩展线 | 七条既有扩展线（K/M/D/N/F/X/E）**不重写、不删改**，延续既定批次结构 |
| 引擎判定 | 最小改动：仅童年房间热区集合减少一档；`advanceIf` / key 原子提交机制不动 |

## 1.3 里程碑同步

本基线落地后，进入 **数据契约增量 → 分批复核与落码 → 资产与演出 → 全分支回归** 的执行通道；具体批次见第六部分。

# 第二部分 · 新旧结局体系映射

## 2.1 改动前后对照

**改动前（20261005）**：

```
未签合同 ──→ 裁决台 ──→ 协议一 inherit（自由）
                   ├──→ 协议二 dome ── 唯一结果 ─────┐ ← 语义异质：与"自由裁决"并列
                   ├──→ 协议三 public_energy（自由）  │
                   └──→ 协议四 charter（自由）        │
签合同 ───────────────→ 同上，但被 buyoutBinding 锁死 ┘
第五协议（元结局，解除约束后仍独立）
```

**改动后（20261008）**：

```
未签合同 ──→ 童年房间（三热区）──→ 协议一 inherit
                              ├──→ 协议三 public_energy
                              └──→ 协议四 charter
签合同 ──→ 穹顶线（独立终局演出）──→ 协议二 · 穹顶托管（唯一结局，独立呈现）
第六剧情线（另一入口，选择驱动）──→ 第六协议 · 归还
第五协议 · 共同署名（元结局，四线合流，任意三协议之上）
```

## 2.2 动与不动清单

| 对象 | 处理 | 说明 |
| --- | --- | --- |
| 协议一 · 个人继承（inherit） | 保留 | 未签合同前提下的自由裁决之一 |
| 协议三 · 公共能源（public_energy） | 保留 | 同上 |
| 协议四 · 玩家公约（charter） | 保留 | 主线真结局，判定与 reviews 全部不动 |
| 协议二 · 穹顶托管（dome） | 单独分出 | 从童年房间裁决台移出，独立成「穹顶线」结局 |
| 第五协议 · 共同署名（fifth） | 保留不动 | resonance 轨道、第五信物、五段演出、排除项全部沿用 20261005 方案 |
| 第六剧情线「第零线」 | 新增 | 全新场景「第零章」+ 全新角色「归零者」+ 全新结局 |
| 主流程段落 | 不动 | 三钥三关 → 水泵站 → 签约厅 → 童年房间 → 结局 的骨架保持 |
| 现有七条扩展线（K/M/D/N/F/X/E） | 不动 | 不重写、不删改；新线与既有线只在 reviews 层交叉引用 |
| 现有引擎判定 | 最小改动 | 仅童年房间热区集合减少一档；advanceIf / key 原子提交机制不动 |

# 第三部分 · 采纳后必改清单

以下为采纳方案后必须落到代码/数据/内容侧的改动项，按生效对象归类。

## 3.1 童年房间热区（裁决台）

- **现状**：童年房间四件童年物件热区并列为四协议选项。
- **改动**：热区由四件改三件——`obj_dome`（旧电视）移出裁决台。
- **约束**：未签合同玩家无感；三协议达成路径与达成全表不变。

## 3.2 结局列表与呈现（4 → 6）

- 结局体系由"四协议平行呈现"改为：**三协议抉择 + 穹顶线独立终局演出 + 第五协议隐藏 + 第六协议隐藏**。
- 协议二不再与三协议挤同一裁决呈现；穹顶托管获得独立的终局演出（3-4 分钟，替代原 dome 结局正文的单段呈现）。
- 终局裁决台（palace console / finaleChoice 界面）新增**第六信物槽**，默认不可见，仅在 `sixth_signal_ready` 置位后出现。

## 3.3 reviews 迁移

- 8.3.1–8.3.4 中 **dome 列全部迁入穹顶线结局回顾**：引用条件与文案不变，仅归属出口改为穹顶线。
- 第六协议追加 reviews 条目：公共条 + Z3 三选一差分条（`zero_db_public` / `zero_db_sealed` / `zero_db_questioned`）。
- 新增双隐藏结局合题条目：`allOf: ['fifth_signature_done', 'witness_release']`，在两者 `ending_seen` 均置位后追加，不参与解锁判定。
- 新增第六结局 × 五角色去向条目（阿尔忒弥斯 / 莫罗 / 弗娜莱 / 艾奇 / 诺兰），并入八结局回顾体系。

## 3.4 第零线入口（两段式）

| 段 | 位置 | 内容 |
| --- | --- | --- |
| 第一段：发现 | 第三幕 · 图书馆（library） | 主路新增可选调查点「落灰服务器柜」（非主线热区、无引导标注）：打开柜门 → 获得 clue `zero_backup_tape`（「第零章的备份磁带」）；离开无变化；反复打开（>2 次）仅演出差异、不写状态 |
| 第二段：进入 | 终局过渡点（finale_transition） | 持有 `zero_backup_tape` 后出现第二选择项「下行：离线湾」→ 触发停机转场进入第零章；不选不影响三协议/第五协议任何判定 |

- 入口全程可选：跳过不影响任何既有结局；不剧透、不惩罚。
- 世界规则：第零章 = 绿洲最早测试服的存档层；倒计时隐式表达（风扇声渐弱），耗尽自动登出回 finale_transition（错过了即错过，可再入策略见 5.3 待决策第 3 项）。

## 3.5 引擎最小改动面

| 改动点 | 口径 |
| --- | --- |
| 童年房间热区集合 | 四 → 三（移除 obj_dome） |
| buyoutBinding | 只读不动，唯一判定来源不变 |
| advanceIf / key 原子提交 | 不动 |
| 排除项统一 | 第五协议与第六协议共用同一组排除项：buyoutBinding / 迷宫背弃（ally_maze_leave），触发即写 `sixth_arc_sealed = true` |

# 第六部分 · 分批复核与落码执行计划

## 6.1 总顺序

```
决策冻结 ✅（本基线）
   ↓
数据契约增量（第一批：K/M）
   ↓
分批复核与落码：K/M → D/N/F → X/E →（可选）第零线
   ↓
穹顶线改动落码（热区三件 / dome_line_played / reviews 迁移）
   ↓
资产与演出（第零线 1 新图 + 服务器柜 0.5 图 + 演出 2 段；穹顶线演出）
   ↓
全分支回归测试（三协议断言 + buyoutBinding + 第五/第六排除项 + 六结局路径）
```

## 6.2 批次明细

| 批次 | 内容 | 状态/口径 | 完成条件 |
| --- | --- | --- | --- |
| 第 1 批 | **K/M 线落码**（数据契约增量首批） | K/M 剧本定稿（待落地） | 节点 id、类型、触发条件、写入 flag/clue、批互锁、reviews 条件引用全部落成 story_config.js 可执行规格并通过打包校验 |
| 第 2 批 | D/N/F 线落码 | D/N/F 节拍/全文定稿 | 同上（每线 0 新图 / 4 节点 / 演出 ≤2 屏预算内） |
| 第 3 批 | X/E 线落码 | X1-X3 已落地；E 线全文定稿 | X/E 剩余节点补齐并回归 |
| 第 4 批 | 穹顶线改动 | 依赖第 3 部分清单 | 童年房间三热区、dome 独立演出、dome reviews 迁移、`dome_line_played` 防重播、旧存档兜底 |
| 第 5 批 | 第零线（可选） | 依赖待决策第 3、4 项 | Z1-Z4 全文对白补写 → 数据契约 → 新图/演出 → `sixth_*` / `zero_*` 落码 → 第六结局解锁与 reviews |

## 6.3 资源预算约束（沿用）

- 既有扩展线（K/M/D/N/F/X/E）：每线 **0 新图 / 4 节点 / 演出 ≤2 段**。
- 第零线：**新图 1 张**（第零章，线框/文本风格残次世界）＋ 服务器柜子场景（复用 library 内嵌子场景，按 **0.5 图折算**）＋ 演出 2 段＋ 结局正文 1 段＋ reviews 增量。
- 新增 flag/clue 只进演出、谈判文本与结局回顾 reviews，**不得写入四协议解锁布尔**。

## 6.4 落码前需补齐的剧情缺口（第零线）

方案第 4 部分为节拍定稿：Z1 演出接入、Z2 归零者会面（对白节选）、Z3 三选一（收束节选）、Z4 演出＋解锁。落码前需按 10.1 voice bible（含新增 V8 归零者卡）**补全中英全文对白与演出台本**，并经评审对齐后再进入数据契约。
