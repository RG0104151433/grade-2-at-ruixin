## 1.2 硬约束（不可违反）

1. **命名以剧本 20261005 为准**：F 线 flag/clue 使用剧本正文定稿命名（`fnale_arc_unlocked`、`fnale_helped`、`fnale_reported`、`fnale_neutral`）；文档地图 G3 列出的工程检索锚点 `e_ch_index`（当前 count=0）仅作定位用，不得作为新状态 id 落码；`aech` 命中为 E 线锚点，与本线无关。
2. **事件类型白名单**：`dialog / setFlag / discoverClue / ifClue(then/else) / ifFlag(then/else) / finaleChoice / changeMap / preload / goalHint / archiveTransition / inviteVerify / indexBook / fade / choice`。
3. **filter 只收 flag，clue 判定必须走 ifClue**：F2 线索「弗娜莱的停顿」为 clue，不得写入任何 trigger 的 `filter/entryFilter`，只能用 `ifClue` 判定防重播。
4. **不触碰四协议解锁布尔**：本契约全部新增状态只是演出、对白与结局回顾（reviews）的素材，**不得写入** inherit / public_energy / charter 的 requirements 或任何协议解锁判定（9.1 声明）。
